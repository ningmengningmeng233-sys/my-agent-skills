# 空间动态与站位记忆表（Blocking Memory Sheet）

> 来源：MiniMax Design 官方客户端 `workflows/drama-series/reference/assets-blocking.md`。
> 本模块用于锁死连续镜头中的主锚物坐标、在场旁观者、视线面向及跨镜头状态转移，彻底杜绝多角色同框瞬移、背对背突变及旁观者莫名消失。

## 1. 空间物理基准与主锚相对坐标

1. **绝对主锚物（Primary Anchor）**：每个场景必须指定且仅指定一个视觉焦点主锚（如“神案与残破石佛”、“会议长桌中央投影仪”、“审讯室单向玻璃”）。
2. **禁止虚无坐标**：严禁写“在房间朝东2米处”、“X:12, Y:4”等非视觉描述。所有位置必须写为相对于主锚物的方位与刻度：
   - `极近（At/Adjacent）`：肢体与锚物相触或紧贴（如趴在案上、倚靠石佛）；
   - `一臂之距（Arm's length）`：伸手可及，常用于近景互动；
   - `近距（Near, 1~2 步）`：处于主锚物身侧，常用于对话正反打；
   - `中距（Mid, 3~5 步）`：处于中景可见范围，与主锚形成构图呼应；
   - `远距（Far, 半个场景外）`：位于深景深后景虚化区域，常用于门窗把守或暗中观察。

## 2. 在场角色全量类型分类与旁观者锁定

1. **角色在场名单铁律**：同场景连续片段，必须以上一段落的完整在场名单为起点。只有剧本明确写出离开动作（离场行）的角色才允许离场，剧本明确入场的角色才允许新增。
2. **角色功能二元分流**：
   - **对白与焦点主体（Dialogue Actor）**：当前承担主台词、主动作推进的角色。
   - **在场旁观者（On-Scene Witness）**：在场但未说话或无攻击动作的角色。**官方铁律：在场旁观者必须在背景边缘或虚化区域显式锁定其站位与视线面向，绝不能直接省略**。
3. **旁观者反应契约**：焦点主体说话或动作时，在场旁观者必须在 prose 中带有一项符合其处境的微小可见反应（如：瞳孔微缩、手指微扣佩刀、呼吸骤停半拍、目光转向核心道具），禁止僵死如蜡像。

## 3. 视线面向与 180 度对话轴保护

1. **视线对象锁定**：每个在场角色必须显式声明其身体面向（Body Facing）与当前视线对象（Gaze Target），如“身体正对石佛，视线平视右侧阴影中的黑衣人”。
2. **轴线越界防御**：机位必须明确位于对话轴线的特定一侧（画左或画右）。除非出现明确的环绕运镜（Steadicam arc）或过肩反打，否则在同一场景中禁止镜头越轴导致角色左右关系颠倒。

## 4. 跨片段状态转移契约（State Handover Contract）
