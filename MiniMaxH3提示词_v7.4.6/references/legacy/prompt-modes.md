# 其余模式对照（legacy — Ref2VA-only 不用于输出）

> 本技能用户决策：只输出 Ref2VA（全能参考）六段结构。文生/图生/首尾帧/
> 末帧模式的知识保留在此文件供对照参考，**不进入产出流程**。
> 来源：官方 H3 资料核对（2026-08-15），与 official-h3-grammar.md 同源。

## 基础模式骨架（T2VA / I2VA / FL2VA / L2VA — 三段）

```
[图片对齐指令 — 仅图生/首尾帧/末帧模式需要，文生省略]

综合多模态描述: [镜头 1] 风格 + 构图 + 主体 + 动作 + 运镜 + 对白 ...
[镜头 2] 于 00:03.500，镜头切至 ...

整体声景: 环境音 / 动作音 / 非语言人声（1~4 句）

非剧情音乐: 背景乐（乐器+速度+节奏+动态，1~3 句）
```

## 图片对齐指令（图片模式专用，第一行，后空一行）

- 图生: `For the target video, at 0.00 seconds into the target video,
  <图片 1> (from [镜头 1]) is fully referenced.`（产品端可写中文：
  「目标视频第 0.00 秒处完整参考 <图片 1>（来自[镜头 1]）」）
- 首尾帧/末帧同理按官方模板，N 为最终镜头编号，S.SS 为两位小数时长。

## 各模式动作官方结构

- 图生: 首帧锚点 → 动作发生 → 持续发展 → 结果或反应
- 首尾帧: 首帧状态 → 可观察的中间变化 → 差异逐步收窄 → 尾帧状态
- 末帧: 合理前置状态 → 明确的动作与过渡路径 → 末镜头逐步收敛 → 落到末帧
