# Lighting, Color & Material — 光色材质写作体系

> 来源：地狱 lighting-color-material（精读 + H3 适配）。本技能失败码
> F-LIGHT-DIR / F-EXPOSURE / F-MATERIAL / F-WEATHER 与评分维度「光色材质
> 10 分」都指向此域——本模块提供正面写作公式（防病不治病）。
> 国漫 3D 适配：皮肤响应以画风层磨皮为准（非毛孔写实），本表其余材质照用。

## 1. 光源五问（每个主要光都回答）

- 光源：太阳 / 天光 / 窗 / 灯具 / 火焰 / 屏幕 / 车灯
- 方向：相对场景、人物、摄影机从哪里来
- 软硬：光源面积与距离带来怎样的阴影边缘
- 对比：明暗层级与填充程度
- 曝光保护：脸 / 窗外 / 火焰 / 金属高光 / 暗部——谁优先保留细节

推荐写法：「主光自画左后方窗投入，冷而宽的天光成柔边侧光；室内仅案头
灯为局部暖光，不填平脸部阴影；保护皮肤与窗外天空细节。」

## 2. 光线五层（不要求每镜五层——光源逻辑一致即可）

| 层 | 作用 |
|---|---|
| 环境底光 | 建立整体可见度与色温（天空 / 室内反弹 / 雾中散射） |
| 主光 | 建立主体体积与叙事焦点（来源 / 方向 / 软硬 / 强度关系） |
| 辅光 / 负补光 | 控制阴影信息（填充比例或有意压暗） |
| 轮廓 / 实景光 | 分离轮廓并证明光源存在（门 / 灯 / 火 / 屏幕的空间位置） |
| 互动光 | 事件对主体与环境的瞬时影响（爆炸 / 车灯扫过 / 屏幕变化） |

自然光场景可能只有天空与反弹——关键是光源逻辑一致。

## 3. 相机光侧

- 顺光：信息清楚，体积较弱
- 侧光：强调面部与材质体积
- 逆光：强调轮廓、空气与遮挡，脸部是否保阴影要明确
- 阴影侧机位：强调反差与轮廓，但**不能同时要求均匀明亮的正面肤色**

「脸在深影中」时允许的可见信息要具体：轮廓边缘 / 眼睛反光 / 极弱的天空
反弹——绝不追加「脸部每个毛孔明亮可见」。

## 4. 曝光保护（写优先级，不同时保住所有极端）

「曝光优先保护人物脸部中间调；窗外允许接近高光但保留云层；房间角落落入
深影，不要求全部提亮。」

**三组经典矛盾（都不可写）**：
- 夜景「极暗」+「每个背景细节清晰」
- 火焰是最亮源，却要求「完全不过曝」+「整个场景同样明亮」
- 逆光剪影 +「正面均匀美妆光」

## 5. 60:30:10 的适用边界

画风层色彩轴采用 60:30:10——它是**可选**的色彩层级工具：60% 主色建立
世界，30% 辅色分离主体，10% 强调色指向叙事焦点。不要求像素精确；不适合
纪实 / 单色 / 自然混光 / 高饱和场景；**不固定复制到每份提示词**——只在
颜色层级真有叙事用途时用。

## 6. 材质响应（材质不是名词，是同一光下的不同响应）

| 材质 | 重点响应 | 常见失败 |
|---|---|---|
| 皮肤 | 次表面透光、颜色不均（国漫 3D：磨皮柔光，见画风层） | 塑料磨皮、所有区域同亮 |
| 布料 | 织纹、褶皱、厚度、磨损、吸水 | 像橡胶或贴图 |
| 金属 | 边缘高光、环境反射、氧化、划痕 | 统一灰色、无反射结构 |
| 玻璃 | 反射、透射、厚度、污渍、折射 | 完全透明无存在感 |
| 木材 | 纹理方向、粗糙度、边缘磨损 | 塑料木纹 |
| 骨骼/角质 | 多孔、细裂、半哑光、厚度 | 光滑陶瓷感 |
| 湿面 | 窄高光、环境反射、滴落、颜色变深 | 只加亮度不影响周围 |
| 烧焦面 | 高粗糙度、裂缝、内部残留色、无均匀镜面 | 像黑色油漆 |

复杂角色先做**材质分区**（哪些区域是皮肤/布料/骨/金属/湿面/烧焦），
不同区域不能共享同一种高光。

**面料运动描写（古装/玄幻常用 — 来源：jineng 13-fashion，2026-08-16
打磨补）**：丝绸/锦缎——涟漪式波动、受光面流动光泽（「衣料如水波般
涟漪」）；薄纱/雪纺——漂浮感、空气托举（「纱随动作漂浮，边缘先动」）；
棉麻——垂坠褶皱、折痕随动作变化；皮革/甲胄——硬挺、折角锐利、受光
高光移动；刺绣——纹饰清晰（见 guoman-3d 材质分工）。布料运动与动作
保持因果（衣随人动、尾随半拍——见 performance-physics §13.6 跟随重叠，
绝不布料先动后人才动）。

## 7. 天气必须作用于世界（与 high-risk-shots #14 呼应成对）

- 雨：衣服吸水变深，皮肤与硬表面出现不均匀水膜，地面反光和水花有方向，
  雨受风影响
- 雪与暴风：雪积在迎风面与水平面，人物呼吸、头发、衣摆和能见度共同
  变化——不能只有背景贴一层雪点
- 雾与烟：雾显示光路并降低远景对比；烟有来源、温度、方向和消散——前景
  主体与远景不得同样清晰
- 尘土：来自脚步、撞击或崩塌，受光束显形，随后扩散沉降
- 风：头发、布料、雨雪、烟和植被方向一致；不同重量产生不同延迟与幅度

## 8. 颜色脚本（跨场次登记）

世界基色 / 角色识别色 / 安全-危险·现实-幻觉·过去-现在等叙事色 / 场次中
的颜色变化 / 禁止漂移的色温或强调色——跨镜连续性见 shot-structure §4
八类连续性（光色类）。
