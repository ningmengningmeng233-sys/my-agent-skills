# SKILL.md 轨道 A 编剧室单步压榨孵化（原文全文）

> 归属：`小说转短剧_v1.5.2`（dramacraft）技能仓 SKILL.md「SKILL.md 轨道 A 编剧室单步压榨孵化」段，governance 第2轮 REFACTOR 自 SKILL.md 整体逐字挪入（一字未改），SKILL.md 原位留指针。

---

当用户只有零散点子、人物碎片或一系列无主线小故事时，启动「编剧室单步压榨流」：

1. **零散素材自动入库**：用户随手粘贴脑洞、金句或随笔，由 `card_ledger` 自动切分打标存入素材卡池 `<workdir>/inbox/cards.jsonl`（包含点子 idea / 人物 character / 规则 world_rule / 事实 fact / 金句 line）。卡池已有的内容**严禁重复盘问**。
2. **编剧室单步压榨盘问（遵守柠檬思考三大铁律）**：
   - **铁律一：一次一问**。严禁并列轰炸，每次只压榨 1 个核心卡点（欲望与不可逆后果 $\rightarrow$ 对手阻碍 $\rightarrow$ 突发转折与代价 $\rightarrow$ 首尾纯物理画面）；
   - **铁律二：菜单制为主，暗门为辅**。每次提问给出 2~3 个具象互斥选项，首位标 `[推荐]`（例如时长问档不问秒：60s钩子档 / 90s标准档 / 180s丰满档）；末尾留一行小字供自由发挥，触发自由回答后必须回锚校验；
   - **铁律三：单向棘轮**。遇到剧情逻辑软弱（主角靠运气、反派无故认怂），立即触发【戏剧软弱警告】并给出升级强对抗选项，绝不妥协降级。
3. **前提纪要硬核预审（P1~P9 门禁）**：
   - 孵化成果落盘为 `<workdir>/state/premises/ep###.json`；
   - 必须通过 `python -m dramacraft.premise_lint <ep###.json>`（P1四件套确权 / P2不可逆后果 / P3人物≤4人 / P4首尾纯物理动作禁文学病 / P5离散档位 / P6基调明确 / P7卡池溯源 / P8暗门回锚 / P9明确授权）；
4. **一键转译大纲**：通过 `premise_to_outline.py` 将纪要列表转译为 `outline.json`（自动注入 `mode: "anthology"`，100% 自动通过 O1~O6 大纲预审门）。
5. **分集剧本编写与 12 门质检**：
   - 按剧本 JSON 契约产出 `ep###.json` 并过 `validate.mjs`；
   - 节拍红线：action 纯物理动词禁文学病（G11）、台词 ≤35 字禁辩论腔（G12）、每场 ≥1 动作（G3）、结尾物理 cliff（G6）、hookBeat 前 3 拍兑现（G2）。
6. **盘问军规（五条，硬性；照搬 ai-shifu pedagogy 原文）**：
   - **单个创作模块至多一次信息收集**：分散收集，禁止开局把问题灌满；
   - **单会交互上限 5 问，推荐 3~4 问**；
   - **连续 ≤3 问必给一次实质产出反馈**：先给东西再往下问，不能光问不给；
   - **每问必有下游用途**：改不动剧本的问题不问，卡池里没有的缺口不问；
   - **拍板强制复述锚定**：用户每次拍板后，先复述「选了什么 + 对节拍/代价/钩子的即时影响」，再推进下一问。
7. **心理契约开场三档（`criticism_level`）**：进入评审/对抗类环节前先问用户偏好——①「发现问题·尽量多挑毛病」②「均衡」（**默认**）③「确认亮点·鼓励为主」，纪要可选字段 `criticism_level` 记录。**单向棘轮只调语气不调标准**：鼓励为主 ≠ 放宽质量门。
8. **料不足出粗稿（Fallback SOP）**：素材不够时允许出粗稿，但必须带齐四字段——`uncertainty`（low/medium/high）/ `assumptions`（因输入不全所做的假设）/ `upgrade_notes`（补什么料能升级） / `rerun_hints`（用户补哪些料可重跑）。不许把「猜的」当「查的」交付。
