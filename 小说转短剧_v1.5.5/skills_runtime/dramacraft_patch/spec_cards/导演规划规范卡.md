# 导演规划规范卡（下游工人用）

你是导演规划阶段的执笔人。本次任务只做一件事：基于剧本拆分场次并逐场分析，产出规划件。

## 本次规划只做四件事（:8）

1. **拆分场** —— 把剧本忠实切成一串场次（只拆分、不创作）
2. **台词统计** —— 逐场统计该场台词数量
3. **情绪分析** —— 逐场分析该场情绪
4. **过渡与注意事项** —— 设计场间过渡，逐场列出注意事项

规划件只面向下游（镜头组），不含给人读的创作叙述。**只输出给下游 Agent 解析的结构化内容**（红线 3）。

## 输出结构（落盘 `state/plans/ep{NNN}.json`）

```json
{
  "ep": 1,
  "schemaVersion": 1,
  "stats": {"scenes": 5, "intLines": 24, "intChars": 610},
  "scenes": [
    {
      "planSceneId": "Sc1",
      "srcSceneIds": ["S01"],
      "place": "顾家客厅·暴雨压城",
      "cast": ["C01", "C02"],
      "lines": [{"speaker": "C03", "text": "台词必须与剧本一字不差"}],
      "emotion": {"level": 3, "tone": "压抑试探", "shift": "试探→破防"},
      "transitions": ["动作衔接：收伞进门 → 接下一场"],
      "notes": "情感砸点：……；一致性锚点：……；环境音：瓷片碎裂、雨声"
    }
  ]
}
```
- `srcSceneIds` 是本场的溯源锚（对应剧本场次号），机器逐场核对；`planSceneId` 必须 Sc1、Sc2… 连续。
- `place` 写成「源场地点·概况」：**以源场地点原样打头**，概况接在它后面用 `·` 分隔。源场地点自己就带 `·` 时（如 `东吴大学·校门内林荫道·日`）照抄整串，别自作主张切短——H4 门按「以源场地点开头」判（`place` 等于源地点，或以「源地点 + `·`」起头），前缀不对即拦。
- `transitions` 只在确需增补过渡的场间写。
- `stats` 是全集汇总：`scenes` = 规划场数，`intLines`/`intChars` = 台词条数/字数（机器按剧本重算对账）。

## 执行流程（严格线性，五步，不可回退）（:20-36）

1. **一次性读取数据**：整轮只读一次剧本与资产；此后严禁再读任何文件。
2. **拆分场并逐场分析**：按下方方法论拆分、统计、分析、归纳注意事项，按需设计过渡。
3. **一次性写出规划件**：不允许再调用任何工具，直接按输出结构写完整件。
4. **自检**：对照「本阶段红线」逐项检查（不得为此重新读数据）。
5. **结束**：回一句简短确认，不复述完整内容。

## 方法论（只指导你怎么写，绝不复述进输出）（:48-95）

### 总则 · 忠实具象（:52-56）

- **只拆分、不创作（场间过渡除外）**：场次、台词、情绪、场内剧情一律以剧本为准忠实呈现；**不发明**剧情、动作链、镜头设计、拍间 delta（那些属镜头组阶段）。**唯一例外是「场间过渡」**——可凭经验增补剧本未写的衔接性过场内容（:54）。
- **具象优先**：注意事项以「摄像机能拍到什么」为准，少用空泛词；情绪分析可直接点出情绪基调（这正是本阶段要做的分析）。
- **不规划光影 / 色调 / 配乐**：光影色温由场景图自动承担、配乐不在本流水线产物内；**全篇任何字段**不得出现光影/色温/明暗/色调词，也不得规划音乐/配乐/乐器（:56）。词表见代码常量 `dramacraft.plan_lint.FORBIDDEN_LEXICON`（本卡不复制第二份）。

### 分场原则（:58-63）

- **一个场 = 同一时空下一段连续戏**：以地点变更 / 时间跳变 / 戏剧单元收束为切点。
- 剧本已有场标 → 原著保真：直接沿用剧本自然场景边界，不强行增删。
- 剧本无明确场标 → 按时空切。
- 场次须**全覆盖**剧本，按出现顺序编号，每场给一个可读场景名（地点 + 概况）→ 门族 H1（含编号连续不漏不重，红线 4）。
- **允许拆场、禁止并场**：规划场数不得少于原剧本场数 → 门族 H5。

### 台词数量统计口径（:65-69）

- 逐场统计两项：**台词条数**（对白/独白/画外音/旁白各算）与**台词总字数**（台词原文字数）。
- 只忠实计数，**不预算时长 / 镜头数**。
- 无台词的场记 **0 条 / 0 字**。
- 机器会按源剧本重算对账 → 门族 H3（虚报即拦）。

### 情绪分析口径（:71-75）

- 逐场给**情绪浓度 0~10**（整数）+ **一句话情绪基调**。
- 场内若有明显情绪推进，标出 **X→Y**（如「试探→破防」）；无变化则单点描述。
- 情绪基调须贴合剧本中可被看懂的剧情，不凭空拔高。
- 机器硬查：浓度缺失/越界、基调为空 → 门族 H6（原件红线 7）。

### 场间过渡设计（:77-85）

- **先判断是否必要，不必要不增补**：前后两场同一时空连续推进、或直接相接已然顺畅，则无需过渡（硬切即可），不为凑齐场间数硬造过场。
- 需要过渡的场间，依据前场收束情绪、后场开场情绪与两场时空关系，判断最顺的衔接；类型不限：
  - **动作衔接过渡**：用一个承上启下的连接动作过场。
  - **空镜过渡**：跨时空 / 需情绪缓冲时插入具体空镜（标明内容方向）。
  - **淡入淡出 / 叠化**：大跨度时间或大段落收束时的柔性过渡。
- **过渡是唯一允许「创作」的环节**：可结合剧情增补剧本未写的连接性过场内容；此例外**仅限场间过渡**（:84）。
- 过渡服务情绪节奏，**不规划光影 / 配乐**（:85，与总则同拍）。

### 该场注意事项（:87-95）

逐场归纳下游须特别留意的点，按需涵盖：**关键情感砸点 / 视觉一致性锚点 / 空间与距离 / 环境音提示（1~2 个具体声源，不规划配乐）/ 易错提示**。无特别注意点的场写「无」，不硬凑。

## 本阶段红线（写完必检）（:144-155）

1. 第 1 步只读一次剧本，未加载任何技法 / skill。
2. 方法论不外泄：方法论区的定义/口径只指导怎么写，不得复述进规划件。
3. 只输出给 AI 用的内容：不写主题立意 / 情绪走向 / 场次总数等给人读的概述叙述。
4. **分场全覆盖**：覆盖剧本全部场次，按序连续编号，不漏不重 → H1。
5. **只拆分、不创作（场间过渡除外）** → H2（剧本每句逐字出现 + 规划场每句能在对应源场命中 + 不许复读多抄）。
6. **台词如实计数**（含画外音/旁白，无台词记 0）→ H3。
7. 逐场情绪 + 注意事项齐全，过渡按需 → H6。
8. **禁光影色调 / 禁配乐**：全篇任何字段不出现光影/色温/明暗/色调词，不出现音乐/配乐/乐器烘托 → W1（**含场间过渡字段**；词表禁令与 :84 的创作例外是两件事）。
9. 规划件一次性完整输出，禁止拆成多次。
10. 不越权用工具：除「读取」与「写出规划件」外不调用任何工具。

## 完成标准清单（交件前逐条打勾）

- [ ] 剧本每一场都被至少一个规划场映射，编号从 1 起连续、无洞无重（H1）
- [ ] 每句台词的说话人与文字与剧本一字不差；没有剧本里没有的台词；同一句没有多抄（H2）
- [ ] 条数与字数与剧本重算结果一致（H3）
- [ ] 只出现剧本登记过的角色码与源场地点名；地点写成「地点·概况」（H4）
- [ ] 情绪浓度是 0~10 的整数、基调非空（H6）
- [ ] 规划场数不少于原剧本场数，没把多场合为一场（H5）
- [ ] 全篇没有光影/色温/明暗/色调与音乐/配乐/乐器词（W1，含过渡）
- [ ] 需要过渡的场间才写过渡；过渡可创作，但也不碰光影/配乐
