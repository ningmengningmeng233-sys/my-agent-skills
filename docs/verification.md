# 验证范围与已知限制

本页整理截至 2026-10-16 的工程边界，供选择技能时参考。版本以 [catalog.json](../catalog.json) 为准；文档完善不改变候选或验收状态。

## 应当分别确认的五件事

| 层次 | 能说明什么 | 还不能说明什么 |
| --- | --- | --- |
| 目录与入口一致 | 版本、路径、入口契约可对账 | 依赖已安装 |
| 本地工程验证 | 指定测试、离线样本或分发检查通过 | 所有真实业务成功 |
| 宿主加载 | 客户端能读取指定技能 | 自然触发、所有工具都可用 |
| 真实业务验证 | 指定账号、模型、输入实际运行并核对 | 其他机器、系统或输入同样成功 |
| 人工效果验收 | 原文引用、文字效果、音画或交付满足本次要求 | 普遍质量或固定成功率 |

不能将其中任意一行简写为“全仓全部完成验收”。

## 已有工程依据的范围

前一轮覆盖检查包括根契约、目录身份、部分包的回归、分发清单与隔离运行演练。去 AI 味的核心依赖与可选相似度依赖已拆分，并做过隔离安装和任务恢复演练；H3 做过规则回归与本地构建门；UMH 做过 Windows 分发成员检查。这些依据用于描述工程范围，不能代替文学效果、接收者客户端或付费模型的实际结果。

本次介绍页更新只验证文档导航、文件存在、版本对应和相关既有契约，不重新宣称所有产品的完整业务测试通过。

## 必须保留的缺口

| 产品或场景 | 当前边界 | 使用建议 |
| --- | --- | --- |
| 资产提取公开档 | 公开版不含部分图片素材，相关视觉生成与一致性验收不可用；完整发布构建尚未闭合，已有 SHA256SUMS 存在失效路径 | 仅按公开文本/离线范围理解，先读 CAPABILITIES.md，不视作完整视觉发行包 |
| 知识转录索引 | 历史来源和独立验收未闭合 | 只隔离试用，勿用唯一生产资料库 |
| B 站转录 | README 与入口许可声明冲突未裁决 | 不据单份 README 认定整包 MIT 或可商用 |
| 抖音转录 | 历史安装说明引用的 requirements.lock 未随当前包提供 | 先核对现有依赖与 doctor，缺项保持阻塞 |
| UMH | 分发检查不等于接收者原生客户端验收；Claude 未验证 | 逐客户端检查接入、信任、写入与回读 |
| H3 | 规则审计与离线构建不能证明真实模型、视频渲染和反向核验已执行 | 单独记录模型请求与实际视频验收 |
| 所有产品 | 完整跨系统、多宿主、真实账号与模型链路尚无统一全部通过结论 | 按当前机器和具体工序做小样本验证 |

## 如何理解版本

版本号表示该目录的发布身份，不表示在线平台始终兼容，也不自动解决目录中的所有历史文档冲突。`catalog.json` 的来源版本用于追溯，不应被读成当前入口版本。分享时附上具体提交号与所用产品版本，避免只说“最新版”。

## 使用前的停止条件

真实依赖缺失、来源未授权、凭据不可用、原文或任务状态异常、模型费用超出范围、清单无法验证时，应停在对应工序，保留可恢复现场。不要生成占位产物、篡改状态或重算清单来伪造完成。
