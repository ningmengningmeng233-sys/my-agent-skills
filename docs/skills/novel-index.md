# 小说索引

> 小说资料 · 分段与检索 · **4.6.2** · [原始技能入口](../../小说索引_v4.6.2/SKILL.md)

为已有小说建立原文段文件与章节导航，支持检索、追更与库维护。适合需要按原文定位人物、事件和章节的用户。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：TXT / Markdown 小说、书名、作者和独立索引库。

输出：小说原文段、章节与全书索引，以及可用于后续检索的元数据。

## 开始之前

按 INSTALL.md / README_CN.md 准备 Python ≥ 3.10、uv 与索引接口配置。正文和索引库放在用户数据目录，原始文件另存备份。

安装时完整复制 `小说索引_v4.6.2/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 先对一本书的小样本切段，检查章节边界。
2. 构建段索引与书导航，抽查原文定位。
3. 检索时返回来源并回读，不把导航摘要当作完整正文。
4. 追更、改名、删除前备份原文段与元数据，按对应维护工序执行。

### 命令入口

在技能根目录执行，使用已准备好的对应运行环境。`<…>` 是必须替换的占位符；下面的业务命令不是安装完成后的自动动作，也不代表本轮已执行真实业务。

```powershell
uv run --with requests --with python-dotenv python scripts/split_segments.py "<源文件绝对路径>" --novel "小说名" --author "作者" --lib "<索引库绝对路径>"
# 切段检查后再构建段索引
uv run --with requests --with python-dotenv python scripts/build_segment_index.py "<索引库>/小说原文/<小说名>-<作者>/" --lib "<索引库>" --skip-existing
```

## 配置与数据位置

按包内配置模板填写索引接口、模型和数据目录，真实 .env 不提交仓库。书名与作者共同参与目录标识，避免同名书混用。

原文段位于 `小说原文/<小说名>-<作者>/`，相应索引、导航与元数据应整体备份。后续构建全书导航按原指南完成，不能只完成切段便声称全库建成。

## 边界与注意事项

- 面向小说资料，不替代非虚构知识库或音视频转录。
- 索引、摘要和外部风格卡不是正文证据；没有收录的作品不能假称已经读过。
- 更新应保护在用段；改名和删除需要同时照顾段文件与元数据，不能只手改目录。
- 外部模型建索引会产生成本并可能传输文本；缺外部风格能力时只能按实际功能说明。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| 路径或书名对不上 | 检查书名-作者目录、绝对库路径和文件编码。 |
| 追更结果不一致 | 保留旧段与状态，检查追更模式与来源边界，不先清空重切。 |
| 索引有结果但正文找不到 | 校对段文件与元数据，修复失效引用后再回答。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
