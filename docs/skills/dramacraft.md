# 小说转短剧

> 创作流程 · 大纲到分镜 · **1.5.5** · [原始技能入口](../../小说转短剧_v1.5.5/SKILL.md)

把小说材料与结构化大纲转为分集剧本，并输出质量报告。随包五个子技能可继续处理大纲、人物、美术、剧本与分镜。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：小说文本、outline.json、目标集数与每集时长、风格要求。

输出：结构化剧本及 Markdown / CSV / JSON / HTML；分镜子技能另产出分镜与投产提示词。

## 开始之前

按 INSTALL.md 准备 Python 依赖与模型网关配置。在技能根目录运行。外部模型需自备权限和预算，配置完成前先运行 doctor，不默认启用在线探测。

安装时完整复制 `小说转短剧_v1.5.5/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 先确认改编范围、集数、目标时长与角色/场景约束。
2. 用 novel-outline 形成大纲并审阅，再用 novel-script 落成剧本。
3. 需要时准备 novel-characters、novel-art，再交给 novel-storyboard。
4. 先试一集，查看时长与质量报告，人工确认剧情后扩大批次。

## 示例

可向已加载该技能的代理这样描述任务；请替换成自己的资料和范围：

> 将这份小说改为短剧，先只做 3 集大纲，单集目标 150 秒。列出取舍、角色和场景，不调用生图或视频服务。大纲确认后再生成第一集剧本并检查时长。

### 命令入口

在技能根目录执行，使用已准备好的对应运行环境。`<…>` 是必须替换的占位符；下面的业务命令不是安装完成后的自动动作，也不代表本轮已执行真实业务。

```powershell
python run_batch.py --doctor
# 已准备输入、配置与预算后，执行正式剧本生成
python run_batch.py --input "小说.txt" --outline "outline.json" --workdir workspace --target-seconds 150 --formats markdown csv json html
```

## 只验证已有剧本

已有结构化剧本时，可先做质量检查，避免重新调用生成模型：

```powershell
python run_batch.py --validate-only "script.json" --outline "outline.json"
```

`--assemble-only` 用于聚合满足缓存和版本要求的已有集数；不代表跳过质量门。doctor 默认检查与 `--probe-api` 的在线探测分开，后者需要明确允许实际请求。

## 边界与注意事项

- 父技能剧本导出不等于成片；分镜、美术出图、配音和视频生成是后续独立工序。
- 时长、说话人、资产对账等质量门用于发现确定性问题，不代替故事审美与人工验收。
- 不要靠改目标时长、绕过退出码或伪造报告把失败改成通过。
- 模型调用可能传出小说内容并产生费用；确认授权和预算，避免默认整本长批次。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| doctor 阻塞 | 按缺项修复网关、依赖或路径；不要用离线占位稿冒充模型生成。 |
| 集长不合格 | 检查实际台词量与节拍，修改剧本后重验。 |
| 上游资产不一致 | 回到大纲、角色或美术定义对齐，再生成下游产物。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
