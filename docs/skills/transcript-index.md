# 知识转录索引

> 转录资料 · 待独立核验 · **1.5.0** · [原始技能入口](../../知识转录索引_v1.5.0/SKILL.md)

为已有的本地 B 站转录文本构建索引、校对资料和检索视图。当前保持待独立核验，适合了解其限制后做隔离试用。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：本地 Obsidian/资料目录中的 B 站转录 TXT，文件名需包含 BV 号。

输出：索引库、校对版与向量库，实际可用性取决于本地模型和服务配置。

## 开始之前

先阅读 references/配置.md，明确 SRC_DIR。配置索引模型接口与本地检索模型，准备脚本要求的虚拟环境。STRICT_BILIBILI=1、ALLOW_SOURCE_WRITE=0、AUTO_TERM=0 是应核对的保护配置。

安装时完整复制 `知识转录索引_v1.5.0/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 复制少量已有转录到隔离数据目录，不直接操作唯一资料库。
2. 配置 SRC_DIR 与接口，先执行 --dry-run 检查计划。
3. 确认预算和写入范围后按原指南建库，抽查索引与原文一致。
4. 检索后回读来源上下文，记录真实依赖、错误和验收缺项。

### 命令入口

在技能根目录执行，使用已准备好的对应运行环境。`<…>` 是必须替换的占位符；下面的业务命令不是安装完成后的自动动作，也不代表本轮已执行真实业务。

```bash
bash build.sh --dry-run
```

## 目录保护

`SRC_DIR` 必须指向自己的资料目录；检查将生成的 `索引库/`、`校对版/`、`向量库/`。默认禁止回写源文，先备份术语表、配置与原文。

dry-run 只预览构建，不证明实际模型依赖或检索可用。正式尝试后仍需逐项记录结果，不能自动升级本包的待核验状态。

## 边界与注意事项

- 独立验收与历史来源尚未闭合；目录收录不是推荐生产使用或跨机器可用的证明。
- 它消费已有 B 站转录，不负责视频下载，也不是通用小说/PDF/笔记索引入口。
- 建索引可能调用付费接口；本地检索不等于整条流程零成本或固定秒数完成。
- 引用须核对原文件与上下文；不能将校对稿、检索片段或相似结果冒充逐字原文。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| 找不到模型或向量库 | 检查配置和本地依赖，按原指南重建，不编造空文件。 |
| 文件被过滤 | 检查文件类型、BV 命名与 STRICT_BILIBILI；勿直接关闭保护来扩大范围。 |
| 检索答案与原文不符 | 回读原文命中前后上下文，标出不确定项并保留失败样本。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
