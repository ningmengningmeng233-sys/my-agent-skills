# MiniMax H3 提示词

> 视频提示词 · 规则审计 · **7.4.6** · [原始技能入口](../../MiniMaxH3提示词_v7.4.6/SKILL.md)

把故事、分镜或参考图要求整理成 H3 视频提示词，并检查镜头、时长、台词、引用与模型能力是否对齐。适合准备生成任务、检查已有提示词。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：分镜、目标模型与生成模式、画风、时长、台词、参考图信息。

输出：按所选模式组织的提示词、规则审计结果与待补资料；实际视频由外部生成平台产出。

## 开始之前

完整保留技能目录。审计脚本需要 Python；生成平台账号、模型权限和参考图由使用者准备。H3、H3-Max、H3-Max-Turbo 的能力不能互相替代，以包内 `config/model-capabilities.json` 为准。

安装时完整复制 `MiniMaxH3提示词_v7.4.6/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 先说明目标模型、时长和输入类型：纯文本、首图、首尾帧或参考图。
2. 提供分镜与逐字台词；没有参考图时明确说明，不让代理编造图号。
3. 选择真人或 3D 风格，按入口规则确定提示词模式与语言。
4. 运行审计，处理错误后再提交外部平台；保留原提示词、报告与生成记录。

## 提交平台前再核对

确认提示词所用输入模式与平台真实选择一致，参考图实际上传顺序与 `<Picture N>` 一致，逐字台词未丢失，时长在目标模型能力范围。保留审计报告中的未运行项。

生成后应核对实际镜头、人物、台词与音画；生成前的审计不能替代这一环。

## 边界与注意事项

- 提示词审计通过不能证明模型已经生成，也不能证明成片符合要求。
- 不支持的模型、时长或参考组合应停止，不能靠改标签绕过能力表。
- 首个 [Shot 1] 不带时间戳，后续镜头按规则写 At MM:SS.mmm；参考图先定义再引用。
- 英文模式按实际接口选择；不能把所有模式一律改成英文，也不能混用真人与 3D 风格契约。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| 参考图引用报错 | 检查图号定义、顺序和实际上传的图片是否一致。 |
| 审计有警告 | 先读警告含义；report 会报告警告，不等于没有警告。严格任务按原指南选择失败策略。 |
| 平台生成结果不对 | 保留平台参数和实际产物，分别检查提示词规则与模型执行效果。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
