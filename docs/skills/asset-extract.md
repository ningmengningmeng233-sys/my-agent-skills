# 资产提取

> 文本资产 · 公开能力受限 · **2.17.0-rc.7** · [原始技能入口](../../资产提取_v2.17.0-rc.7/SKILL.md)

从小说中提取人物、场景、道具与服饰等资产事实，生成登记、关系、提示词和过程账本，帮助保持跨章节连续性。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：TXT / Markdown / DOCX / EPUB 文本，或明确排序的多文件输入。

输出：文本资产登记、索引、提示词与过程记录；不包含被排除的受限风格图片。

## 开始之前

先阅读 CAPABILITIES.md。公开档排除 32 张受限风格/来源图，相关视觉生成与一致性验收不可用。按 QUICKSTART.md 配置文本模型与运行环境；Windows 使用配套 .bat 入口或准备 Bash。

安装时完整复制 `资产提取_v2.17.0-rc.7/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 指定输入顺序、资料范围与目标资产库；保留原文备份。
2. 先 dry-run 核对步骤，再仅对小样本执行文本资产工序。
3. 逐项回读来源，检查稳定 ID、关系、服饰状态与连续性冲突。
4. 仅按已完成工序交付，保留 .process 和过程数据库；视觉能力缺口明确标注。

## 公开档与发布状态

本页的 dry-run 是参数和步骤预览；即使预览正常，也不能推导完整构建、模型调用或签发已通过。Windows 可阅读 QUICKSTART 的 `run_pipeline.bat` 用法。

真实资产库应独立保存，包含规范化输入、过程账本与 `.process` 状态。遇到完整清单或视觉资源缺项，应停止在对应边界；不要混入私人受限素材再将结果公开。

## 边界与注意事项

- PDF 不在本入口支持范围，需在其他工具中转换并检查后再导入。
- 公开档文本/离线能力不能代表私有视觉能力；不能补几张替代图便宣称等效。
- 当前完整发布构建尚未闭合，既有 SHA256SUMS 有失效路径；不能宣称完整分发签发通过。
- 文本模型调用有费用与隐私影响；配置放在指定本地位置，不提交密钥或私人原稿。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| 提示缺少风格图片 | 先确认是否受公开档限制；不要索取或恢复无权分享的素材。 |
| 校验清单失败 | 保留错误与当前版本，按缺项定位；不要直接改哈希或断言让它通过。 |
| 人物或道具串联错误 | 回读源文与过程记录，修复对应资产工序并重验关联项。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
