# B 站转录

> 音视频 · 字幕与识别 · **5.5.5** · [原始技能入口](../../B站转录_v5.5.5/SKILL.md)

将 B 站视频整理为可归档转录，优先使用可用字幕，再按配置回退语音识别。支持分 P、收藏夹批次与摘要补齐。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：可访问的视频链接（含可选 ?p=N）或配置后的收藏夹。

输出：转录 TXT、原始记录、归档数据库与摘要状态。

## 开始之前

Python ≥ 3.10、FFmpeg/FFprobe，以及包内要求的下载/识别依赖。Windows 的 .sh 入口需要 Git Bash 等 Bash 环境。识别模型首次下载可能占用数百 MB 至数 GB，按用途准备账号会话。

安装时完整复制 `B站转录_v5.5.5/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 按锁文件准备独立环境，再运行 doctor 检查。
2. 先转录一个短视频或明确的单 P，回读字幕/识别结果。
3. 按 .env.example 配置个人归档目录；批量收藏夹需明确 FAV_MEDIA_ID。
4. 确认单条成功后再小批量处理；摘要是后续独立状态，不和下载成功混淆。

## 配置与批量范围

| 配置 / 选择 | 使用前确认 |
| --- | --- |
| BILI_ARCHIVE_DIR | 指向自己的资料目录，避免把真实转录留在代码仓库 |
| FAV_MEDIA_ID | 只有处理收藏夹时才配置对应对象 |
| EXPAND_PAGES | 默认不展开全部分 P；打开前检查任务量 |
| 摘要接口与识别模型 | 按 .env.example 配置，分别验证，不混为转录成功 |

在 Bash 终端运行 .sh 入口；上方创建虚拟环境与依赖安装示例在 Windows PowerShell 执行。不要在同一个未经确认的整段粘贴中自动完成下载与真实业务。

## 边界与注意事项

- 多 P 收藏夹默认不代表全部展开；是否启用 EXPAND_PAGES 需明确，避免成倍增加任务。
- 412 / -352 等风控或认证失败应暂停处理，不靠高频重试绕过。
- ASR、OCR 与摘要均可能出错；时间戳和文件存在不能证明内容准确。
- 只处理有权访问和使用的内容。README 与入口许可表述存在冲突，不能据此认定全包 MIT。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| doctor 不通过 | 依次处理可执行程序、模型、路径和权限，保留实际诊断。 |
| 抓错分 P | 核对链接的 p 参数和数据库中的 BV + page，避免只按 BV 判断。 |
| 只有转录没有摘要 | 查看摘要服务配置与待补状态，不把原文重跑当作补摘要。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
