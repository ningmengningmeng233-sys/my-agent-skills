# Style Library — 国漫 3D（唯一风格，严格约束）

## 风格（唯一）

| 文件 | 风格 | 官方风格词 |
|---|---|---|
| `guoman-3d.md` | 国漫 3D（中国 3D 动画电影质感） | `3D CG` |

**本技能包画风严格锁定国漫 3D**：不设切换机制、不建其他风格库、不混合
风格。所有产出提示词必须使用本风格库前缀。

## 机制

- 风格前缀在每份提示词的 [Shot 1] 开头逐字粘贴一次，全片一致；后续镜头
  不重复
- 前缀 11 轴（Style/Lighting/Color/Camera/Skin&material/Acting/Physics/
  Composition/Continuity/Technical/Audio）全正向声明，不写裸否定列表
- 单场景可 override 单行，但同一字段多处 override 时应升格回前缀
- 官方风格词对齐：`3D CG`（速查表 7 类之一）

## 注意

- 若项目方向变更需新增风格，须先经用户拍板——不得自行添加

## 新增风格流程（用户拍板后执行）

1. 复制本文件为 `styles/新风格名.md`
2. 按 11 轴空模板填写（见下）
3. 官方风格词挂靠（速查表 7 类之一：Cinematic/live-action/2D-animated/
   3D CG/claymation/watercolor/vintage film）
4. 排他声明：负向约束转译为正面排他（如「非 3D CG、非真人实拍」）
5. 更新「与基准差异对照表」（对比当前国漫 3D 基准）
6. 画风层精简原则：控制在 ~450 字（每份提示词重复粘贴的成本）
