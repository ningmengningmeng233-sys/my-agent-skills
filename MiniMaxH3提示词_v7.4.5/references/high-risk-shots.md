# High-Risk Shot Library — 高危镜头库（产出前检查）

> 常见 AI 视频高危镜头。产出提示词**之前**先对照本库检查输入分镜；
> 命中 → 向用户汇报命中项 + 处理建议，等用户确认修改方向后再产出。
> 绝不自动删改（用户裁决权），但必须给出合理建议。

## 使用流程

1. 读输入分镜，对照下表逐项检查
2. 命中任一项 → 停下，汇报：「镜头 N 命中高危项 #X —— 风险：……」
3. 给 2-3 个处理建议（保持原样 / 改写方案 / 后期处理），说明代价
4. 等用户选择 → 按选择产出

**完成条件**：每个命中项用户都已明确选择方向（「都行/随便」按交互纪律
当没听懂重解释）；未命中则本步完成于全部镜头检查完毕。

## 高危清单（v1 — 14 项）

| # | 高危镜头 | 识别特征（在分镜输入里看） | 为什么难 | 处理建议（给用户的选项） |
|---|---|---|---|---|
| 1 | **长字幕/画面文字** | 字幕、招牌、书页文字、任何 ≥6 字且需清晰的文字 | 字形漂移、加字漏字（官方亦提示文字渲染不可靠） | A 缩短为关键词 / B 改后期加字 / C 保持原样（接受风险） |
| 2 | **纯黑/纯白长时间画面** | 黑屏、白屏、无内容段 >2s | 模型在无内容段加噪、闪烁、内容漂移 | A 改极暗场景+微光保留氛围 / B 后期做黑场 / C 保持原样 |
| 3 | **镜像/水面/刀面反射** | 镜子、水面倒影、反光刀面 | 反射体与反射内容同框时场景地理崩坏 | A 反射单独成镜、切走再切回 / B 避免反射同框 / C 保持原样 |
| 4 | **同一角色多实例** | 克隆、镜中自我、时间双重、双胞胎同框 | 身份追踪假设一身份一体，实例互相污染 | A 每实例独立命名+独立锚点、优先切镜 / B 拆分镜头 / C 保持原样 |
| 5 | **人群/多人同框** | 街市、人群、聚会、战场，>3 可辨识个体 | 人数漂移（三人变百人或反之） | A 人群环境化+计数句+≤3 追踪 / B 单人特写代替 / C 保持原样 |
| 6 | **快速闪切/频闪** | 每秒 >1 切、频闪、快速跳切 | 闪烁、帧间漂移、观感不适 | A 减切点、每镜 ≥1s、双反差 / B 合并镜头 / C 保持原样 |
| 7 | **长时间静止+长对白** | 单镜 >4s 静止、连续念白 >10s | 口型漂移、画面死 | A 插微动作/微生命、分镜 / B 压缩台词 / C 保持原样 |
| 8 | **超远景小脸** | 远景人物脸部仅占画面 <3% | 微表情丢失、脸崩 | A 给脸部特写机会 / B 描述锁五官轮廓 / C 保持原样 |
| 9 | **大幅旋转/翻滚镜头** | Roll 大角度、360° 旋转、翻滚运镜 | 几何扭曲、地面翻转崩坏 | A 减小角度（≤90°）/ B 分镜 / C 保持原样 |
| 10 | **手部精细特写** | 手指计数、系绳、拆解小件、握手特写 | 手指畸形（AI 通病） | A 避开细指特写（中景带手）+ 屏幕配额规约（配额 10%–18% 且锁定下象限）/ B 简化动作描述 / C 保持原样 |
| 11 | **激烈打斗/高速运动** | 连击、追逐、多动作同拍 | 物理混乱、肢体错位 | A 一镜一动作、ALREADY 开题、非对称速度比锁定（避免动作平均化）/ B 拆镜 / C 保持原样 |
| 12 | **烟雾/火/水花/碎片粒子** | 爆炸、火焰、水花、碎片四散 | 形态漂移（烟变实体、火穿身） | A 量化+作用到环境人物 / B 简化特效 / C 保持原样 |
| 13 | **变装/瞬移/状态跳变** | 一秒变装、闪现、时间跳跃、无过渡变形 | 状态跳变无中点则瞬切或模糊 | A 显式中点过渡 / B 拆镜/桥接 / C 保持原样 |
| 14 | **极端天气** | 暴雨、暴雪、浓雾、沙尘 | 像背景贴层，不作用于世界 | A 作用到人物/地面/光/声 / B 减强度 / C 保持原样 |

## 构建安全场景（Build-safe — 来源：地狱 Rewrite Playbook）

高危库是「命中后问」；构建安全是「构建时避开」——描述高风险内容时
从构建上就换成安全且更电影化的等价物：

| 避免 | 构建为 |
|---|---|
| 人群恐慌/废墟下奔逃 | 空城/撤离后的街道；一名孤独身影做尺度参照 |
| 武器向建筑/人群射击 | 能量对峙、扫掠探照灯、充能光晕、无枪口焰的冲击波 |
| 生物互相撕咬/血腥 | 缠斗/对峙/擦身/能量碰撞——战斗受控 |
| 破坏波及人群 | 无人地形破坏（冰川/沙漠/废墟/公海/撤离区）；角色「反应」坍塌而非「受害」 |

**受控即物理**：给战斗一个受控规则（「战斗保持在水面——破浪、下潜、
缠斗、没入，绝不离水」；「boss 尺度锁定约 2.5 人高，不是怪兽级」）——
同一条款既保安全又接地物理、阻止尺度升级。
**安全基准场景**（跑偏时拉回）：一个原创生物（无版权）+ 泛化纪念堂/
竞技场地点 + 白天 + 无武器 + 表现性动作（起身、咆哮、展翅）——表现
而非暴力。

**漂移容错 vs 惩罚性场景（来源：higgsfield-cinema — 构建时避开，与上表
14 项「命中后问」互补）**：
- **容错**（漂移读作视差，不出戏）：圆形竞技场 / 模糊废墟 / 重复纹理
  （森林、沙丘、柱廊）/ 雾尘烟环境
- **惩罚**（漂移一眼暴露）：地标建筑 / 强视线几何 / 带文字招牌的公共
  空间 / 连续反射面
- 动作戏按此选场景——**构建时选容错场景，不等失败再修**

## 注意

- 命中多项时逐项汇报，建议各自独立，用户可逐项裁决
- 用户选择「保持原样」时不争论，照写并在输出标注「高风险保留」
- 本库随实测扩展（新翻车镜头记进来），版本 v1

## 官方避坑与缺陷防御规约（Failure Guards 扩展）
> 完整规范见 `references/failure-guards.md`。

- **塑料脸防御**：严禁 `airbrushed, porcelain, waxy`；强制写入自然毛孔、微小瑕疵与哑光质感。文学颜色词（脸红/发白）转译为微血管生理反应。
- **多参考图稀释防线**：单片段参考图严格 ≤3 张；强制在【空间基准】写入各通道单向排他防火墙，阻断背景石壁/青苔材质侵入面部。
- **手部安全象限**：手部互动必须有实体支撑（握持刀柄/器皿），画面占比控制在 10%~18% 且锁定下半象限，严禁悬空比划。
- **群演克隆防御**：强制保留开场句“群演禁止出现一模一样长相的人物”，拉开年龄体态反差。
