# Shot Structure — 镜头结构设计（动作-反应变体 + 出彩配比 + 场次检查）

> 来源：山田大师《镜头设计逻辑》《导演核心方法论》。镜头设计层（叙事结构），
> 与 performance-physics（微观表演链）互补。输出中文。

## 1. 动作-反应组合变体（12 种 — 镜头设计的基本单元）

| 变体 | 结构 | 效果 | 适用 |
|---|---|---|---|
| 标准型 | 动作→反应 | 因果直接 | 常规叙事（主力） |
| 反应前置型 | 反应→动作 | 悬念：先看结果再看原因，中间几秒最强好奇心窗口 | 悬疑、揭示 |
| 动作并置型 | 动作A→动作B→动作C→总反应 | 累积压力，反应重量被叠加放大 | 多线汇合 |
| 反应省略型 | 动作→（无反应）→下一场景 | 留白：观众脑中补出反应，比画面更强烈；悬挂感 | 关键台词后 |
| 动作隐藏型 | （声音动作）→视觉反应 | 声画分离，画外枪声→表情；声音动作更恐怖 | 惊悚、恐怖 |
| 反应延迟型 | 动作→日常→日常→反应 | 真实感：冲击太大需要时间消化 | 沉重事件后 |
| 同步型 | 动作与反应同画面（长镜） | 观众自选看谁，信息密度高 | 群戏、长镜 |
| 反应链型 | 动作→反应A→反应B→反应C | 事件辐射范围、不同角色不同态度 | 消息传递 |
| 重复动作渐变型 | 动作→反应→同一动作微变→不同反应 | 重复变奏展示时间推移与情绪累积 | 三次按门铃式 |
| 对位型 | 画面动作A + 声音动作B → 复合反应 | 表面与内在矛盾 | 内心戏 |
| 省略动作型 | 反应→反应→反应（动作从未出现） | 「那件事」的恐怖超越画面承载 | 恐怖片经典 |
| 链式衔接型 | 动作A→反应A兼动作B→反应B兼动作C→… | 叙事惯性：多米诺连锁推进，镜头组不断裂 | 群戏、连续推进 |

**标注纪律**：关键叙事节点标注本镜在动作-反应结构中的角色（「展示 A 的决定（动作），为下镜 B 的反应铺垫」/「刻意省略反应，硬切制造悬挂」）。

**70/30 法则**：约 70-85% 镜头用标准模式撑骨架，15-30% 用出彩模式制造记忆点。

## 1b. 叙事目的提取法（来源：山田导演核心方法论）

**叙事目的两层**：
- 结构层（叙事功能）：交代信息 / 建立角色 / 推进情节（冲突/升级/翻转）/
  埋设回扣伏笔 / 呈现主题 / 首尾呼应 / 情绪转场呼吸点
- 导演执行层（视听意图）：制造不安/压迫/窒息、控制视线、营造氛围、
  制造时间感、视觉隐喻、节奏标记、建立或打破预期

**四遍提取法**：
1. 结构性通读：标每场核心事件与价值转变（McKee：场始末核心价值是否不同）
2. 功能标注：逐场标结构层目的，每场 1-3 个；找不到目的的戏应删/并
3. 导演意图叠加：「我要用什么视听手段让这个结构功能生效？」
4. 合并为叙事目的句：一句话同时覆盖「做什么+为什么」，具体到视听手段，
   点明隐喻功能，客观不煽情

**自检 5 项**：每场至少一个目的？全片目的均匀分布？伏笔/回扣成对？
主题通过视听动作而非台词传达？连续三场高强度后有无呼吸点？

## 2. 出彩镜头六手法（按使用频率）

1. **视觉隐喻**（约 38%）：具象画面传达抽象含义——「不是'角色被困住'，而是'空墙面上只有光影'」；通常是标准动作的非标准反应
2. **视角反转/揭示**（约 22%）：突然改变观众对已知信息的理解——常用反应前置型或省略动作型
3. **结构呼应/闭环**（约 12%）：与全片另一位置精确呼应
4. **感官对比/并置**（约 9%）：反差元素同画面或相邻镜头
5. **信息延迟/留白**（约 9%）：刻意不给信息，悬挂张力（反应省略型典型用法）
6. **视觉奇观/升华**（约 3-4%）：纯粹视觉冲击，通常近结尾

**使用规律**：分散全片（开头建立气质、结尾升华略多）；82% 出彩镜头前后是标准镜头；连续出彩不超 2 个（超了就不出彩了）；出彩镜头平均稍长（~4.9s vs 4.1s）。

**选择检查**：每场至少一个出彩设计？出彩是否在叙事目的最重的镜头上？出彩是否有叙事理由（「好看」不是理由，「用俯拍让角色看起来被困住」才是）？连续出彩是否超 2 个？

## 3. 场次 Double Check（三层，每场拆解后必过）

**第一层：导演影调一致性**
- 镜头语言与定调匹配？（国漫 3D 固定 + 项目基调）
- 意象体系在需要处出现？

**第二层：本段节奏设计**
- 切镜频率、景别选择、时长分配与节奏规划一致？
- 与前后场景的节奏形成有意义对比或过渡？

**第三层：标准与出彩配比**
- 大多数镜头简洁可靠不抢戏（标准）；每场至少一个记忆点（出彩）

## 4. 连续性控制（来源：地狱 continuity-control）

**八类连续性**：身份（脸/体型/发型核心轮廓/道具几何——引用批准资产 ID
与版本）/ 状态（服装层级/伤势/湿度/污渍/携带物/门的开合/道具损坏——
保持或有明确变化事件）/ 空间（场景分区/出入口/唯一家具/相对位置——换
机位不等于重建房间）/ 轴线与屏幕方向 / 动作（上镜手脚道具动作阶段=
下镜 open state）/ 光线与曝光（光源位置/色温/天气/互动光——换机位可改
明暗面但窗光不瞬移）/ 天气环境 / 声音（底床/持续声/声音桥有 continuity
key——画面切换不自动重置同空间声音）。

**变化账本**（每个变化记录）：之前状态 → 触发事件 → 本镜可见变化 →
之后状态 → 从哪镜生效 → 是否需要新资产状态版本。未记录变化的字段默认
保持——不让提示词用新形容词悄悄改连续性。

**镜头首尾卡**：open state（位置/朝向/姿态/视线/表情/手脚道具接触/
服装伤势天气破坏/相机起始关系/持续声音）与 close state（同字段尾帧）；
下一镜不直接连续时标记时间跳跃/地点跳跃/省略动作。
**禁止只写「动作连续」（来源：seedance2-chinese-guoman）**：跨镜/跨片段
衔接必须写出**具体衔接姿态**——「从上一段结束姿态（右手持书、视线锁
门）进入本镜」——不得用「动作连续」「保持一致」等省略写法替代；同一
动作跨镜保持起止姿态、速度、方向、持物手、受力关系与环境状态一致。

**场次规则**：同场直接连续=严格继承 close state 只允许 changes_here；
同场省略时间=记录省略时长与允许变化（重大伤势/换装/道具转移不得无说明
发生）；跨场次=允许时间地点服装环境改变但新 scene open state 必须有
来源；梦境/幻觉/闪回=作为明确场次类型登记（不由对白自动触发），返回
现实的接点单独写。

**豁免**：可接受缺陷记录（问题/影响/原因/批准人/适用范围/后期修复）——
口头「没关系」不能让镜头跳过质量门。

## 4b. 多镜头序列契约（来源：地狱 multi-shot-sequences）

**序列总契约**（先写）：总时长（=各镜头可读时间+切点转场预算+落点停留；
五镜塞五秒=每段一秒不可读→减少镜头数，不要求「快速闪过每个细节清晰」）/
精确镜头数量/序列目标/每镜叙事功能/切点规则/全序列必须保持的资产与
连续性/最终落点。

**切点类型 5 种**：硬切（写准确事件或时间）/ 动作匹配切（上镜动作阶段
与下镜开始阶段匹配——抬手在接触前切到手部特写继续接触）/ 视线匹配切
（上镜视线方向→下镜目标，目标不出现于错误方向）/ 声音桥（记录来自哪
镜/何时起止/空间是否改变）/ 遮挡切与甩镜切（需明确遮挡物或运动方向，
过度依赖生成不稳定中间帧）。

**蒙太奇 5 组织逻辑**（选一，不随机美图）：时间递进（同对象状态逐步
变化）/ 空间并列（不同地点同时关联事件）/ 动作并列（相似动作成节奏）/
因果压缩（准备/过程/结果关键片段）/ 情绪累积（细节逐步加压）。规则：
限定镜头数；每段时长可识别；身份状态按时间推进；每段构图有差异但服从
共同视觉母题；声音用共同底床/节奏音/明确静默连接；最终镜头提供落点。

**对话序列**：建立镜头定轴线；正反打 A 看右 B 看左；每镜只允许当前
说话者口型（反应镜可画外声音）；过肩明确前景肩归属；环境底床跨切持续。

**常见镜头组合模板（来源：guoman storyboard-template — 直接套用骨架）**：
- 对话场景（两人）：全景建立 → A 近景（对白）→ B 近景（对白）→ 双人
  中景（反应）→ 拉远收束
- 多人（3+）：远景入场 → 前景近景（对白）→ 切中景（对白）→ 环境特写
  过渡 → 全员中景收束
- 单人独白：环境建立 → 中景 → 近景推进 → 特写（情绪）→ 拉回中景

## 5. AI 短剧分支（来源：山田类型-G 短剧总纲 — 用户项目为 AI 短剧）

### 5.1 时长层级硬约束
一集 120-150s / 场景 ≤15s / **分镜（镜头级）1.5-6s（一场景 4-8 镜）**——
块级（单次生成片段）有效范围 4—10 秒（config/duration-policy.json；模型能力上限 15 秒是
另一概念），见 references/duration-ledger.md——两口径按层级区分不混用 /
每分镜 ≤3 人（AI 错误率控制）；6s 镜头建议拆为 2×3s 降低生成错误率。

### 5.2 七条视听核心法则
1. **一镜多能**：长片「建立→对话→反应」3 镜序列，短剧压缩为 1 个复合镜
2. **情绪前置**：情绪必须在第 1 个镜头建立，无铺垫时间
3. **冲突密度最大化**：每 15-20s 至少一个情绪转折点
4. **剪辑即叙事**：2s 快切=节奏本身，1.5s 碎片=情绪本身
5. **视觉信息压缩**：前景/中景/背景三层同时承载不同信息
6. **重复即强化**：同一构图/动作的变奏重复（叙事锚点）
7. **AI 生成友好**：单镜信息量可控，避免复杂群体调度、大幅度物理运动

### 5.3 钩子 3 秒法则（扩展：钩子科学 — 来源：jineng 11-social-hook）
- 开场 3 秒建立：谁 + 在哪 + 发生了什么异常（不用大全景建立镜开场）
- **五大注意力触发器**（开场首秒至少命中一个）：模式中断（常态被打破）/
  好奇心间隙（信息缺口，观众想知道答案）/ 情感触发（共情/威胁/渴望）/
  对比原则（大小/明暗/静动反差）/ 运动检测（画面里有动作发生）
- **2 秒钩子四段**（H3 适配：首秒宽镜内完成抓取+好奇构建，[1s-2s] 完成
  动量+承诺时刻）：①注意力抓取（视觉冲击或异常）②好奇心构建（信息
  缺口成形）③动量（节奏推进）④承诺时刻（告诉观众接下来发生什么）
- **钩子承诺 5 秒内兑现**：钩子给出的悬念必须在 5 秒内兑现或升级——
  防虚假承诺陷阱
- **好奇心阶梯留存轴**：2-5s 确认钩子成立 / 5-10s 引出新问题 / 10-15s
  给部分答案 / 15-20s 大揭示或转折 / 20-30s 收尾留新悬念——按集时长
  规划叙事任务分配
- **钩子模式分类**（按机制选，不随机美图）：视觉冲击（奇观/特写/异常
  构图）/ 好奇心（问题开场/信息延迟）/ 情感（威胁逼近/渴望物出现）/
  模式中断（日常被打破）/ 直接对话（台词开场向观众说话）
- 结尾 3 秒制造「不看下一集会死」的悬念（反转/伏笔/情绪定格）

### 5.4 快切法则
- 画面中心法则：关键视觉信息始终在画面正中
- 每镜只传递一个信息单位（一个动作/一句台词/一个情绪）
- 强拍（冲突/反转）用升格慢动作，弱拍（反应/过渡）用正常速度快切
- 景别跳切制造节奏：特写→全景→特写

### 5.5 G2 悬疑反转配方（用户项目类型）
- **信息控制是核心武器**：限制视角（观众只见角色所见）；关键线索特写
  物理化（照片/文件/物件）
- **信息不对称公式**：观众知道 A → 角色以为 B → 反转揭示 C
- **构图**：对称空间中出现不对称=理性裂缝；门缝/镜面/倒影构图（遮挡暗示）
- **光线/色调**（在国漫 3D 光影行内调整）：低照度+硬光比；冷色去饱和
  基调；关键线索单点光聚焦
- **剪辑节奏**：铺垫段 2-3s 中速；接近真相切镜加速（每镜 ≤2s）；反转
  瞬间 1.5s 快切×3 + 1 个 3s 定格
- **声音**：环境音低频持续（不安感）；反转瞬间声音骤停 0.5s；线索配
  「滴答」式音效
- **反转时刻镜头三件套**：推镜逼近 → 面部特写 → 闪回碎片快切（3-5 个
  1.5s）
- **伏笔**：前 1-2 镜埋设（越不起眼越有效）；每集结尾留钩

## 6. 单调审计与离场行（来源：higgsfield-shotlist-director）

- **单调审计**：连续 3 镜不得同景别+同运镜（特写推近→特写推近→特写
  推近 = 单调）——检查产出序列
- **离场行**：上镜头离开者记录退出侧+最后状态（「沈昭从画左离场，最后
  状态：右手握书、视线锁门」）——重入场必须合法（从退出侧回或显式
  转场）
- **节奏预算**：总时长÷4-6s≈镜头数；留一个 6-8s 英雄定格；所有时长
  精确加总
- **「别切碎悲伤」**（密度判断）：同阵容/同地点/同一情绪单元/≤15s 才
  合并成一镜；地点切换/阵容变化/机位变更/表演弧线 → 拆分
- **升级构建（来源：官方中文版示例「严格」段）**：特效/状态/情绪跨拍
  增强序列写显式递增锁——「效果在节拍 2 明显强于节拍 1，节拍 3 达到
  峰值」——写数字/阶段对比，不用「更亮/更强」无参照形容词；含「绝不
  回退」方向的否定式禁止
  **触发判定（2026-08-16 拷问补）**：只锁「同一元素跨拍可见增强」
  （特效更亮/伤势更重/速度更快——分镜有「越来越/逐渐」或明确递进
  阶段）；普通表演层次变化（表情/语气递进）不算，不套用本锁

## 7. 节奏要点（导演核心方法论提炼）

- **克制 ≠ 匀速**：节奏陷阱——「克制」是选择性放慢，不是全程平均；全程匀速 = 无节奏
- 双轨节奏：叙事节奏（事件推进）与情绪节奏（观众感受）可以错位
- 场景级节奏标注：本场快/慢/起伏，与前后场的对比设计
- 全片节奏波浪图：高潮位置分配（开头建气质、中段转折、结尾升华）

## 8. 好莱坞工业级原子节拍切片器管线 (Hollywood Beat Splitter Engine)

> 解决用户直接输入 300~1000 字长篇小说、复杂剧本时，直接生成导致的“动作快进压缩、时序混乱、肢体抽搐崩溃”问题。在进入底层 H3 Prompt 编译前，强制执行两阶段解耦流。

### 8.1 阶段一：原子动词切片法则（3~6 秒 / 单核心动作）
长文本严禁单镜吞吐，必须在内部先解构为标准化 **Shot List（原子镜头序列）**。每个切片必须命中且仅命中一个主叙事节拍（Narrative Beat）：

```
[原始剧本/长文本输入]
       │
       ▼ (Beat Splitter 切片引擎)
  ├─ Beat 1: Establish Beat (起势与环境锚定) ── 景别：中景/全景 ── 3~4 秒
  ├─ Beat 2: Action Climax (动力学爆发与接触) ── 景别：特写/紧凑中景 ── 2~3 秒
  └─ Beat 3: Physical Consequence (因果余波与反应) ── 景别：反应近景 ── 3~5 秒
```

- **时长黄金切割**：单镜严格压在 **2.5s ~ 5.0s**（低于 2s 模型演不完，高于 6s 物理漂移率剧增）。
- **动词原子化断言**：一个镜头只保留一个承重主谓宾（如“拔剑”与“刺出”强制分镜，绝不写“拔剑后顺势前冲刺穿敌人”）。

## 9. 官方单向编译时长账本（Duration Ledger 规约）
> 完整规范见 `references/duration-ledger.md`。

1. **核算公式**：$\text{Shot Duration} = \text{round}(\frac{\text{台词字数}}{\text{语速档位}}) + T_{\text{动作反应预留}} + T_{\text{首尾缓冲}}$。
2. **语速档位**：缓速档（权谋/深情/威慑，3.0~3.5字/s）、标准档（日常叙事，4.0~4.5字/s）、急速档（激烈争吵/战斗，5.5~6.0字/s）。
3. **Clip Group 15s 装箱**：单次生成硬上限 15s。同空间、同资产、因果承接的相邻原子节拍装入同一 Clip Group，超过 15s 必须在自然换气点切分。
