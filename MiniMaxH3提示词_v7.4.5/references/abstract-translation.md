# Abstract → Concrete Translation Library（抽象→具象翻译库）

> 来源：山田大师《抽象具象化翻译库》（摘录+国漫 3D 适配）。

## 1. 识别规则（一句话）

**摄影机拍得到吗？拍不到就翻译。**

| 类别 | 特征 | 典型词 |
|---|---|---|
| 情绪名词 | 不可见内心状态 | 恐慌、愤怒、喜悦、悲伤、焦虑、尴尬 |
| 心理动词 | 认知过程无外部动作 | 意识到、觉得、感到、想起、理解 |
| 抽象比喻动词 | 比喻代替动作 | 炸开、弥漫、涌起、笼罩、凝固、蔓延、沸腾 |
| 氛围虚写 | 对空气/气氛的形容词 | 气氛紧张、空气安静、降至冰点 |

**例外（正常视听语言，不翻译）**：特效描述（画面扭曲/时间倒流）、内心
独白/旁白（OS）、音效/配乐指示、字幕/文字画面。

## 2. 翻译决策树（三步）

```
第1步 找主体：抽象词是谁的状态？
   ├─ 单人 → 单人身体反应（表情/肢体/行为）
   ├─ 一群人 → 群像连锁动作（A撞B、B摔C，多米诺传导）
   └─ 环境/空间 → 环境物件被波及（水面、门、光、物件状态）

第2步 定强度：
   ├─ 轻 → 微表情+小动作（手指、眼神、嘴角、呼吸）
   ├─ 中 → 明显肢体动作（站起、转身、抓握）
   └─ 重 → 破坏性/连锁（撞翻、摔倒、砸落）

第3步 选载体：
   ├─ 表情 → 特写（眼神、嘴角、瞳孔、眉头）
   ├─ 肢体 → 中近景（手、脚、肩、姿态）
   ├─ 行为 → 全景（后果：撞翻东西、摔门）
   └─ 环境 → 空镜/物件特写（水面晃动、门被撞开）
```

**黄金规则：动作必须带因果关系。**「第一个人撞翻第二个人」比「人群慌乱」
高级——观众看懂恐慌怎么从一个人传导到另一个人。抽象词翻译后至少形成
一个动作链，不是一个孤立动作。

## 3. 精选翻译示例（国漫 3D 适配）

| 抽象原文 | 具象化翻译 | 载体 |
|---|---|---|
| 他紧张 | 他敲桌面的手指越来越快，视线在门口和手表间来回，三次抬手欲言又止 | 小动作 |
| 他怒了 | 指节捏得发白，茶杯摔在桌上，椅子被带翻在地 | 破坏性 |
| 她悲伤 | 手在杯沿停住，一滴泪落进杯中，她低头看着水面没有动 | 定格 |
| 她喜悦 | 嘴角先翘起，眼睛跟着弯起，然后笑出声，转身抱住旁边的人 | 表情递进 |
| 他恐惧 | 瞳孔放大特写，后退半步撞到墙，手撑桌沿指节发白 | 特写+肢体 |
| 他绝望 | 手从门把手上慢慢松开，身体顺着门滑坐下去，头垂下来 | 身体下沉 |
| 尴尬 | 视线移开，手摸了摸后颈，干笑两声，脚步往旁边挪了半步 | 回避 |
| 惊讶 | 手里的杯子停在半空，嘴微张，眨了一下眼才回过神 | 定格式 |
| 犹豫 | 手伸向门把手又缩回，来回踱两步，最终停在原地 | 反复试探 |
| 疲惫 | 进门先靠在门板上，闭眼几秒，剑从手里滑落在地 | 身体塌陷 |
| 期待 | 一直望着门口方向，听见脚步声身体前倾，又立刻坐直假装没事 | 前倾-回缩 |
| 释然 | 肩膀慢慢塌下来，长长呼出一口气，嘴角浮起一点弧度 | 松弛过程 |
| 恐慌炸开（群像） | 第一个人猛地转身撞翻身后的人，第二个人脚下打滑摔倒，第三个人撞到桌子，杯盏哗啦滚落摔碎 | 多米诺 |
| 欢呼沸腾（群像） | 第一个人站起来鼓掌，第二个人跟着起立，几秒内全场起立，帽子抛向空中 | 传染 |
| 气氛紧张（环境） | 杯中水面微微晃动，门缝的光被一只人影挡住又移开，无人说话但呼吸声清晰 | 物件+空镜 |
| 威胁逼近（环境） | 灯笼的光被巨大的影子逐盏遮住，脚步声由远及近，门闩轻轻颤动 | 光+声 |

## 4. AI 常见翻车写法修正对照

| 翻车写法 | 修正 |
|---|---|
| 他惊讶地抬头 | 他手里的杯子停在半空，嘴微张，眨了一下眼才回过神，然后抬头 |
| 气氛很紧张 | 杯中水面微微晃动，无人说话，呼吸声清晰可闻 |
| 人群慌乱 | 第一个人撞翻身后的人，多米诺式传导到门口，有人被挤到墙角 |
| 她很伤心 | 她的手在杯沿上停住，一滴泪落进杯里，低头看着水面没有动 |
| 镜头很有冲击力 | 镜头以大幅甩镜扫过战场，尘土在光柱中飞扬（写物理不写评价） |

## 4b. 发光 vs 反光歧义（实测教训 2026-08-15）

角色身体部位的光学词——「眼神光灼亮」「轮廓光晕」「眼中光晕」——易被
模型理解成**实体自发光**（眼睛真的发光）。区分：

- **反光**（受光）：瞳孔上方高光反光点（如灯光倒映在眼中）、边缘受光
  勾线、皮肤受光面微亮——写「反光」「受光」「倒映」，不写「发光」
- **发光**（自发光）：只用于明确特效（能量光环、光效道具，见 guoman-3d
  §5d）——写「自发光」「发出光晕」并限定来源与范围

实测案例：悬疑录测试提示词写「眼神光灼亮」→ 生成中眼睛自发光冒光。

## 4c. 安全改写（来源：地狱 Rewrite Playbook — 高风险措辞 → 后果/张力/物理/氛围）

| 高风险原文 | 安全改写（更电影化） |
|---|---|
| 两人在巷子里打架 | 两人紧张的肢体对峙，雨巷，戏剧性低光，每次冲击相机颤抖 |
| 爆炸摧毁汽车 | 橙色光爆与浓烟从车中涌出，金属向外翻卷，玻璃碎片反光 |
| 血从他手上滴落 | 他的双手在身侧颤抖，袖口有深色污渍 |
| 男人用枪指着另一个人的头 | 楼梯间对峙——一人手臂前伸、另一人纹丝不动、单顶荧光灯下硬边剪影 |
| 怪物把受害者撕碎 | 不对劲的后果——空房间、翻倒家具、拖向门口的一道污迹、闪烁的实用灯 |

原则：高风险动词（打/杀/射/血/刺）→ 后果/张力/物理/氛围描述；
「对峙比屠杀更紧张、空城比恐慌人群更诡异、咆哮比击杀更有力」。

## 5. 自检清单

- [ ] 抽象词是否全部翻译为「摄影机拍得到」的画面？
