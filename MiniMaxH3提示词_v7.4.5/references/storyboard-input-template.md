# Storyboard Input Template — 分镜输入模板

> 用户按此模板提供分镜输入，1c 输入完整性检查有固定参照——字段缺失
> 一眼可查。输出中文。

## 模板（表格）

| 镜头号 | 时长 | 景别·角度 | 画面内容 | 对白/台词 | 声音 |
|---|---|---|---|---|---|
| 1 | 3s | 平视·近景 | 陆慎行袖中摸出焦了半页的旧书 | 无 | 衣料声 |
| 2 | 5s | 平视·特写 | 焦书半页上的一行小字 | 陆慎行（OS）："越是完美的现场，越说明凶手在利用规则。" | 翻页声 |
| 3 | 4s | 平视·纯黑 | 黑屏，字幕浮现 | 字幕："下一集——……" | 堂鼓、骤停 |

## 字段说明（每个字段的填写标准）

| 字段 | 必填 | 填写标准 |
|---|---|---|
| 镜头号 | 必填 | 1、2、3…（= 台账 SC###-SH### 的 SH 号；提示词内为 [镜头 N]——三处对应关系固定） |
| 时长 | 必填 | 秒数（**镜头级** 1.5-6s 甜点；块级（单次生成）4-10s 有效范围见 references/duration-ledger.md——两口径按层级区分；<4s 自动合并、>10s 自动拆条，模型能力上限 15s 不作为默认目标） |
| 景别·角度 | 必填 | 角度·景别（平视/俯拍/仰拍 × 远景/全景/中景/近景/特写）；缺省按内容推断并标注假设 |
| 画面内容 | 必填 | 谁/在哪/做什么（一镜一主动作） |
| 对白/台词 | 可空 | 说话者（含 OS 画外音标注）+ 逐字台词；无则写「无」 |
| 声音 | 可空 | 环境声/动作音/音乐提示；无则写「无」或留空 |

## 使用流程

1. 用户按模板给分镜（或给自由文本——技能按此模板字段提取）
2. 1c 输入完整性检查对照此模板逐字段核对
3. 缺失字段按 1c 规则处理（时长缺失→问；景别缺失→推断标注；对白/声音缺失→默认无）

**完成条件**：全部镜头的 6 字段已核对完毕（缺失项已按 1c 处理或标注
假设）；镜头数/总时长已确认（>15s 已拆条）。

## 高危预检（顺带）

输入模板自带高危预检位置——镜头号旁可标「⚠」：
- 黑屏/纯白 → 高危 #2
- 长字幕/画面文字 → 高危 #1
- 镜子/水面 → 高危 #3
- 人群 → 高危 #5
（完整清单见 high-risk-shots.md，命中即走 1c 门禁用户裁决）
