## 2. 官方原生中文 Prompt 完整骨架


## 3. 高阶工业级工艺原生融入规约

在官方原生中文骨架中，从开源吸收的顶级工艺以自然语言方式无缝嵌入对应板块：

### (1) 因果动作链七要素 → 融入【画面演进】
在每个镜头的动作展开中，严格贯彻七要素：
- **部位 + 方向 + 速度 + 力度 + 惯性 + 接触 + 可见后果**。
- 正例：“沈昭右手（部位）沿桌面右前方（方向）以平缓速度（速度）沉稳前推（力度），小臂与衣袖随惯性前送（惯性），掌心精准贴合茶杯外壁（接触），杯底沿木纹滑出半寸并在杯口荡起两圈微澜（后果）。”

### (2) 主光世界向量与明暗交界线 → 融入【环境光影】
- **向量与色温**：“主光源位于场景右前方方位角45度、俯角30度处，呈现3200K暖黄烛火质感；角色侧首时，明暗交界线（Terminator Line）沿颧骨与下颌骨骼起伏平滑扫掠，背光侧暗部保留微弱冷灰环境漫反射，无任何死黑。”

### (3) 多通道解耦防火墙与排他短语 → 融入【空间基准】
- **防材质/光色污染**：“图1为沈昭角色卡，仅锁定其面部骨骼、眉眼比例与玄色发簪；严格阻断图2环境石壁材质或图3兵刃冷光向其面部与皮肤产生任何串色或纹理污染。”

### (4) 好莱坞节拍切片器 → 映射【画面演进】独立段落
- 每一个 2.5s~5.0s 的原子 Beat 对应【画面演进】中的一个独立自然段。
- 相邻段落严格落实**景别跨档**（如特写接中景）与**30°~90° 机位角度跨越**，绝不进行 <30° 的同景别跳切。

### (5) 生理化微表情与情绪转译 → 融入【画面演进】
- 严禁空洞文学词汇（如“神情悲伤”、“他脸红了”）。
- 转译为微观生理体征：“喉结轻微上下滑动一次，下眼睑边缘迅速泛起一层微润湿光，睫毛低垂微颤，嘴唇边缘轻微失血发白”。

## 4. 生产验收检查单（Native Chinese Check List）

1. **结构完整**：逐字保留首段长焦大光圈声明、末尾【画面风格】声明，中间六大章节标题（【环境光影】、【空间基准】、【角色声音签名】、【画面演进】、【声音设计】、【画面风格】）无漏项。
2. **参考图绑定**：每张参考图独占一行，格式为 `图N = <名称>，锁定<属性>`，宫格参考图固定为最后一张。
3. **主锚定位清晰**：以单一显式物理主锚为基准，所有在场角色明确区分 `dialogue actor` 与 `on-scene witness` 并声明视线与相对位置。
4. **纯粹台词与音效**：台词逐字嵌入演进段落，附带生理发声动作；首段严禁背景音乐，【声音设计】仅包含环境音与拟音。
