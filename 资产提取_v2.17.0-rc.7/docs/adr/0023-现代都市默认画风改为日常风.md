# ADR-0023: 现代都市默认画风改为日常风，赛博朋克独立保留

- 状态: Accepted
- 日期: 2026-08-19

## 背景

`题材-画风映射.md` 曾把「现代都市」默认映射到 C10 赛博朋克风（霓虹夜景），导致都市爱情/职场/家庭等日常剧默认输出赛博夜景，用户每次都要手动在调度清单行级切回日景或传 `--style 日常风`。用户确认修改。

## 决策

1. 现代都市系题材（现代都市 / 都市情感 / 职场 / 现代都市（都市情感/职场））并入 C6 日常风行，默认画风 = 日常风（暖金时段、柔和粉彩、自然光）。
2. 科幻 / 赛博朋克 / 未来都市 保持 C10 赛博朋克风，霓虹夜景能力不丢失。
3. 需要夜景/赛博/未来感时：显式 `--style 赛博朋克风`，或调度清单行级「画风」列切换（ADR-0004 决策 3）。
4. 画风库 C6 适用标签补充「现代都市日常」。

## 影响

- `references/题材-画风映射.md`、`references/画风库.md`、`测试/run_style_test.py` 断言。
- 存量提示词不会被自动覆盖；如需按新映射刷新，运行 `generate_prompts.py --force`。
