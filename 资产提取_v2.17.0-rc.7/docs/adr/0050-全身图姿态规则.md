# ADR-0050: 全身图姿态规则（默认自然站姿、标志站姿按原文、禁动态动作）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：全身图默认手臂自然下垂、双脚与肩同宽；视觉描述/原文确有标志性站姿时按原文写一个并写明重心与手部位置；禁止动态动作（走路/挥剑/跳跃），动态留给分镜与衍生。

## 决策

1. 默认自然站姿。
2. 标志性站姿按原文并写明重心与手部位置。
3. 禁止动态动作。
4. 衍生沿用基础姿态。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`。
