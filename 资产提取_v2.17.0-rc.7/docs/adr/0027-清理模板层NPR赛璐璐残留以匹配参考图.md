# ADR-0027: 清理模板层 NPR/赛璐璐残留以匹配参考图

## 状态

已接受（2026-08-19）

## 背景

用户明确声明「画风定性一定要按照我给的图片来」。参考图为斗罗大陆/玄机科技高精度 3D 国漫角色设定集，核心特征是写实比例、PBR 材质、无 NPR/赛璐璐/卡通描边。但现有模板与兜底画风中仍存在与用户目标直接冲突的表述：

- `templates/描述补全模板.md` 第 7 行默认视觉基准为「非写实渲染、卡通渲染、赛璐璐/次世代风格化、国漫三维质感、发束感/色块分割」，会把资产描述先拉向 NPR/卡通。
- `references/画风库.md` 中 A1「中式国漫三维 基础风」是古风/历史未细分题材的兜底，仍写「非写实渲染，卡通渲染，清晰轮廓描边，硬边阴影色块」。

## 决策

1. 将 `templates/描述补全模板.md` 的默认视觉基准改为写实 3D 国漫：高精度三维建模、物理渲染（PBR）材质、写实国漫质感、细腻毛发与皮肤纹理、金属/丝绸/皮革/宝石真实光泽，并明确禁止赛璐璐/卡通渲染/硬边阴影色块/二维平面感。
2. 将 `references/画风库.md` 中 A1「中式国漫三维 基础风」的渲染层改为写实 3D 国漫基础风：保留东方美学色彩与高颜值角色，删除 NPR/卡通渲染/清晰轮廓描边/硬边阴影色块。
3. 同步清理 `服饰设计/` 子模块中残留的「非写实渲染/卡通渲染/赛璐璐/硬边阴影色块」等表述；服饰设计生成的角色条目与生图提示词同样以写实 3D 国漫为默认渲染语言。
4. 以 `CONTEXT.md` 中「高精度 3D 国漫设定集风（斗罗/玄机风格）」术语为最高优先级画风基准；后续任何新增模板或兜底画风若与该定义矛盾，必须按本 ADR 原则清理。

## 权衡

- **全部清理 vs 仅清理 H7 相关路径**：仅清理 H7 相关路径（玄幻/仙侠）改动最小，但用户要求「画风定性按照参考图来」且参考图的写实 3D 渲染是跨题材渲染语言，因此默认视觉基准和兜底 A1 也必须同步，否则非玄幻题材仍会退回到 NPR。
- **彻底删除 NPR 表述 vs 保留为可选项**：彻底删除可保证输出不跑偏；若未来用户确实需要 NPR/赛璐璐，应显式新建卡片而非让默认路径残留。

## 后果

- `描述补全模板.md`、`画风库.md` A1 与 H7 在写实 3D 渲染上达成一致。
- 需要同步检查 `基础提示词模板-人物.md/场景.md/道具.md`、`衍生提示词模板.md`、服饰设计子模块是否仍有冲突表述，并在同一批次清理。
- 现有测试（画风库解析、样式检查、纯中文检查）需重跑，确保无回归。
