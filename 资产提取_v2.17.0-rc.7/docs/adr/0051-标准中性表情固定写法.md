# ADR-0051: 标准中性表情固定写法

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：脸部参考图的表情中性固定为标准肌肉描述，逐字复用，保证所有角色基础脸图表情基线一致。

## 决策

1. 标准中性：「面部肌肉完全放松：双唇自然闭合、嘴角不扬不垂、眉毛平展无高低、眼睑自然开合无眯眼、下颌放松」。
2. 人物基础/衍生/服饰设计三处逐字复用。
3. 剧本/描述指定极轻微表情时按指定肌肉动作写。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`、`服饰设计/SKILL.md`。
