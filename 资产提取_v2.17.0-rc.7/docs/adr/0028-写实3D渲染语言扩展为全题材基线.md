# ADR-0028: 写实 3D 渲染语言扩展为全题材基线

## 状态

已接受（2026-08-19）

## 背景

用户提供的参考图（斗罗大陆/玄机科技角色设定集）确立了一种跨服装内容的渲染语言：高精度三维建模、PBR 材质、写实比例、纯白/浅灰摄影棚背景、正侧背四视图、无 NPR/赛璐璐/卡通描边/硬边阴影色块。此前技能包中部分题材（现代都市 C6、赛博朋克 C10 等）默认使用非写实渲染/卡通渲染/清晰轮廓描边，与参考图冲突。

## 决策

1. 将写实 3D 国漫渲染语言确立为全技能包的**渲染基线**：所有题材的人物/场景/道具基础提示词与描述补全，默认使用高精度三维建模、物理渲染（PBR）材质、写实比例、无 NPR/赛璐璐/卡通描边/硬边阴影色块。
2. 玄幻/仙侠/神魔/奇幻使用 H7「高精度 3D 国漫设定集风」（华丽装饰版）；现代/民国/科幻等其他题材在保留各自内容主题（服装、场景元素、色调）的前提下，渲染层必须同样遵循写实 3D 基线。
3. 现有 C 系/动漫系卡片若与写实 3D 基线冲突，将逐步清理或标记为 legacy；新用户默认不再命中 NPR/卡通渲染风格。

## 权衡

- **统一写实基线 vs 按题材保留不同渲染风格**：统一基线能保证用户参考图的风味贯穿所有题材，避免现代题材突然变成二维动漫风；代价是需要改写或弃用部分现有卡片（C6/C10 等）。
- **修改现有卡片 vs 新增卡片**：为避免破坏已有 `--style` 引用，优先新增写实 3D 版本卡片并改映射，旧卡片标注 legacy。

## 后果

- 题材-画风映射表需要为现代/民国/科幻等题材新增或调整默认映射，指向写实 3D 渲染卡片。
- `画风库.md` 中 C6/C10 等卡片需要审阅，或新增对应写实 3D 版本（如 H8 现代写实 3D、H9 民国写实 3D、H10 科幻写实 3D）。
- 服饰设计子模块的默认渲染描述也需要同步为写实 3D。
- 测试用例需要更新，确保默认命中的画风不再包含 NPR/赛璐璐/卡通描边等关键词。
