# ADR-0047: 裁头规则保留发型后侧轮廓（按需背面无脸图）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：双图锚点的「全身图裁头」裁的是头部与面部，不是发型。若角色发型有后侧轮廓（披发/发髻/垂背辫子），按需追加一张「背面视角全身图（仅后脑勺发型轮廓与服装背面，无脸）」；发型简单无后侧特征则不追加——遵循「只生成需要的」。

## 决策

1. 全身图默认裁除头部与面部，禁止第二张脸。
2. 发型后侧特征按需追加背面无脸图；无则不加。
3. 人物基础与衍生同步。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`。
