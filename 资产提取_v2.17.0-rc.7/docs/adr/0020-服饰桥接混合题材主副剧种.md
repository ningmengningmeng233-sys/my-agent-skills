# ADR-0020: 服饰桥接输出混合题材主副剧种

- 状态: Accepted
- 日期: 2026-08-19

## 背景

`prepare_costume_input.py` 之前只按「最早出现的命中键」输出单一剧种。混合题材（如「都市玄幻」）会静默丢失副剧种，编排器无法执行服饰设计 ADR-0002 的白名单交集/黑名单并集融合规则。

## 决策

**桥接脚本自动解析混合题材，输出主剧种 + 去重后的副剧种列表。**

1. 主剧种 = 题材串中最早出现的命中映射；副剧种 = 其余命中映射去重（映射到同一剧种只计一次）。
2. 角色清单头部写「剧种 / 副剧种」两行，并附融合规则提示；stdout 同步输出。
3. 完全未命中时仍由编排器询问用户指定剧种（唯一询问例外）。

## 影响

- `scripts/prepare_costume_input.py` 新增 `resolve_genres()`；`SKILL.md` 步骤 3.6 与单元测试同步。
