# ADR-0045: 设定图背景统一为浅灰 #B8B8B8

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：人物双图锚点、服饰裁头服装三视图、道具三视图三处设定图背景统一为浅灰 #B8B8B8（贴近地狱中性灰实测结论，避免纯白导致角色与背景混淆）；服饰校验脚本把 #B8B8B8 作为背景色豁免，不误判为角色配色出界。

## 决策

1. 三处设定图背景统一 #B8B8B8。
2. H7 画风卡背景描述同步。
3. check_costumes 配色出界检查豁免背景色集合（#B8B8B8/#DCDCDC/#7F7F7F）。

## 影响

- `references/画风库.md` H7、`服饰设计/SKILL.md`、`服饰设计/输出/*`、`服饰设计/scripts/check_costumes.py`。
