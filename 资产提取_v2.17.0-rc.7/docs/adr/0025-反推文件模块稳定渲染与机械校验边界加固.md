# ADR-0025: 反推文件模块稳定渲染与机械校验边界加固

- 状态: Accepted
- 日期: 2026-08-19

## 背景

审查 `check_final.py` 与服饰 `check_costumes.py` 发现四处边界问题：

1. `render_final` 只在存在衍生需求/待确认项时才输出对应模块，导致合法反推文件缺模块，`check_final` 误报；
2. `check_final` 用子串匹配，正文提到模块名也算通过；
3. 反推文件交付说明与文件夹结构建议停留在旧布局（每资产一文件、Excel、裁决_*.md 根目录、国漫3D_AI资产库），与 v2.7 三类型合并文档和 .process 归档不一致；
4. `check_costumes.main_color_hex` 的正则会跨过逗号把「次色 #...」误认为主色，造成主色撞车漏检。

## 决策

1. `render_final` 始终输出「衍生需求汇总」与「待确认附录」模块（无数据时输出空表头），模块集合固定为 12 个。
2. `check_final.REQUIRED` 改为标题级匹配（`## 一、项目基础信息表` 等），正文提及不算命中；补入「交付物说明」模块。
3. 交付说明与文件夹结构建议同步为 v2.7 布局与纯中文（人物/场景/道具提示词.md、.process/裁决/、国漫三维资产库、提示词库）。
4. `main_color_hex` 收紧为 `主(?:色)?[^#，,；;
]*#...`：逗号/分号/换行即终止，次色不再误判为主色。
5. `check_costumes` 补 10 项边界单元测试（黑名单声明剥离、配色板、分段、主色识别、三视图缺失等）。

## 影响

- `scripts/aggregate.py`、`scripts/check_final.py`、`服饰设计/scripts/check_costumes.py`、相关单元测试。
