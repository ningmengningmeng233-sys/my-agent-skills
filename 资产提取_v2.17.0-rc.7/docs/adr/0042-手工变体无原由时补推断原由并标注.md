# ADR-0042: 手工变体无原由时补推断原由并标注

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：调度清单手工增行不强制填写原由；生成三段式时若变体无原由，由 LLM 按题材物理逻辑补一个中性原由，并标注「（推断原由）」，不得冒充剧本事实。

## 决策

1. 手工增行不要求写原由。
2. 道具/场景三段式无原由时补中性原由 +「（推断原由）」标注。
3. 剧本驱动行仍使用真实原文出处。

## 影响

- `templates/衍生提示词模板.md` 道具/场景段、`SKILL.md` 步骤 6 调度清单说明。
