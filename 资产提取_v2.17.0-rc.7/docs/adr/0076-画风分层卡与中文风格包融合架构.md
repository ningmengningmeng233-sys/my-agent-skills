# ADR-0076: 画风分层卡与中文风格包融合架构

- 状态: Accepted
- 日期: 2026-09-06

## 背景

上次实测画风定性质量不佳，排查确认三类根因：

1. **分层断层**：画风库 43 卡中仅 10 张（A1/C6/C10/H1-H7）有「建模层/渲染层」分节；其余 33 张的渲染锁定退化为一句氛围词（如 A2「仙侠奇幻，飘逸仙袂……御剑飞行镜头，法阵符文」——运镜词混入人物定妆链路），负面词仅 3-4 条、无反赛璐璐/反平涂基线。而大多数题材的默认映射正落在这批 0 分层卡上。
2. **材质定性粒度不足**：H7 建模层对材质只有一句泛写；外部风格蒸馏体系（waterblower 式，luminous-xianxia 与 image2-styles 素材库）已验证「视图级（人脸/全身/环境/物件）+ 材质级（16 种各一段）+ 共享不变量 + 按画面内容路由注入」的定性粒度显著优于整卡注入。
3. **检查形同虚设**：style_keywords 仅取定性前两分句前 2 字符做子串匹配（H7 实测为「高精」「次世」）；逐字四层锁定检查只覆盖有分层卡；负面锁 any 命中即过；人物「身份锁」段不在必查项；`--style` 名称不归一化（「高精度3D国漫设定集风」静默落入自由描述模式绕过画风库）。

用户确认持续以「新增画风蒸馏卡」方式扩充画风库，要求新增路径零代码。

## 决策（路线丙）

1. **画风库仍是唯一入口**：题材挂钩与 `--style` 行为不变，所有调用方零改动。
2. **画风卡升级为「分层卡」**：四层渲染锁定（建模/渲染/场景背景/镜头）为必选基线；可选挂「风格包指针」指向 `references/stylepacks/<画风ID>/`——四视图定性（脸部/全身/环境/物件）、材质定性（皮肤/头发/布料/皮革/金属/玻璃/塑料/木材/石材/陶瓷/纸/液体/自发光/橡胶/妆面/植被 16 类）、共享不变量、负面词。**风格包全部纯中文落库**；英文原文仅作内部索引，绝不注入提示词。
3. **材质路由注入**：生成时按资产类型与画面实际材质从风格包点菜——人物路由 皮肤/头发/布料/金属/皮革/妆面，场景路由 石/木/植被/液体等，道具按材质表路由；物件图不读角色视图，空场景不读角色文件。材质定性并入模板既有「材质四件套」，不重复堆叠。
4. **渲染锁定代码级确定性拼装**：渲染锁定段与负面提示词并集由 `generate_prompts.py` 直接组装（负面按类型过滤画风卡负面），不再依赖 LLM 逐字抄写。
5. **零代码新增规范**：新增画风蒸馏卡 = 复制 `references/stylepacks/_模板/` → 填写中文定性 → `画风库.md` 建卡挂指针 →（可选）题材映射加行 → `check_style_lib.py` 自检 0 错误即完成。
6. **落地范围（用户拍板：11 个 sucai 完整风格全部落库）**：H7 以 luminous-xianxia-cinematic-cg-style-generator 素材为内容源首个落地（样板包）；sucai/image2-styles 的 11 个带 SKILL.md 完整风格（2D强线条平涂赛璐璐、80年代赛璐璐、3D渲染-v3~v8、style柔光古典写实-v2、中式恐怖-画皮纸人、儿童插画）全部翻译落库为分层卡 H8-H18 并各挂风格包；A2-A6 等无分层旧卡按新格式补渲染基线（渐进迁移，旧格式继续可用，渲染层兜底不变）。
7. **检查链路同步加固**：身份锁段必查、负面锁 any→all、style_keywords 抽 ≥6 字片段、无分层卡按内容语言句逐字检查、`--style` 名称归一化（3D↔三维、去空格）+ 未命中卡片显式警告。

## 被放弃的备选

- **路线甲（只重写卡面文字、结构不变）**：无法实现材质级路由；每卡全量塞 16 种材质定性会导致提示词爆炸且稀释画面重点。
- **路线乙（整包搬运外部英文技能、画风卡只存指针）**：外部技能是对话式生图形态，与离线管线注入点不符；英文素材与纯中文输出铁律硬冲突，现场翻译质量不可控。

- `references/stylepacks/`（新增目录：`_模板/` + `H7/`）

- `references/题材-画风映射.md`（去重「西幻」、补表头）
- `scripts/engine/style.py`（风格包解析 + 材质路由 + 名称归一化 + 未命中警告）
- `scripts/generate_prompts.py`（渲染锁定/负面并集确定性组装 + 材质路由注入）
- `scripts/check_schedule.py`、`scripts/check_style_lib.py`（检查加固 + 风格包完整性自检）
- `templates/基础提示词模板-*.md`、`templates/衍生提示词模板.md`（材质路由注入点）
- `CONTEXT.md` 新增术语：分层卡、风格包、材质路由
- `测试/`（单元与画风回归补用例）
