# ADR-0030: 道具视图规划按剧本用途动态决定

- 状态: Accepted
- 日期: 2026-08-19

## 背景

道具基础提示词此前固定为四宫格（正/侧/背/细节）。吸收《地狱》「视图按镜头计划，不按物体」原则后，经拷问确认改为动态视图规划：固定布局会为不需要的视图付费，且剧本需要底部/内部视图时固定四宫格无法提供，模型会凭空编造未见过的面。

## 决策

1. 基础三视图保底：正面图 + 侧面图 + 背面图，始终生成。
2. 可选格按原文/视觉描述决定，剧本没说就不加：底部/底侧（翻转、掉落、滚动、倒扣场景）、内部/打开状态（容器/匣子/剑鞘/机关）、微距（关键材质/接缝/铆钉/纹样/铭文）。
3. 布局按格数排布：3 格一行、4 格二乘二、5-6 格三乘二，同一画面一次生成。
4. 衍生道具状态变体保持与基础一致的视图规划；变体备注要求状态微距时替换微距格。
5. `check_schedule.py` 道具必守词从「四宫格」改为「正面图+侧面图+背面图」。

## 影响

- `templates/基础提示词模板-道具.md`、`templates/衍生提示词模板.md`、`scripts/check_schedule.py`、e2e mock 与快照。
