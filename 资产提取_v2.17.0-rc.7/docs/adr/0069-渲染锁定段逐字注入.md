# ADR-0069: 渲染锁定段逐字注入人物/场景/道具提示词

- 状态: Accepted
- 日期: 2026-08-19

## 背景

实际产物对照发现：人物提示词只出现零散渲染词或完全没有画风定性，H7 的完整渲染语言（写实三维渲染、物理渲染材质、金属高光镜面反射、边缘光、体积光神光、电影级光影、浅灰影棚）没有进入正文，只剩负面段约束。用户要求完美质量，确认采用地狱「锁定一次、逐字注入每条提示词」的正统做法。

## 决策

1. 人物/场景/道具提示词开头逐字注入「渲染锁定段」：画风卡 建模层/渲染层/场景背景/镜头 四层文字；无四层则中文定性逐字。
2. 内容语言（中文定性第一段）仅在 玄幻/仙侠/神魔/修真/奇幻 题材逐字追加，其他题材过滤（ADR-0046）。
3. `style.render_lock_sentences()` 提取四层；`check_schedule.py` 对人物/场景/道具做画风锁定段完整性机械检查。
4. H7 中文定性纯中文化（3D→三维、PBR 去括号）以保证逐字注入不破纯中文。

## 影响

- `templates/基础提示词模板-人物/场景/道具.md`、`scripts/engine/style.py`、`scripts/check_schedule.py`、`references/画风库.md` H7、e2e mock 与快照、单元测试。
