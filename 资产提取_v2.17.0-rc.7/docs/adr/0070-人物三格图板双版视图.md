# ADR-0070: 人物三格图板双版视图（默认不裁头 + 结算询问裁头版）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

对照《地狱》实际产物与用户指定参考，v2.9.0 的双图锚点（脸部参考图 + 裁头全身图）布局不对：用户要的是「左面人物正面特写 + 右面正视图和后视图」的同一画面布局；且地狱库有裁头版与不裁头版两种。用户确认方案 C：两版都要，默认不裁头，是否要裁头版在结算页面询问用户后再生成。

## 决策

1. 人物基础/衍生提示词统一为**三格图板（一张图）**：左面一格 = 人物正面特写（头顶到锁骨，全脸清晰）；右面上下两格 = 正视图（全身）+ 后视图（全身），两格等大、身高比例一致。
2. **双版视图**：`full`（默认）= 右面两格全身均保留头部（不裁头）；`crop` = 右面两格全身头部与面部一律裁除不入画，全图唯一的脸是左面正面特写，右面后视图只露后脑勺。
3. `generate_prompts.py` 新增 `--view-mode full|crop`（默认 full）；基础与衍生同版同文件：full → `人物提示词.md`，crop → `人物提示词_裁头版.md`。裁头版是独立可选产物，旧版单文件只迁移进 full 版，不混入 crop 版。
4. **只生成需要的**：默认流水线只生成 full；步骤 8 完成报告（结算页面）必须询问用户是否需要裁头版，用户明确确认后才补执行 `--base/--deriv --view-mode crop`，并复跑完整性检查。
5. 衍生与基础同版：裁头版衍生优先读裁头版基础（缺失时回退 full 基础，身份锁同源）；模板 `{view_mode}` 在生成时由脚本注入。
6. `check_schedule.py`：full 人物提示词必查三格图板词（正面特写/正视图/后视图）；crop 文件存在时才逐节检查；一旦 crop 基础存在，调度清单的人物变体必须同时有 crop 衍生，缺失照报。
7. 渲染锁定段逐字注入（ADR-0069）同步落到衍生提示词模板，基础/衍生/裁头版共用同一渲染锁定段。
