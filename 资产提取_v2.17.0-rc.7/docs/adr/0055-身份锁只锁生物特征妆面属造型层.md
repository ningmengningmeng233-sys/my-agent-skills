# ADR-0055: 身份锁只锁生物特征+基础发型，妆面头饰属造型层

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：身份锁只锁不可变生物特征（脸型/肤色/眉形/眼型/瞳孔色/鼻型/唇形/疤痕痣胎记）+基础发型发色；妆面（眼影/唇色/腮红/眉妆）与头饰属造型层，基础写基础妆面，衍生与服饰设计可按造型改变，不算身份漂移。

## 决策

1. 身份锁范围限定为生物特征+基础发型发色。
2. 妆面/头饰为造型层，可随造型变体改变。
3. 人物基础/衍生/服饰设计三处同步。
