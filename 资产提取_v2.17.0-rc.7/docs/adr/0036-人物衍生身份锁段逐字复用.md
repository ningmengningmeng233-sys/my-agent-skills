# ADR-0036: 人物衍生身份锁段逐字复用

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：人物衍生提示词不逐字带整段基础提示词（token 浪费），而是逐字复用基础提示词中的「身份锁段」（脸型骨相/五官/发色/疤痕标志），服装与妆容按变体重写。

## 决策

1. 人物衍生从注入的基础提示词提取身份锁段并逐字复制到变体提示词开头。
2. 服装/妆容/发型/配饰按变体重写；身份锁之外不重复全身描述。
3. 未提供基础提示词时禁止编造基础状态对比，直接完整描述变体后状态。

## 影响

- `templates/衍生提示词模板.md` 人物段。
