# ADR-0059: 状态性眼部变化允许（仅剧本明确状态变体，三段式）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：身份锁锁眼型/瞳孔色，但剧本明确描写的状态变体（开眼/狂暴/魔化）可改变眼型/瞳孔色，必须三段式「基础 → 因<状态> → 变为Y」；基础双图永远用常态。

## 决策

1. 状态性眼部变化仅在剧本明确的状态变体出现。
2. 三段式变化，常态仍为身份锁原值。
3. 人物基础/衍生同步。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`。
