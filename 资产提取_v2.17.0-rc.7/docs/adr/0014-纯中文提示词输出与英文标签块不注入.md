# ADR-0014: 纯中文提示词输出与英文标签块不注入

- 状态: Accepted
- 日期: 2026-08-19

## 背景

用户反馈生成的提示词「偶尔夹杂英文」，并确认自己在技能包中要求过纯中文。核查发现技能包内从未写入纯中文约束，相反有三处机制主动注入英文：

1. `references/画风库.md` 把「英文标签块」设为每张画风卡的必填字段（ADR-0004/0005 设计），风格锁定机制要求把英文标签块连同 `Style lock: preserve this art style...` 锁定句一起注入提示词。
2. `scripts/engine/style.py` 的 `build_style_block()` / `build_render_block()` 原样拼接英文标签与英文锁定句。
3. `templates/` 各输出格式写明「中文为主可含英文标签」，部分模板还硬编码 `PBR` / `NPR` / `3D rendered` / `volumetric lighting` 等英文关键词。

因此英文夹杂是系统设计行为，不是模型偶发行为。

## 决策

**所有面向生图/交付的生成产物全程纯中文；画风卡英文标签块降级为内部索引，不注入任何提示词。**

1. `build_style_block()` 只注入中文定性与负面词，锁定句改为中文「风格锁定句：所有镜头必须保持上述画风不变」；`build_render_block()` 只输出中文渲染/建模层。
2. 全部模板删除英文关键词（`3D`→三维、`PBR`→物理渲染、`NPR`→非写实渲染、`CG`→电脑动画、`Toon Shading`→卡通渲染等），输出格式统一为「全程纯中文，禁止出现英文单词、英文标签或英文缩写」。
3. 画风库中文定性与负面字段去英文；英文标签块字段保留（作为生图模型常用的风格索引与自检资料），但明确标注「仅内部索引，不注入提示词」。
4. `check_schedule.py` 新增「纯中文」合规检查：连续 2 个以上英文字母即报「不合规·需重新生成」。唯一例外是色值代码（如 `#B8B8B8`）与序号数字，因其不含连续 2 个字母，自然不受影响。

## 权衡

| 备选 | 优点 | 缺点 |
|---|---|---|
| A. 保留英文标签注入 | 扩散模型对英文标签响应好，画风锁定更稳 | 违反用户纯中文要求，交付物出现英文 |
| B. 纯中文 + 英文标签仅内部索引（选定） | 符合用户要求，提示词可读性好 | 画风锁定的模型侧强度略降，需靠中文定性与必守词检查兜底 |

## 影响

- `scripts/engine/style.py`、`templates/*`、`references/画风库.md`、`scripts/check_schedule.py` 同步修改。
- 历史产物中含英文的提示词会被 `check_schedule.py` 判为不合规，需 `--force` 重新生成。
