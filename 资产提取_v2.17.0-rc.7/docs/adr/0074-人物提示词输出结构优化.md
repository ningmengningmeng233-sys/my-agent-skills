# ADR-0074: 人物提示词输出结构优化（v2.10.0）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

用户查看当前人物提示词样例后指出六处问题：H7 镜头层混写双版本；full 版未强调三格同一张脸；内容语言段过长且与渲染层重复；负面缺少三格身份/服装不一致；“图中不要有任何文字”重复三次；身份锁没有独立成段、右面两格未显式声明复用同一身份锁。

## 决策

1. **H7 镜头层版本中立化**：画风卡第 4 层只写通用三格图板构图与“全身完整入画”；full/crop 差异由模板 `{view_mode}` 注入，不再把两个版本写进同一条渲染锁定句。
2. **full 版同脸锁定**：`view_mode=full` 注入“左面特写与右面正视图必须是同一张脸、同一发型、同一妆面”；crop 版注入“三格共用同一身份锁，右面两格无面部”。
3. **内容语言精简为准确定性服务**：H7 中文定性第一段收敛为“高精度三维国漫角色设定集风，写实成人比例，立体五官，发束分明，肤质细腻；华丽金属/宝石/鎏金/浮雕/刺绣装饰，光泽丝绸/皮革/纱质内衬，蓝金/紫青/玉清/粉白幻想配色。”渲染语言由四层锁定，内容语言只锁设定/服装/配色基调，不重复堆叠。
4. **负面增加三格一致性**：人物负面新增“无三格身份不一致、无三格服装不一致”，check_schedule 负面锁同步。
5. **“图中不要有任何文字”降重**：左面特写段末句强制，右面两格段末写“画面内均无文字”，布局段不强制，避免三处重复。
6. **身份锁独立成段**：人物基础/衍生输出改为七段——渲染锁定 → 风格基调 → 身份锁 → 整体三格图板布局 → 左面特写 → 右面正视图/后视图 → 负面提示词；右面两格显式复用同一身份锁。
7. **斗罗/玄机式定性强化**：H7 中文定性明确为“高精度三维国漫设定集风（斗罗/玄机式），写实三维国漫动画电影级质感，精致美型五官，清秀骨相，皮肤柔滑瓷感，发丝分明带高光”；渲染层明确“非真人照片级写实”，并新增负面“无真人照片级写实/无欧美厚涂/无油腻塑料感/无灰暗写实胶片感”，防止跑向照片写实或普通 3D 游戏风。
