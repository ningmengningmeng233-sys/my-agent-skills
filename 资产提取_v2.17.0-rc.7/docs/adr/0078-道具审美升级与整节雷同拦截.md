# ADR-0078: 道具审美升级与整节雷同拦截

- 状态: Accepted
- 日期: 2026-09-06

## 背景

用户实测反馈道具提示词审美效果一般，要求按 ADR-0077 同样办法优化。排查确认三个根因：

1. **道具模板缺静物审美骨架**：模板只约束视图规划（三视图/可选格）与材质身份（四件套），但静物画面组织美学（剪影可读、边缘层级、干燥表面反应、痕迹分布、构造感、落地稳固）零要求；ADR-0077 已让物件视图定性与材质路由对道具生效，但骨架级共性规则仍缺位。
2. **描述补全道具维度是一句话**：无构造/痕迹逻辑/焦点细节/表面反应的结构化预写。
3. **道具正文雷同无拦截**：e2e 快照中三个道具（拨算盘/琴/旧书）除资产名外正文逐字一致；且 mock 的资产名提取标签（「名称: 」vs 用户模板实际的「道具: 」）从未命中——雷同拦截落地时顺带揪出该潜伏 bug。

## 决策

1. **道具审美骨架（模板级，所有画风通用）**七条必守：剪影可读、边缘层级（次级边缘柔和、仅一处焦点轮廓锐利）、干燥表面反应（哑光至缎面为主，光泽材质按路由定性单独给光泽）、材质靠光学表达（高光宽度/粗糙度/透射/雕刻深度/接触阴影，禁满版纹理堆砌）、功能性痕迹（只在接触点/把手/开合处，稀疏克制）、构造感（接缝/榫卯/开合线，细节解释形体或功能）、落地稳固（接触阴影清晰，禁悬浮穿模）。
2. **描述补全道具 7 维度**：形体与剪影/构造与工艺/材质身份四件套/使用痕迹与功能逻辑/焦点细节（剧本没写不加）/表面反应倾向/负面限制。
3. **内容整节雷同拦截**：check_schedule 新增 `check_section_duplicates`——场景/道具合并文档各节「去掉自身资产名后归一化正文」逐字重复即报（骨架句各节必然相同，故剥离资产名后整体比对）；与 ADR-0077 的「场景层次雷同」互补（层次句级 vs 整节级）。
4. **e2e mock 修正**：道具分支资产名提取改用用户模板实际标签「道具: 」；三个样例道具（算盘/琴/旧书）按各自材质·痕迹·构造差异化。

## 被放弃的备选

- **把骨架写入画风卡**：静物审美是跨画风共性（各风格包的物件视图已承载个性），写进 46 张卡会大量重复。
- **只拦道具不做场景整节比对**：场景同样存在整节雷同风险（层次句检查只覆盖前/中/后景），一并纳入。

## 影响

- `测试/unit/test_stylepack.py`（整节雷同用例）
