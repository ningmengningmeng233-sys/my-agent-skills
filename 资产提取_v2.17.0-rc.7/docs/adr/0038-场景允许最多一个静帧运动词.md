# ADR-0038: 场景允许最多一个静帧运动词

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：场景基础提示词允许写 1 个静帧运动词制造动势，但必须剧本有动势描写、与景别/角度不冲突；没有就不写。

## 决策

1. 静帧可用库：慢速推进 / 快速变焦 / 轨迹跟随 / 手持感 / 摇镜感 / 拉远揭示 / 鸟瞰掠过。
2. 最多 1 个；与景别/角度不冲突；剧本有动势才写，禁止乱加。
3. 基础与衍生场景模板同步。

## 影响

- `templates/基础提示词模板-场景.md`、`templates/衍生提示词模板.md`。
