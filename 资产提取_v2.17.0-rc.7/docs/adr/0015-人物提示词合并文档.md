# ADR-0015: 人物提示词合并文档（按序号分节）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

v2.6.0 之前，每个人物基础/衍生提示词各存一个文件（`提示词/基础/人物_xxx.md`、`提示词/衍生/人物_xxx_变体.md`）。用户反馈人物提示词应「存放在同一个文档里，按序号分好」，便于连续阅读与整体分发。

## 决策

**人物基础提示词合并写入 `<资产库>/提示词/基础/人物提示词.md`；人物衍生提示词合并写入 `<资产库>/提示词/衍生/人物提示词.md`。场景与道具维持单文件不变。**

1. 文档格式：`# 标题` + 说明行 + `## 001. 角色名` 节 + `---` 分隔；序号与反推文件人物表顺序（基础）/调度清单人物行顺序（衍生）一致。
2. 断点续跑：任务先写隐藏缓存目录（`.人物基础缓存` / `.人物衍生缓存`），全部成功后按序号合并写回合并文档；合并文档已含某节即跳过该任务。崩溃后重跑时缓存自动恢复，不重复烧钱。
3. 迁移兼容：首次运行时，v2.6.0 旧版 `人物_xxx.md` 单文件自动并入合并文档；旧资产库无需重新生成。
4. 衍生人物变体节标题为 `角色名（造型名）`；衍生提示词注入的基础提示词从基础合并文档对应节读取（找不到再回退旧单文件）。
5. `check_schedule.py` 的人物覆盖/合规/纯中文检查同步改为逐节扫描合并文档。

## 权衡

| 备选 | 优点 | 缺点 |
|---|---|---|
| A. 保持一人一文件 | 断点最简单，单文件可单独分发 | 文件碎片多，不符合用户阅读习惯 |
| B. 合并文档（选定） | 人物提示词一眼全览、按序号有序 | 需要缓存恢复与节级断点，实现复杂度上升 |

## 影响

- `scripts/generate_prompts.py`、`scripts/check_schedule.py`、`测试/` 与 `测试/e2e/` 快照同步更新。
