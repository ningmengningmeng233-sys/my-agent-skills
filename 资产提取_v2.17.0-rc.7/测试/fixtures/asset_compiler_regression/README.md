# 回归夹具：证据驱动资产编译器（v2.17.0 工单 0）

本目录冻结一个**脱敏**短篇，用于稳定复现 v2.16 现有链路的资产静默丢失与召回缺口，
并作为 v2.17 编译器的 100% 召回验收真值。

## 文件

- `source.txt`：六章脱敏古风短文。全部为虚构专名（永昌、断玉门等），无真实项目名/人物名/密钥/绝对路径。
- `expected_assets.json`：机器可读的期望资产真值（`schema_version: 1`）。测试从此文件读取数量，不硬编码。
- `../../repro_asset_compiler_failures.py`：跑现有链路的复现器，输出漏斗计数与覆盖断言。
- `../../unit/test_asset_compiler_fixture.py`：夹具结构 + 出处可追 + 脱敏守卫。

## 夹具刻意覆盖的难点

| 场景 | 夹具中的体现 | v2.16 现状（待冻结的故障） |
|---|---|---|
| 单次出现但推动剧情的关键道具 | 残破木门（仅第二章） | 误判 P3 → 无基础提示词，静默丢失 |
| 群演 | 往来说书人、几名衙役 | 应非独立正式资产 |
| 同名歧义 | 琴师阿锦 vs 撑船的阿锦 | 不得静默合并同一 stable_key |
| 人物状态 | 负剑公子（断臂之后） | 应写母资产变体，不伪造自环 |
| 服装 | 月白长裙/玄色大氅/猩红战袍 | 现链路无法产出（无提取词） |
| 后期文字 | 字幕/片尾字幕/片头预告 | 不得计为道具、不进生图队列 |
| 制作说明 | 冷色调/忌亮黄 | 提供约束，不得生成正式资产 |

## 正式资产下限（由 expected_assets.json 满足）

人物 ≥7、场景 ≥6、道具 ≥10、服装 ≥3、后期元素 ≥2。
