## 主流程（按序执行，每步完成标准见 SKILL.md）

### 步骤 0：确认输入（编排器交互，无命令）
确认三要素：源文件路径（.txt/.md）、题材（→ `{genre}`）、资产库目录。**画风确认（必须）**。

### 步骤 1：摸底与拆段 ✅ 实测通过
```powershell
python scripts\split_segments.py "<源文件1>" ["<源文件2>"...] --novel 小说名 --author 作者 --lib <资产库> [--overlap 1]
```
产物：`<资产库>\原文段\<小说名>-<作者>\` 段文件（5 章/段或 1 万字/段，幂等内容比对，千/万级章号识别）。行首数字列表（如 `1. 说明`）不会被当作章节；只有编号后仍带明确的章/回/卷/节或英文章节标记时才识别。

### 步骤 1.5：全局登记表 ✅ 实测通过
```powershell
python scripts\scan_registry.py "<资产库>\原文段\<小说名>-<作者>" --lib <资产库>
```
候选遍（并行）→ 分层聚合（log₂ 轮）；产物 `登记表.md`。

### 步骤 2：段级提取 ✅ 实测通过
```powershell
python scripts\extract_segments.py "<资产库>\原文段\<小说名>-<作者>" --lib <资产库>
```
N 段并行 + 登记表锚点注入 + 断点续跑；产物 `段产物\*-资产记录.md`（三张表，出处强制）。

### 步骤 3：聚合裁决 ✅ 实测通过
```powershell
python scripts\aggregate.py "<资产库>\段产物\<小说名>-<作者>" "<资产库>\原文段\<小说名>-<作者>" --lib <资产库>
```
出处校验 → 预聚合 → 交叉校验 → 登记表对账 → 分块裁决（5 块并行幂等）；产物 `反推_最终.md`（固定 12 模块）+ `.process\裁决\裁决_<块>.md(.hash)` + `.process\登记表对账报告.md`（过程文件全部归档，根目录不堆积）。

### 步骤 3.5：对账闭环 ✅ 实测通过
```powershell
python scripts\scan_registry.py --include-claims "<资产库>\.process\登记表对账报告.md" --lib <资产库>
```
[新增] 申报出处验证通过并入登记表；未通过留待确认附录。

### 步骤 3.6：服饰设计衔接 ✅ 实测通过
```powershell
python scripts\prepare_costume_input.py "<资产库>\反推_最终.md" --genre <题材> --lib <资产库>
python 服饰设计\scripts\check_costumes.py <服饰标准库> <角色服饰标准表>
```
题材 → 主副剧种（题材-剧种映射.md，混合题材自动输出副剧种，仅完全未命中询问）→ 角色清单 → 标准先行 → 逐角色条目 → 阻断清零才交付；产物 `<资产库>\服饰设计\<剧名>\`。

### 步骤 4：描述补全 ✅ 实测通过
```powershell
python scripts\generate_prompts.py --enrich "<资产库>\反推_最终.md" --genre <题材> --lib <资产库> [--style <画风>] [--yes]
```
自动化必须显式 `--style <画风> --yes`（只传 `--yes` 会直接报错）；产物 `描述\人物描述.md`、`场景描述.md`、`道具描述.md` 三个合并文档（按序号分节）。

### 步骤 5：基础提示词 ✅ 实测通过
```powershell
python scripts\generate_prompts.py --base "<资产库>\反推_最终.md" --genre <题材> --lib <资产库> [--style <画风>] [--yes] [--view-mode full]
```
人物全量注入画风锁定块（三格图板：左面人物正面特写 + 右面正视图与后视图；默认 `--view-mode full` 不裁头），道具只注入渲染层、场景全量注入；产物 `提示词\基础\人物提示词.md`、`场景提示词.md`、`道具提示词.md` 三个合并文档（按序号分节）。

### 步骤 6：衍生提示词 ✅ 实测通过
```powershell
python scripts\generate_prompts.py --init-schedule "<资产库>\反推_最终.md" --genre <题材> --lib <资产库>  # 已存在时默认保留；--append 只追加新行；--force 全量重建
python scripts\generate_prompts.py --deriv --genre <题材> --lib <资产库> [--style <画风>] [--yes] [--view-mode full]
```
默认清单 = 服装表 + 剧本驱动需求（有出处才生成）；人物/场景/道具衍生均自动注入对应基础提示词全文，基础缺失直接失败不生成；产物 `提示词\衍生\人物/场景/道具提示词.md` 三个合并文档（按序号分节）。

### 步骤 7：完整性检查 ✅ 实测通过
```powershell
python scripts\check_schedule.py "<资产库>\反推_最终.md" --lib <资产库> [--style <画风>] [--style-lib]
```
五项检查（分集/基础/衍生/合规/纯中文）+ 描述层负面限制与类型字段必查 + 画风锁定逐层必查与画风关键词覆盖基础/衍生合并文档；缺失项补跑（`--force`）或人工处理。

### 步骤 8：完成报告（编排器汇总 + 结算询问）
拆段 N 段 / 提取 N/N / 正式资产 X + 附录 Y / 描述·基础·衍生 N/N / 检查结果 + 待确认附录逐条。**末尾必须询问是否需要裁头版**：默认不生成；用户确认后补执行 `--base --view-mode crop` 与 `--deriv --view-mode crop`，新增 `人物提示词_裁头版.md`，并复跑步骤 7 通过。

## 追更流程（连载新增章节）

按序重跑：拆段（`--append` 或重跑，旧段 hash 不变自动跳过）→ 登记表 → 提取 → 聚合 → 服饰设计（已有标准库自动加载）→ 描述/基础/衍生 → 检查。
**每次 `generate_prompts.py` 运行都会要求画风确认**（自动化场景必须 `--style <画风> --yes`，只传 `--yes` 会报错退出）。
