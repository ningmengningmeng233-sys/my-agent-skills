# ADR-0001：三段式融合架构 — chunpu 负责生成，omer-metin 负责校验

本技能由两个来源技能融合而来：chunpu 版 character-design（中文，叙事驱动的角色形象生成）与 omer-metin 版 character-design（英文，游戏行业视觉方法论）。两者方法论起点不同——前者从角色内核出发（开脸定善恶→身形定品性→服饰强化），后者从观看体验出发（3-Read 规则：剪影→色彩→细节）。我们没有把它们并排堆放，而是让它们各司其职：

**① 定内核（chunpu 主导）**：角色身份/经历/性格 → 面部、身形、气质 → 产出角色形象特征
**② 落视觉（omer-metin 主导）**：剪影骨架 → 配色板 → 服饰细节（材质/纹样/配饰）→ 产出服饰标准条目 + 生图提示词
**③ 校验闭环（omer-metin）**：剧种内聚 + 角色差异化 + 黑名单扫描 → 违规报告

即"一个当设计师，一个当质检员"。备选方案（以 chunpu 为主线、3-Read 仅作为服饰落地时的自检步骤插入）被否决，因为它只做浅层拼接，无法把 omer-metin 的校验体系（validations）作为独立闭环落地，而校验闭环正是本技能"批量不出乱子"的保证。
