# 角色设计校验清单（Validations）

来源：omer-metin character-design（英文版），全量中文化并改造为可执行规则。本文件是**严格的规则与约束**——用于客观校验角色服饰标准条目（生成时自检）与批量产出（生成后全局校验）。

**严重级别（Severity）**：
- **阻断（Blocker）**：必须修改后才能交付（黑名单命中、跨剧种违禁元素）
- **警告（Warning）**：建议修改，可带警告交付（配色出界、角色撞车等）

**执行时机**：每个角色生成完毕自检一轮；批量全部生成后全局校验一轮；标准库变更后按需全局复检。

---

## 1. 剪影测试（Silhouette Test）

**级别**：警告（Warning）
**用途**：角色可辨识度的第一保证。

- [ ] 有纯黑剪影版本？（证明剪影被实际测试过）
- [ ] 缩小尺寸后剪影仍可读？
- [ ] 单凭剪影就能认出角色？
- [ ] 剪影与同剧其他角色不混淆？

**违规处理**：警告——建议补剪影验证，若同剧撞车升级为"角色差异化"检查。

## 2. 剪影地标（Silhouette Landmarks）

**级别**：警告（Warning）
**用途**：让角色在任何尺度下可认的关键特征。

- [ ] 至少识别出 2-3 个地标特征（大氅、飘带、发冠、武器等）？
- [ ] 地标在剪影中可见？（纯剪影下消失的特征不算）
- [ ] 剪影存在不对称？（对称剪影通常无聊且通用）
- [ ] 考虑了负空间？（元素间空隙防止"团块"）

## 3. 形状语言（Shape Language）

**级别**：警告（Warning）
**用途**：服饰剪裁与配饰气质的性格传达。

- [ ] 明确了主导形状族（圆/方/三角）？
- [ ] 形状选择与角色性格匹配并有理由？
- [ ] 形状语言在角色各服饰元素间一致？
- [ ] 与同剧其他主角的形状语言有区分？

## 4. 配色板规范（Color Palette）

**级别**：警告（Warning）
**用途**：精确色彩规范，防止漂移。

- [ ] 主色以十六进制色值指定（不是"深蓝"这种模糊词）？
- [ ] 次色已定义？（角色至少两色才可读）
- [ ] 点缀色已指定？（增加视觉兴趣与焦点）
- [ ] 色彩层级建立？（主 > 次 > 点缀）
- [ ] 主导色不超过 3-4 个？（太多 = 视觉噪音）
- [ ] **所有颜色均在剧种标准库配色板内？（出界 = 警告）**

## 5. 环境色彩测试（Color in Environment）

**级别**：警告（Warning）
**用途**：短剧场景多变，角色必须在常见场景里可读。

- [ ] 在暖调场景（夕阳/火光/宫宴烛光）测试过？
- [ ] 在冷调场景（夜景/雪/水下）测试过？
- [ ] 在中性场景（阴天/室内常规光）测试过？
- [ ] 与剧集常见背景（宫廷、森林、都市夜景等）对比可区分？
- [ ] 各条件下明度对比保持？（明暗关系不随光线崩坏）

**注意**：该检查为设计自检项，输出条目时确认配色板声明了明度结构即可，不要求真的渲染测试。

## 6. 比例指南（Proportions）

**级别**：警告（Warning）
**用途**：角色比例一致性的基础。

- [ ] 头身比已指定？（如"7 头身"，不是"高个子"这种模糊词）
- [ ] 关键尺寸已记录？（肩宽、臂长、腿长等，便于一致复现）
- [ ] 定义了可接受的风格化浮动范围？（防漂移同时允许风格化）

## 7. 三视图完整性（Turnaround Sheet）

**级别**：警告（Warning）
**用途**：角色服饰标准条目必须包含可实施的多角度视图（生图提示词层面）。

- [ ] 含正面视图？
- [ ] 含侧面视图（或 3/4 侧）？
- [ ] 含背面视图？（短剧角色转身常见，背面服饰必须设计过）
- [ ] 各视图姿态一致？
- [ ] 各视图比例一致？

**实现方式**：本技能通过 16:9 三视图生图提示词模板落地（左半面部特写 + 右半正/侧/背），生成提示词时逐项确认。

## 8. 表情表覆盖（Expression Sheet）

**级别**：警告（Warning）
**用途**：角色表情规范（用户指定保留）。

- [ ] 含中性表情？
- [ ] 含喜、悲、怒、惊四类基本表情？
- [ ] 含"坚定"表情（战斗/决断场景）？
- [ ] 表情与角色脸型一致？（防崩脸）

**实现方式**：服饰标准条目中作为可选字段"表情表"，按角色需要（主角必填，群演可省）。

## 9. 设计与背景故事对齐（Visual Storytelling）

**级别**：警告（Warning）
**用途**：服饰必须体现角色设定，不允许"设定一套、穿一套"。

- [ ] 服饰体现角色身份/职业？
- [ ] 服饰暗示角色经历？（伤疤、磨损、纪念物）
- [ ] 服饰传达性格？（姿态、表情、着装风格）
- [ ] 服饰表明归属/阵营（剧种内）？
- [ ] 关键性格特质有视觉表达？

## 10. 文化敏感度审查（Cultural Review）

**级别**：阻断（Blocker）——涉及敏感元素时
**用途**：服饰标准不得冒犯文化。

- [ ] 使用的文化元素经过研究与记录？
- [ ] 宗教/神圣元素未被当作装饰使用？
- [ ] 明确避免了刻板印象？
- [ ] 角色深度不止于文化身份标签？

**违规处理**：涉文化敏感元素未审查 = 阻断；审查通过但存在争议 = 警告并在报告中标出。

## 11. 角色差异化（Cast Differentiation）

**级别**：警告（Warning）——撞车即警告
**用途**：批量生成时防止角色之间"换装即克隆"。

- [ ] 队列剪影测试：每个角色单凭剪影可辨？
- [ ] 每个角色有独占主色？（与其他角色主色不重叠 = 撞车警告）
- [ ] 体型/头身比在阵容内有变化？
- [ ] 形状语言在阵容内有变化？
- [ ] 1 秒内能认出每个角色？（"三词速描"测试：不同角色的描述词不得相同）

## 12. 剧种内聚（Faction Cohesion）

**级别**：警告（Warning）——不遵守即警告；黑名单命中升级为阻断
**用途**：同一剧种全部角色共享视觉体系。

- [ ] 剧种配色板已定义，全员从板内取色？
- [ ] 剧种形状语言基础已确立（全员圆润或全员锐利等）？
- [ ] 反复出现的纹样母题已列出，角色从母题库选用？
- [ ] 角色在剧种内仍保持个体区分？（内聚 ≠ 抹杀个性）
- [ ] 剧种与剧种之间视觉可区分？

## 13. 禁忌清单校验（Blacklist / Taboo Check）

**级别**：**阻断（Blocker）**——命中必须修改
**用途**：剧种画风约束的强制力所在。
**执行方式**：**由机械脚本执行（scripts/check_costumes.py，扫描含用户额外禁忌）**，LLM 复核语义边界。

- [ ] 服饰元素逐项对照剧种黑名单（如玄幻禁机甲/西装/赛博霓虹）？
- [ ] 服饰元素对照用户额外声明的禁忌清单（如"本剧禁露肩装"）？
- [ ] 混合剧种时对照副剧种黑名单（黑名单取并集）？

**违规处理**：命中 = 阻断，修改后复检，不修改不交付。

## 14. 设计文档完整性（Design Document Completeness）

**级别**：警告（Warning）
**用途**：角色服饰标准条目字段完备性。

- [ ] 角色名与定位已指定？
- [ ] 剪影分析（或地标说明）已包含？
- [ ] 配色板含精确数值？
- [ ] 形状语言已定义？
- [ ] 三视图（生图提示词）已包含？
- [ ] 性格/背景对齐已说明？

## 文本规范规则（Text Rules）

以下为产出文本的硬性格式规则，防止模糊描述：

**规则 1：色彩必须具体**
- 不允许："主色：红色/深蓝/亮绿"这类模糊描述
- 必须：`主色：#E63946`（十六进制色值）

**规则 2：比例必须数值化**
- 不允许："高个子/宽肩膀/细胳膊"
- 必须："角色 7 头身，肩宽 2.5 头，臂长 2.5 头"

**规则 3：禁止通用描述**
- 不允许："标准战士/普通法师/典型主角"
- 必须给出具体、独特、可辨识的特征
