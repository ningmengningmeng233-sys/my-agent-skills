# 题材-剧种映射（v2 流水线 → 服饰设计）

v2 提取出服装资产后自动衔接「服饰设计」模块（`服饰设计/`，短剧服装设计，ADR-0006）时，把 v2 题材换算为服饰设计的 8 个内置剧种。**本表只做换算，不改动服饰设计模块内容**。

## 使用规则

1. 映射命中 → 直接使用该剧种，**不询问用户**（直接接上原则）。
2. 映射表标注「近似」的题材 → 使用兜底剧种，并在角色清单头部标注「近似剧种:原题材 X → 剧种 Y」。
3. 映射完全未命中（表外题材）→ 此时才询问用户指定剧种（唯一询问例外，见服饰设计 SKILL.md 阶段 0）。
4. 混合题材（如「都市玄幻」）→ 主副剧种规则：白名单交集、黑名单并集、配色以主剧种为基准（服饰设计 ADR-0002）。

## 与画风库的关系

题材 → 剧种（本表，服饰约束）与题材 → 画风（题材-画风映射.md，视觉风格）**是两条独立链路**：
- 画风库决定「画面怎么渲染」（色彩/氛围/镜头）
- 剧种决定「角色穿什么」（白名单/黑名单/纹样/制式）
- 两者同源于题材,但约束不同维度,互不覆盖;服饰条目生成时同时注入两套约束(画风锁定块 + 剧种服饰约束)
