# 共享风格不变量

纯三维渲染，风格化的高端游戏过场成像：形体理想化但物理上有体积，剪影柔和圆润，主几何干净可读，次级细节受控，呈精修的块面而非噪点式写实；比例取游戏角色式的理想化，形体落地扎实。材质呈基于物理的反应，光照为电影级光线追踪；柔和漫射的电影日光，暖调高光衰减，冷淡的环境补光，对比中低、黑位受控、无生硬的死黑压缩；接触阴影干净，镜面点缀克制。色域以奶油白与淡蓝打底，皮肤与点缀呈暖玫瑰调，高光缀哑金；环境材质在场时加入苔绿与石色中性调；饱和度受控、偏粉彩，后期干净，高光衰减轻柔。精品级材质细节可见但克制——毛孔、发丝、织纹、石坑、划痕、包浆与水滴清晰可辨而不喧闹，不坠入超摄影级噪点。完成度边界：预渲染游戏过场与精品电脑静帧；不是二维插画，不是绘画式概念图，不是真人摄影，也不是泛用的亮面动漫。
