# 风格包规范（ADR-0076）

风格包 = 分层画风卡的可选附件目录：`references/stylepacks/<画风ID>/`。画风卡仍居 `画风库.md`（唯一入口），风格包只提供**视图级 / 材质级 / 不变量 / 负面词**的细粒度中文定性，生成时按画面内容路由注入（材质路由），物件图不读角色视图，空场景不读角色文件。

## 目录契约

```
stylepacks/<画风ID>/
├── 说明.md          必需：来源/落库日期/结构清单/缺省说明
├── 视图-脸部.md      人物特写格用
├── 视图-全身.md      人物全身/服饰用
├── 视图-环境.md      场景用
├── 视图-物件.md      道具用
├── 不变量.md         全视图共享的介质与指纹（整段注入）
├── 负面词.md         、分隔的中文负面短语清单（按类型过滤后并入负面段）
├── 卡片草稿.md       新卡登记用草稿（中文定性分层 + 英文标签块 + 负面词），落库后可留档
└── 材质/            16 类标准材质定性（缺类省略，在说明.md 记录）
    ├── 皮肤.md 头发.md 布料.md 皮革.md 金属.md 玻璃.md 塑料.md
    ├── 木材.md 石材.md 陶瓷.md 纸.md 液体.md 自发光.md 橡胶.md
    └── 妆面.md 植被.md
```

## 硬规则

1. **全部纯中文落库**（数字/色值除外）——风格包文件会被逐字注入提示词，英文原文只留在来源技能包，绝不进入本目录。
2. **纯文本**：参考图（.png）不复制进技能包，来源图片位置记录在 说明.md。
3. **材质名用标准 16 类**：皮肤/头发/布料/皮革/金属/玻璃/塑料/木材/石材/陶瓷/纸/液体/自发光/橡胶/妆面/植被；源素材多出的材质取最接近的标准类，确实无法归类的可保留译名并在 说明.md 登记。
4. **最低契约**：说明.md 必需；满配包 = 4 视图 + 不变量 + 负面词 + 材质齐全；精简包（源素材不全）允许缺视图/材质，但缺什么必须在 说明.md 写明。路由代码对缺失文件自动跳过。
5. 每个材质/视图文件 = 一段可直接注入的定性散文（1-4 句），不要列表化提示词、不要英文。

## 新增画风蒸馏卡（零代码）

1. 复制 `_模板/` 为 `stylepacks/<新H编号>/`；
2. 把蒸馏源（外部风格技能）的 视图/材质/不变量/负面 翻译成纯中文填入，写 说明.md；
3. 按 卡片草稿.md 起草新卡，写入 `画风库.md`（H 系续号）并加一行 `- **风格包**: <新H编号>`；
4. （可选）在 `题材-画风映射.md` 加行挂钩题材；
5. 跑 `python scripts/check_style_lib.py`，0 错误即完成。
