# 风格组装参考（按剧本类型组装风格卡）

混合风格（如「仙侠奇幻 3D 渲染」）经常使用时的组装机制（ADR-0005 决策 7）。画风可拆层（层结构与卡片字段契约见 `画风卡片模板.md`）——本表把画风库拆成四个组件维度，编排器按剧本类型选组件起草一张 H 卡，**用户确认**后落库。

## 强制纪律（用户拍板，不可绕过）

1. **每次组装都必须用户确认**：起草完成后必须向用户展示完整卡片（名称/定性/英文/负面），用户明确同意后才可写入画风库；不允许静默落库、不允许「确认过一次规则后自动落库」。
2. 组装产出一律走 **H 系编号**、标准卡片格式（必填 4 字段，契约同 `画风卡片模板.md`）。
3. 落库后必须跑 `python scripts\check_style_lib.py` 自检，0 错误才算完成。
4. 需要按题材自动命中时，在 `题材-画风映射.md` 加行（题材挂钩唯一入口）。

## 组装流程（编排器执行）

1. 确认剧本类型（如「玄幻 3D」）与用途（场景风？要不要人物/道具定妆？）
2. 按下表选组件：内容层 × 渲染层 × 色调层 ×（可选）氛围层
3. 起草 H 卡：内容层 + 渲染层（若需定妆注入，**必须含「1. 建模层 / 2. 渲染层」分节**）+ 色调氛围 + 英文标签 + 负面（负面 = 所选组件源的负面并集，去冲突）
4. **向用户展示卡片全文，等确认**（用户可改组件/措辞，改后重新展示）
5. 确认后写入画风库（H 系编号顺延）→（可选）映射加行 → 自检 → **向用户回执**：卡片编号/名称、自检结果（0 错误）、触发验证（`--style 名称` 与题材映射命中结果）

## 负面词组装规则

所选组件的负面词**并集去重**，冲突项（如「无三维渲染」与三维渲染组件冲突）剔除；渲染层为三维国漫时，固定追加 A1 渲染层负面：无平涂赛璐璐/无厚涂/无非写实渲染/卡通渲染/清晰轮廓描边/硬边阴影色块/二维平面感/无日式萌系比例/无网红脸/无随机换脸/无成人幼态化/无分身镜像路人。

## 组件缺失处理

起草时组件表无合适组件（如「军事现代」「克苏鲁」）：
- **不得静默编造来源**——起草必须注明每个组件的出处（画风库卡 ID 或「新造，经用户确认」）；
- 向用户说明「组件表无此组件」，由用户选择：① 自由起草（新造组件，确认时一并确认）；② 先扩展组件表（在对应维度加行，标注来源卡或「新造」）再起草。
