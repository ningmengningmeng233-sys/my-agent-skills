# 画风卡片模板（新增风格照此填写）

新增一个画风的**三步**：① 复制下方模板为一张卡片，粘贴进 `画风库.md`（放在「三、风格锁定机制」之前或任意 H 系区域）；② 需要按题材自动命中时，在 `题材-画风映射.md` 加一行；③ 运行自检：

```powershell
python scripts\check_style_lib.py
```

---

## 编号与字段契约（ADR-0005）

- **编号用 H 系**：`H1`、`H2`…（无上限，勿跳号）。不要用 A-G 系编号——G 系是速查表不是卡片，A-F 系编号归既有风格；新卡混入会撞号或被当空卡解析。**编号只是内部 ID，触发用名称**：`--style` 请传卡片名称（如 `蒸汽朋克国风`），传编号（`--style H1`）会被当自由描述原样注入。
- **必填 4 字段**：名称 / 中文定性 / 英文标签块 / 负面词。缺任一，自检报错（H 系逐卡校验）。
- **可选「X. 渲染层」分节 = 人物/道具定妆注入的开关**：中文定性里含「建模层」「渲染层」关键词的行，会注入人物/道具定妆提示词；**不写这两层 → 该风格只作用于场景/衍生变体，不支持人物/道具定妆注入**（自检会提示）。
- 「适用」字段是给人看的备注，不参与任何逻辑；**题材挂钩的唯一入口是 `题材-画风映射.md`**。
- 画风语义越具体越好：中文定性一句话写完会削弱必守词检查（自检按标点分段取前 2 词段），建议用分节/逗号分句写法（参考 A1 五层结构或 A2 短句风格）。

---

## 卡片模板（复制 ↓ 从「### H1.」到最后一个字段）

```
### H1. 你的画风名称

- **适用**: 什么题材/场景用它（纯备注，不生效）
- **中文定性**: 一句话或分节描述画风——如：
  1. 建模层：……（可选；含「建模层」即支持人物/道具定妆注入）
  2. 渲染层：……（可选；含「渲染层」即支持人物/道具定妆注入）
  3. 色调氛围：……
- **英文标签块**: English style tags, comma separated（仅作内部索引，不注入提示词）
- **负面**: 无X，无Y
```

### 填写示例（照抄结构改内容即可）

```
### H1. 高精度三维国漫设定集风

- **适用**: 全题材通用（纯备注，不生效）
- **中文定性**: 高精度三维国漫设定集风，写实成人比例，物理渲染金属/丝绸/皮革/宝石真实材质，纯白/浅灰摄影棚背景，三格图板（左面人物正面特写 + 右面正视图与后视图）全身完整入画，电影级光影。拒绝非写实渲染/赛璐璐/卡通渲染/清晰轮廓描边/粗描边/平涂/硬边阴影色块/二维平面感
  1. 建模层：高精度建模，物理渲染材质，真实金属/丝绸/棉麻/皮革/宝石质感，发束感，八K超高清，细腻毛发与皮肤纹理
  2. 渲染层：写实三维渲染，真实光影，柔和主光 + 轮廓光/边缘光，体积光/氛围光，动态明暗对比，高饱和度色彩，拒绝非写实渲染/赛璐璐/卡通渲染/清晰轮廓描边/粗描边/平涂/硬边阴影色块/二维平面感
- **英文标签块**: high-precision 3D Chinese anime, PBR materials, realistic 3D rendering, clean studio backdrop, turnaround views, cinematic lighting, no cel-shading, no hard-edged shadows（仅内部索引，不注入提示词）
- **负面**: 无非写实渲染/赛璐璐/卡通渲染/清晰轮廓描边/粗描边/平涂/硬边阴影色块/二维平面感，无日式萌系比例，无网红脸，无随机换脸，无成人幼态化，无分身/镜像/背景路人
```

填好后如需按题材触发，在 `题材-画风映射.md` 加一行：

```
| 清末 / 民国蒸汽 | 蒸汽朋克国风 | H1 |
```

完成标准：自检 0 错误（警告可接受但请阅读）。
