## 二、核心反推流程步骤表（每步一个命令）

| 步骤 | 一条命令 | 要点 |
|---|---|---|
| ★ 一键跑完 0–8 | `run_pipeline.sh --lib <库> --input <源文件> [--genre 古风] [--style 仙侠奇幻风]` | 逐步编排、任一步失败即停并打印原因码与步骤名；**再跑同一条命令即从断点续跑**（`--dry-run` 只列步骤不出网）。Windows 用 `run_pipeline.bat` |
| 0 开始界面 | `maintenance.py status --lib <库> --json` | 阻塞式确认：配置、断点、已有产物 |
| 1 摸底与拆段 | `split_segments.py <源文件…> --novel … --author … --lib <库>` | TXT/MD/DOCX/EPUB 与多文件顺序清单；PDF 明确拒绝 |
| 1.5 全局登记表 | `scan_registry.py <原文段目录> --lib <库>` | 防命名漂移、跨段漏提、重复提取 |
| 2 段级提取 | `extract_segments.py <原文段目录> --lib <库>` | 逐段反推，带原文摘句与出处 |
| 3 聚合裁决 | `aggregate.py <段产物目录> <原文段目录> --lib <库>` | 产出 `反推_最终.md`、类型化总账与依赖图 |
| 3.1 编译链核对 | `maintenance.py build-ledger --lib <库> [--json]` | 由索引重建总账+依赖图，并报数量守恒 |
| 3.6 服饰设计 | `prepare_costume_input.py <反推_最终.md> --genre … --lib <库>` | 自动衔接，服装与身份解耦 |
| 4 描述补全 | `generate_prompts.py --enrich <反推_最终.md> --genre … --lib <库>` | 每资产一次 |
| 5 基础提示词 | `generate_prompts.py --base … --lib <库> [--style …]` | 每资产一次 |
| 5.1 确定性编译（可选） | `maintenance.py compile-prompts --lib <库> [--shadow\|--apply]` | 由总账编译；默认只出差异报告，不覆盖正式产物 |
| 6 衍生提示词 | `generate_prompts.py --init-schedule …` → `--deriv …` | 按调度清单逐变体 |
| 7 完整性检查 | `check_schedule.py <反推_最终.md> --lib <库>` | 只报不补 |
| 8 完成报告 | `maintenance.py verify --lib <库> [--style …]` | 一键收口并签发 `交付清单.json`（9 项机械检查） |

## 三、视觉生产命令集

```text
建计划 → 构图卡（可选预览/批准）→ 批量生成 run-ready → 崩溃恢复 resume
        → 导出审核请求 review-export → 当前主模型读图后 review-import
        → 发布正式版本 publish → 交付门 check_visual_delivery
```

```powershell
python scripts\visual_production.py status     --lib <资产库> --json   # 人话/机器可读状态
python scripts\visual_production.py run-ready  --lib <资产库> [--parallel 1-4]
python scripts\visual_production.py resume     --lib <资产库>          # 崩溃恢复，不重复生成
python scripts\visual_production.py pause      --lib <资产库> [--clear]
python scripts\visual_production.py review-export --lib <库> --task <任务ID>
python scripts\visual_production.py review-import --lib <库> --task <任务ID> --result <审核结果.json>
python scripts\visual_production.py publish    --lib <库> --task <任务ID>
python scripts\check_visual_delivery.py --lib <资产库>
```

无密钥时：`run-ready`/`run` 明确失败并指出手工与只提示词出路；`export`/`export-all` 永远可用。

## 四、三种内部模式与用户说法对照表（自 SKILL.md 第三节逐字移入）

| 用户说法 | 内部模式 | 行为 |
|---|---|---|
| 否，只反推资产 | `data_only` | 不创建视觉计划、不调用图片 API、不阻断资料签发 |
| 不直接生成，只准备提示词任务包 | `prompt_only` | 建计划、出构图卡与可自行生成的提示词包，**零网络** |
| 是，直接生成图片 | `direct_generate` | 调图片引擎生成，随后必须经主模型审核与发布器入库 |
