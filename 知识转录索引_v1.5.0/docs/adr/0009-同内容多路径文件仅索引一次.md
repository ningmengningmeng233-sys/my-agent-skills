# 0009-同内容多路径文件仅索引一次

- 日期：2026-08-16
- 状态：已接受

## 背景

源目录递归扫描下，同一文件（内容 hash 相同）可能出现在多个路径（如复制
粘贴到两个目录）。台账以 hash 为主键（ADR-0007），moved 判定
`rec.rel != s.rel` 导致多路径文件**交替**被判为「移动」——每次 build.sh
都重新切条目烧 token，永不收敛；产物扁平命名（校对版/索引库按 stem 命名）
会互相覆盖，条目行号指向的文件与校对版实际内容错位。

## 决策

同 hash 多路径时**只索引第一份**（扫描顺序第一个），其余路径输出
「重复文件」提示并跳过，不切条目；台账记录保持单一 rel 不折叠。

## 权衡

- 备选：产物文件名带路径哈希全索引——全链路（检索校对版推导/体检/快照/
  重建台账）命名约定变更，现有 271 个产物命名不一致，迁移成本高；
  重复文件本质是复制粘贴，索引两份收益低。
- 备选：扫描排除子目录——放弃递归支持，与「源目录递归扫描」既定行为冲突，
  且已有 2026/08 子目录文件。
- 选择「只索引一次 + 提示」：与 ADR-0007 内容指纹原则一致，改动最小，
  提示让用户自行清理重复。

## 关联

- ADR-0002 一视同仁：指**不同内容**的文件全量索引、不设跳过阈值；
  同内容重复文件不重复索引，两者不冲突。
