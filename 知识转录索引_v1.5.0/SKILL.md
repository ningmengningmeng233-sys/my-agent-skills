# 转录索引

为 Obsidian 里的 B站视频转录 TXT（`标题_作者_日期_BV号.txt`）建主题条目索引 + 本地向量库，
支持带出处的语义检索。产物在源目录内（`索引库/` `校对版/` `向量库/`）；术语见 `CONTEXT.md`，决策见 `docs/adr/`。

## 路由

按用户意图分流，**先说结论再看库**：

- 检索：用户要“我的转录库”“库内”“已收录”“视频里讲过”，或基于库内资料总结/归纳/比较/提炼观点 → 走下面的检索流程。
- 维护：用户要建/更新/体检/快照/清理/恢复转录索引 → 走建索引与维护。
- 不接：小说建库、PDF、聊天粘贴文本、单文件普通总结、公开网络找视频。只说“哪个视频讲过”且未指明本地还是公开时，先反问澄清。
- 成本：检索本地零 token，约 4 秒（加载 embedding 模型）；增量建索引调用摘要模型、消耗 token——执行前告知用户。

## 检索（步骤 + 完成标准）

1. **解析技能目录**：`<技能目录>` = 当前 `SKILL.md` 所在目录。以下命令全部用绝对路径拼接，不从任意 cwd 裸跑。
2. **双路召回**：执行 `"<技能目录>/.venv/Scripts/python.exe" "<技能目录>/scripts/检索.py" "<问题>" [--top N] [--author 作者] --json`。
   - 向量 top-15 + 关键词兜底；向量分低于 0.55 且非关键词命中的条目被过滤，输出带 `note`——把“未命中”转述为“无相关条目”，不是故障。
   - 向量库缺失/损坏时脚本会提示先 `build.sh --force`，照转述，不堆栈。
3. **展示候选清单**：输出已按主题聚类、作者分组，每项有 `candidate_no`、标题、作者、日期、BV 号。单来源命中（≤2 条）提示可直接精读，不强制走选择。
4. **用户选择**：接受「看 #2」「看 BVxxx」「看某一家」或「对比当前召回候选」。用户指公开视频时改用联网搜索。
5. **精读作答**：读取命中项的 `index_rel`（索引）、`proof_rel`（校对版）、`source_rel`（源 TXT）；读不到时明确“无法核验”，**禁止凭摘录或记忆补答**。
6. **完成标准**：每条论断带出处 `文件｜条目编号｜原始行号窗口`；行号是定位窗口（±3 行），不等于逐字引文。对比模式只对比当前召回候选，不宣称全库穷尽。

**检索 JSON 契约**（解析后按字段精读）：

```json
{"query": "问题",
 "clusters": [{"tag": "主题",
   "items": [{"candidate_no": 1, "item_no": 3, "name": "条目名", "summary": "...",
              "excerpt": "...", "source_rel": "相对路径.txt",
              "index_rel": "索引库/<key>-idx.md", "proof_rel": "校对版/<key>_校对版.txt",
              "artifact_key": "<key>", "lines": "原 第120-148行",
              "author": "...", "date": "...", "bv": "BV...", "score": 0.7, "kw": false}]}],
 "note": "过滤说明"}
```

## 建索引与维护

```bash
bash build.sh --dry-run   # 安全预览：新增/变更/移动/边界跳过，不写盘不调 LLM
bash build.sh             # 校对→切条目→向量，只处理新文件/变更
bash build.sh --force     # 全量重跑（写产物 + 消耗摘要 API）
build.bat                 # Windows 原生入口，等价 bash build.sh
```

- **安全门**：校对有文件失败即停止；切条目任一失败默认不进建向量；`--dry-run` 先报告 API 调用风险和摘要占位符。默认不写回源 TXT（`ALLOW_SOURCE_WRITE=0`）、不自动追加术语表（`AUTO_TERM=0`）。
- **闭环**：build 结束自动输出只读体检摘要；配置 `SNAPSHOT_DEST` 时自动同步只读快照。
- 体检 / 快照 / 清理 / 恢复的完整命令与前置条件见 [`references/维护.md`](references/维护.md)。
