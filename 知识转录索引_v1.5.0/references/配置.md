# 配置与依赖

## 配置存放位置

**不要在技能目录保存真实 API key。** 复制 `.env.example` 到用户私有配置目录并填写：

- Windows：`%USERPROFILE%\.config\转录索引\.env`
- 或设置 `TRANSCRIPT_INDEX_CONFIG_DIR` 指向自定义目录

加载优先级：进程环境变量 > 用户私有配置 > 技能目录 `.env`（仅兼容旧安装）。

## .env 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `SRC_DIR` | 是 | Obsidian 源目录（转录 TXT 所在，产物自动生成在目录内）。路径用正斜杠、勿加引号。 |
| `OPENAI_API_KEY` | 是 | 兼容 OpenAI Chat Completions 协议的密钥（当前默认服务商 DeepSeek）。 |
| `STRICT_BILIBILI` | 否 | 默认 `1`：只索引文件名含合法 BV 号的 TXT；`0` 允许通用 TXT（承担误索引和 API 消耗风险）。 |
| `ALLOW_SOURCE_WRITE` | 否 | 默认 `0`：发现摘要占位符时拒绝写回源 TXT；`1` 才允许。 |
| `AUTO_TERM` | 否 | 默认 `0`：LLM 术语建议只展示不自动追加；审查后设 `1`。 |
| `SUMMARY_API_URL` / `SUMMARY_API_MODEL` | 否 | 摘要服务端点与模型，默认 DeepSeek。 |
| `EMBED_MODEL` / `EMBED_MODEL_DIR` | 否 | 本地 embedding 模型（HF 仓库名 / 本地目录）。默认 `BAAI/bge-small-zh-v1.5`。 |
| `CONCURRENCY` / `MAX_RETRY` / `API_TIMEOUT` | 否 | 并发与重试。 |
| `TERM_TABLE` / `TAG_TABLE` | 否 | 词表路径，默认在源目录 `索引配置/` 下。 |
| `SNAPSHOT_DEST` | 否 | 快照默认目标；配置后 build 结束自动同步。 |

## 依赖

- 运行依赖见 `requirements.txt`；其中 `demjson3` 是 LLM JSON 宽松解析兜底，`pytest` 供本地回归测试。
- 词表位于源目录 `索引配置/`（术语表.md / 标签词表.md），随库走；技能目录保持可迁移，不要直接编辑快照目录。

## 回归测试

```bash
"<技能目录>/.venv/Scripts/python.exe" -m pytest "<技能目录>/tests"
```
