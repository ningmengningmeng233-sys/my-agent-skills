# 既有约定（改脚本前读）

这些约定已由脚本强制执行，改代码前先读 `docs/adr/` 理解为什么。此处只列行为约定，供维护时对照。

- **一视同仁**：所有文件都切条目，条目数由内容结构决定；清单/素材类正文强制 ≥1 条「速查清单」（LLM 判 0 条时脚本兜底）。
- **校对双轨**：规则产「校对版」（阅读终点）＋ LLM 写「摘录」（检索展示），行号一律映射原始文件。
- **行号零漂移**：LLM 只报锚点短语，脚本计算行号；锚点 miss → 摘录 n-gram 降级定位 → 仍失败才丢条目。摘要补全强制压成单行，避免改变原始行号。
- **标签词表**约束切条目（聚类质量依赖词表统一）；**术语表**只收英文/专名类和人工确认的中文错字，普通英文词不会作为全局替换源词。
- **台账认内容不认名字**：改名/移动零重建（同步索引与向量元数据），同 BV 重复仅提示；同内容多路径仅索引第一份，其余提示跳过（ADR-0009，防交替重切烧 token）。
- **产物键**：新文件产物命名 = `stem--hash前12位`，避免同名文件互相覆盖；旧版扁平 stem 产物兼容。
- **部分失败门禁**：切条目任一文件失败即不发布新的向量库（防“看似完整”的部分库）；已完成的 manifest 每文件原子落盘，中断不丢记录。
