# 维护命令（体检 / 快照 / 清理 / 恢复）

所有命令都要从技能目录用绝对路径执行（`<技能目录>` = SKILL.md 所在目录）。运行目录（Obsidian 源目录）是权威，快照目录是只读镜像。

## 体检（只读，最常用）

```bash
"<技能目录>/.venv/Scripts/python.exe" "<技能目录>/scripts/_检查行号引用.py" [--src <目录>] [--json]
```

- 不带 `--src`：对运行目录做全量体检，包含行号越界检查。
- `--src <目录>`：对指定目录体检；该目录无源 TXT 时自动进入快照模式（按 idx 存在性降级检查，跳过行号）。
- `--json`：输出结构化指标，便于程序消费。
- build.sh 结束时也会自动输出体检摘要（未索引/越界/孤儿/干净文件数）。

**体检指标含义**：`unindexed_count` = 有 BV 号但未建索引的源文件；`out_of_bounds` = 行号越界（必错）；`orphan_count` = 台账死记录；`clean_files` = 行号全部干净的文件数。

## 快照同步

```bash
"<技能目录>/.venv/Scripts/python.exe" "<技能目录>/scripts/_同步快照.py" [目标目录]
```

- 缺省目标：`SNAPSHOT_DEST` 环境变量；都未配置时落到桌面 `知识库索引/v2`。
- 先写临时目录、做复制校验、再整体替换——中断不会留下半份快照。
- build.sh 结束时若配置了 `SNAPSHOT_DEST` 会自动同步。

## 清理（删除动作，先预览再确认）

```bash
"<技能目录>/.venv/Scripts/python.exe" "<技能目录>/scripts/_清理台账.py" --dry-run
```

- `--dry-run` 只列出将清除的孤儿台账、孤立索引/校对产物、bv_map 重复，不写盘。
- 用户明确确认后再去掉 `--dry-run` 真正执行。

## 恢复台账

```bash
"<技能目录>/.venv/Scripts/python.exe" "<技能目录>/scripts/_重建台账.py" [--dry-run]
```

- 场景：切条目进程被中断，已生成 idx 但未登记进 manifest，直接重跑会重复烧 token。
- 从 idx frontmatter 反推源文件并登记 `ok=True`，让增量续跑只处理真正缺失的文件。
- `--dry-run` 先预览将登记的文件，不写盘。
