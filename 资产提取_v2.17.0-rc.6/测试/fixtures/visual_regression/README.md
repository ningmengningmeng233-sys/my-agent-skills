# 第一集视觉回归夹具（只读清单）

本目录保存「资产反推_DBIO修仙记-第01集」真实资产库的**只读图片清单**，供旧库非破坏迁移
（实施计划阶段 7）做前后比对。仓库内**不放任何用户图片字节**，只有文本清单。

## 采集方法

- 采集脚本以只读方式递归扫描资产库内 `.png/.jpg/.jpeg/.webp`，逐文件记录：
  相对路径（POSIX 分隔符）、字节数、SHA-256、按魔数嗅探的 MIME、像素宽高（Pillow 读取）。
- 不为采集修改、移动、重命名任何用户文件；不写资产库内任何文件。
- 采集时点：2026-09-18，资产库处于 v2.15.0-rc.2 技能版本下。

## 与机器门的关系

同一资产库在 v2.15.0-rc.2 下运行

```text
python scripts/check_visual_delivery.py --lib <第一集资产库>
```

结果为 `BLOCKED（VISUAL_BLOCKED）`，退出码 1，`任务 0/33 已通过`（33 项全部 `PLANNED`），
未生成 `视觉资产/视觉交付清单.json`。

即：**图片已落盘不等于机器门认可**。目录里的 82 张图对交付门不可见，只有经过任务记录、
哈希绑定与结构化审核的产物才算数。这正是本次升级要修的核心缺口，也是本夹具要冻结的现场。
