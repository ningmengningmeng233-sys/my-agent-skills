# ADR-0003：校验严重级别分级（阻断 / 警告）

自动校验的违规结果必须分级，否则无法执行："机甲出现在玄幻剧"与"配色用了库外的一个紫色"不是同一种问题，同等对待会导致要么全部阻断（过度严格，小问题阻塞交付）要么全部警告（失去强制力，画风跑偏没人拦）。本技能定义两级：

- **阻断（Blocker）**：黑名单命中、跨剧种违禁元素——必须修改后才可交付。
- **警告（Warning）**：配色出界（不在标准库配色板内）、角色撞车（主色/剪影/纹样与已有角色重复）——建议修改，可带警告交付。

"全部阻断"与"全部警告"两个极端方案被否决：前者把校验变成交付障碍，后者把校验变成摆设。分级方案保留了强制力的同时允许用户带警告推进。
