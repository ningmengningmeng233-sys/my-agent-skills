# ADR-0002：标准先行（库驱动）工作流与主副剧种融合规则

批量建立服饰标准有两种语义：标准先行（先建剧种标准库，角色逐个引用生成，生成后校验）与角色先行（一次批量生成，事后统一检查）。本技能采用**标准先行**：1 次建库 + N 次生成，标准库按剧种持久化可复用——"标准"必须存在一个可维护的实体，否则批量就退化为"一次画完"，失去长期价值。

同时定义**主副剧种融合规则**应对混合题材（如"都市玄幻"）：主剧种判定（取占主导者）→ 白名单取交集、黑名单取并集、配色以主剧种为基准、副剧种仅注入少量元素。备选方案"不支持混合题材，只支持单一剧种"被否决——短剧大量题材本质是混合的（都市玄幻、民国悬疑、战神+甜宠），不支持混合等于要求用户自废高频场景。
