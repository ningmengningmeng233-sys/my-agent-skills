# 短剧服装设计 — 术语表

本技能（短剧服装设计，drama-costume-studio）的词汇定义。以本表为准；正文中每个术语首次出现时括注英文原文。

## 核心概念

**剧种（Genre）**:
短剧题材分类。内置 8 种：玄幻仙侠 / 古装宫廷 / 民国年代 / 都市现代 / 科幻末世 / 悬疑探案 / 战神逆袭 / 甜宠偶像。
_Avoid_: 类型、题材（口语中"题材"可以理解，但文档与标准库一律用"剧种"）

**主剧种 / 副剧种（Primary Genre / Secondary Genre）**:
混合题材（如"都市玄幻"）时，占主导地位的剧种为主剧种，次要的为副剧种。融合规则：服饰白名单取交集、黑名单取并集、配色以主剧种为基准、副剧种仅注入少量元素。
_Avoid_: 混合剧种（不准确，混合题材必分主次）

**服饰标准库（Costume Standard Library）**:
某剧种的"全剧统一规范"：配色板（十六进制色值）、纹样母题清单、服装制式（男女基础款）、禁忌清单。按剧种持久化，可加载、可修改、可复用。
_Avoid_: 服装库、样式库

**剧种内聚（Faction Cohesion，原游戏"阵营内聚"）**:
同一剧种内所有角色共享视觉元素——同一配色板、同一纹样母题、同一服装制式，让全剧看起来是一个体系。
_Avoid_: 统一风格（弱化，内聚是校验规则不是观感描述）

**角色差异化（Cast Differentiation，原"阵容差异化"）**:
同一剧种内，每个角色保持可一眼区分的视觉特征：独特主色、独特剪影、独特纹样。与剧种内聚并存：内聚管"统一"，差异化管"不撞车"。

## 视觉法则

**三级阅读法（Three-Read Rule）**:
角色视觉必须按"剪影 → 色彩 → 细节"三层递进可读。第一层剪影（外轮廓一眼可辨）→ 第二层色彩（2-3 个主色定调）→ 第三层细节（纹样/配饰/材质）。细节永远最后加，加完必须回头检验前两层是否仍成立。

**形状语言（Shape Language）**:
用几何形传达性格的视觉体系：圆/曲线 = 亲和、安全；方/矩形 = 稳重、可靠；三角/尖角 = 凌厉、危险、速度。直接映射服饰剪裁与配饰气质。

**剪影（Silhouette）**:
角色服饰的外轮廓形状。角色辨识度的第一保证，要求有 2-3 个"地标特征"使角色在纯轮廓下依然可辨。
_Avoid_: 轮廓（口语词，文档统一"剪影"）

**地标（Landmark）**:
剪影上独特、可辨识的特征（如大氅、飘带、发冠、武器），任何尺度下可见。每个角色至少 2-3 个地标，同一剧种内不与他人重复。
_Avoid_: 特征点、记忆点（口语可通，文档统一"地标"）

**三视图（Turnaround）**:
角色正、侧、背三个角度的全身设定视图，角度间比例严格一致。生图提示词的输出格式（16:9 横版：左半面部特写 + 右半三视图）。

**表情表（Expression Sheet）**:
角色规定表情集合：中性 / 喜 / 悲 / 怒 / 惊，且必须与角色脸型保持一致（防止表情脱离脸型产生"崩脸"）。服饰标准条目中作为可选字段。

**纹样母题（Motif）**:
剧种或角色反复出现的装饰纹样（如玄幻的云纹、古装的龙纹）。标准库定义全剧母题，角色条目从母题库选用，禁止随意自创。

**配色板（Color Palette）**:
角色的色彩规范：主色 / 次色 / 点缀色，全部用十六进制色值指定。全剧配色板由标准库定义；单个角色最多 3-4 个主导色。

## 约束机制

**白名单（Allowlist）**:
某剧种允许使用的服饰元素清单（由剧种画风约束库定义）。

**黑名单（Blocklist）**:
某剧种禁止使用的服饰元素清单（如玄幻剧禁机甲、西装、赛博霓虹）。**黑名单命中 = 阻断**，不修改不交付。

**校验严重级别（Severity）**:
**阻断（Blocker）**：黑名单命中、跨剧种违禁元素——必须修改后才能交付。
**警告（Warning）**：配色出界（不在标准库配色板内）、角色撞车（主色/剪影/纹样与已有角色重复）——建议修改，可带警告交付。

**禁忌清单（Taboo List）**:
标准库内记录的黑名单元素 + 用户额外声明的禁用元素（如"本剧禁止露肩装"），与黑名单同效力（阻断级）。

## 工作流模式

**标准先行（Standard-First Workflow）**:
本技能默认工作流：先建立/加载剧种服饰标准库，再批量生成角色条目，生成后强制校验。库驱动，非角色驱动。

**单角色修订模式（Single-Character Revision）**:
批量生成后，单独修改某个角色时启用：只重跑目标角色（定内核→落视觉→服饰条目），标准库不动，修订后仍过校验。快速路径，不走全流程。

**全局复检（Global Recheck）**:
标准库变更（如换配色板、增黑名单项）后，对已生成的全部角色重跑校验（不重新生成，只校验），输出更新后的违规报告。

**剧名持久化（Title-based Persistence）**:
所有交付物按剧名落盘：`输出\剧名\服饰标准库.md + 角色服饰标准表.md + 校验报告.md`（**剧名不带书名号**，如 `输出\青云令\`）。同一剧种再次工作时自动加载已有标准库，形成闭环。

**渲染风格（Render Style）**:
标准库中锁定的全剧统一画风词（如"高精度 3D 国漫写实三维渲染""物理渲染（PBR）材质""写实国漫三维质感"），嵌入每段生图提示词，防止同剧不同角色画风漂移。
_Avoid_: 画风（口语可用，文档统一"渲染风格"）

**生图提示词（Image Prompt）**:
每个角色条目附带的、可直接用于 AI 生图的 16:9 三视图提示词（由 chunpu 模板 + 剧种约束自动嵌入生成）。
