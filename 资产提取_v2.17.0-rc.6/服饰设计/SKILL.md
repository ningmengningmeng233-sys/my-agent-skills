# 短剧服装设计（drama-costume-studio）

为短剧角色**批量建立"好看 + 符合剧种画风"的服饰标准**。融合两个来源技能：chunpu character-design（叙事驱动的角色形象生成，负责"生成什么"）与 omer-metin character-design（视觉方法论与校验体系，负责"怎么保证好看统一"）——一个当设计师，一个当质检员（见 docs/adr/0001）。

## 核心原则

1. **红线不可越**：剧种黑名单（红线）命中 = 阻断，不修改不交付（玄幻剧永远不出现机甲）。
2. **标准先行**：先建剧种服饰标准库，再批量生成角色条目，生成后强制校验。
3. **好看有规则可依**：三级阅读法（剪影→色彩→细节）、形状语言、3-3-3 规则（最多 3 个主导色 / 3 个主要服饰元素 / 3 个配饰焦点）、地标特征——详见 references/patterns.md。
4. **术语统一**：所有输出用 CONTEXT.md 术语表词汇，不发明新词。

## 工作流总览

```
阶段0 意图确认 → 阶段1 服饰标准库 → 阶段2 批量生成 → 阶段3 自动校验 → 阶段4 交付落盘
                                        ↑（单角色修订 / 全局复检为快捷路径）
```

## 阶段 0：意图确认

1. **确认剧种**：8 个内置剧种之一（玄幻仙侠/古装宫廷/民国年代/都市现代/科幻末世/悬疑探案/战神逆袭/甜宠偶像）。用户未明确指定时，**先从剧情描述推断**（如"穿越到现代"→都市玄幻/都市现代、"民国"→民国年代），仍无法确定再问。
2. **混合题材**：判定主剧种与副剧种（按 references/genre-styles.md 混合速查表，或问用户），融合规则以该文件"使用规则"为准。
3. **收集额外禁忌**：询问用户是否有个人禁忌清单（如"本剧禁露肩装"），与黑名单同效力（阻断级）。
4. **确认剧名**：用于落盘目录（剧名持久化）。

## 阶段 1：服饰标准库（标准先行）

1. 检查 `输出\剧名\服饰标准库.md` 是否已存在（**剧名不带书名号**）：
   - **存在** → 加载为本次标准（不重建）
   - **不存在** → 按 references/genre-styles.md 对应剧种模板建立：
     - **配色板**：从该剧种"配色倾向"扩展为全剧配色，全部 hex 数值。**容量规则**：角色数已知时，配色板色数 ≥ 角色数（每角色独占主色），不足则增加同色系变体色扩充
     - **纹样母题清单**：从该剧种"纹样母题"确定 3-5 个全剧通用母题
     - **服装制式**：男女各 2-3 套基础款（由白名单元素组合）
     - **禁忌清单**：该剧种黑名单 + 用户额外禁忌
     - **渲染风格**：1 个词/短语锁定画风（如"高精度 3D 国漫写实三维渲染""物理渲染（PBR）材质""写实国漫三维质感"），全剧统一，嵌入每段生图提示词
2. 保存到 `输出\剧名\服饰标准库.md`（**剧名不带书名号**，如 `输出\青云令\`）。

## 阶段 2：批量生成

### 2.1 输入解析（双模）

- **结构化输入**（表格 / JSON / Markdown 表格，推荐）：`角色名 | 身份 | 性格关键词 | 特殊设定` 逐行 → 直接使用。
- **自然语言输入**（一段描述）：先解析为结构化角色清单，**解析结果先给用户确认**再继续。
- 字段不足时（缺性别/身份等）：按剧种默认补全并标注，或询问用户。

### 2.2 逐角色三段式生成（每个角色依次执行）

**① 定内核（chunpu 方法论）**
- 从角色身份/经历/性格出发：先开脸定善恶（眼神、眉宇、口鼻线条）→ 再身形定品性（体型、线条软硬）→ 气质神态（站姿、神态）
- 反模板反套路：拒绝标签化（"高冷=冰山脸"）、拒绝完美比例、找出记忆点

**② 落视觉（omer-metin 方法论）**
- 剪影骨架：确定 2-3 个地标特征（按 patterns.md"剪影设计技法"）
- 配色：从标准库配色板取色（主/次/点缀，最多 3-4 个主导色，十六进制色值）
- 服饰细节：从白名单取材（上衣/下装/鞋/材质），纹样从母题库选用，配饰承载角色故事

**③ 产出角色条目（表格，字段固定）**

| 字段 | 内容 |
|---|---|
| 角色名/定位 | 名字 + 剧中定位（如"女主·神医穿越"） |
| 基础信息 | 身高、**头身比（如 6.5 头身，数值化）**、体型、外表年龄、人生经历关键词 |
| 面部特征 | 按身份锁固定顺序：脸型骨相→肤色肤质→眉形→眼型→瞳孔色→鼻型→唇形→发型发色→疤痕/痣/胎记（以上为身份锁，逐字段复用、禁止二次推断）→妆容→头饰（造型层，可按造型改变）；**若输入已提供主流水线身份锁（含推断标注），身份锁部分逐字段复用** |
| 全身穿搭 | 上衣、下装、鞋、服饰材质、配色（hex） |
| 配饰 | 首饰/眼镜/帽子/背包/武器等（每件附叙事理由） |
| 剪影地标 | 2-3 个辨识度特征 |
| 表情表 | 主角必填：中性/喜/悲/怒/惊/坚定 |
| 生图提示词 | 双图锚点（与主流水线一致；本裁头三视图的背面格 = 该角色全身图背面图的唯一真相源，主流水线需要背面时优先复用）：图一=脸部参考图（默认正面，剧本/描述指定朝向时按指定、表情为标准中性——面部肌肉完全放松：双唇自然闭合、嘴角不扬不垂、眉毛平展无高低、眼睑自然开合无眯眼、下颌放松、均匀柔光、单人、中性灰背景 #B8B8B8）；图二=裁头服装三视图（同一画面横排三格：正面/侧面/背面全身站姿，三格头部一律裁除不入画，**固定中性站姿：手臂自然下垂、双脚与肩同宽、不摆任何展示姿势**，完整展示服装剪影/配色/纹样/配饰），嵌入剧种约束与渲染风格 |

**阶段完成标准**：角色清单全部角色均已产出条目并通过生成时自检。

### 2.3 角色差异化（横向检查）

生成每个新角色前，对照已生成角色检查（执行"队列测试"思想）：
- 主色不撞车（每个角色独占主色）
- 剪影地标不重复
- 形状语言有区分
- 体型/头身比有变化

## 阶段 3：自动校验 + 违规报告

**机械检查走脚本，语义检查走对照**——两层校验缺一不可：

1. **机械检查（硬门禁）**：在本模块目录（`服饰设计/`）的上级技能根目录运行 `python 服饰设计/scripts/check_costumes.py <服饰标准库路径> <角色服饰标准表路径>`，自动检查：黑名单词扫描（阻断）、配色十六进制色值是否在板内（警告）、头身比存在（警告）、主色撞车（警告）、三视图角度声明（警告）。**脚本报告存在阻断项时禁止交付**，修复后重跑至通过。
2. **语义检查（LLM 对照）**：按 references/validations.md 逐条核对脚本覆盖不到的项（文化敏感、剪影地标、形状语言区分、表情表、叙事对齐等）。

汇总规则：

- **阻断项（Blocker）**：黑名单命中、跨剧种违禁元素、文化敏感未审查 → **必须修改**，不修改不交付
- **警告项（Warning）**：配色出界（不在标准库配色板内）、角色撞车（主色/剪影/纹样重复）、字段缺失 → 建议修改，可带警告交付

输出 `校验报告.md`：角色 × 违规项表格 + 逐条修改建议（违规成因参照 references/sharp-edges.md 诊断库向用户解释）→ 修改后复检，直到**无阻断项**。用户明确拒绝修改阻断项时：允许交付，但报告显著标注"未达标：存在未修复的阻断项"。

## 阶段 4：交付与落盘（剧名持久化）

独立触发时落盘到当前工作目录下的 `输出\剧名\`（**剧名不带书名号**，如 `输出\青云令\`）；**与「资产提取」主流水线衔接时，输出目录被桥接器覆写为角色清单所在目录**（`<资产库>\服饰设计\<剧名>\`，遵循数据外置原则，用户数据不进技能包）：
- `服饰标准库.md`（本剧标准，下次同剧种自动加载）
- `角色服饰标准表.md`（全部角色条目表格）
- `校验报告.md`（最终报告：机械脚本结果 + 语义检查结果，阻断项清零、警告项列表）
- 可选：`角色服饰标准.json`（结构化导出，供自动化管线）

交付时告知用户：下次同剧种工作将自动加载该标准库。

## 快捷模式

### 单角色修订模式
**触发**：用户要求改某个角色的服装（如"把女主的裙子换一下"）。
**流程**：只重跑目标角色（定内核→落视觉→条目），**标准库不动**；修订后**重跑校验脚本 + 语义检查**（阻断项必改）；更新角色表与报告。

### 全局复检模式
**触发**：标准库变更后（换配色板、增黑名单项），用户要求全部复检。
**流程**：不重新生成，仅对全部已生成角色重跑校验脚本 + 语义检查，输出更新后的校验报告。

## 质量底线

- **纯中文输出**：角色条目与生图提示词正文全程纯中文；十六进制色值（如 `#E63946`）、数字比例（如 16:9、6.5 头身）允许出现。英文术语只允许出现在参考文档的括注里，不得进入交付文本
- 服饰元素全部取自剧种白名单，始终在红线（黑名单）内——越线即阻断
- 配色一律用十六进制色值指定（如 `#E63946`），标准库外取色记警告
- 纹样一律从标准库母题库选用
- 阶段 3 校验是每个批次的必经收尾，阻断项清零后才算交付
- 混合剧种同时对照主、副剧种两套约束（黑名单取并集）
