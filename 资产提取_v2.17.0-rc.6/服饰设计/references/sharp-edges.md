# 角色设计诊断库（Sharp Edges）

来源：omer-metin character-design（英文版），全量中文化。本文件列出**关键失败模式与成因**——用于诊断已有设计的问题并向用户解释风险。按严重级别分级：critical=致命，high=严重，medium=中等。已按本技能范围裁剪纯游戏向条目（动画就绪、缩放测试）。

---

## 先细节后剪影（Detail Before Silhouette）

**严重级别**：critical
**场景**：设计师先堆服饰细节、配饰和材质，基础轮廓还没定型。

**成因**：剪影是角色的名片。如果缩略尺寸下不可读，再美的渲染也救不了。马里奥、索尼克、林克能在 16 像素时被认出，因为剪影是先设计的。先抠细节，最后得到的是"看着酷但实际没法用"的视觉噪音。

**解法：剪影优先工作流**
1. 用纯色块起稿（只用黑色填充，缩略尺寸设计，只要体量与比例）
2. **三形状测试**：能否用 3 个简单形状描述剪影？（"圆头、方身、三角披风"）需要 3-4 个以上就简化
3. **地标测试**：找出 2-3 个独特凸起（尖耳、背后武器、独特发型）——任何尺度下可见
4. 之后才加细节：细节是"挣来的"，每加一笔回头检验剪影是否仍成立

**剪影检查表**：
- [ ] 缩小尺寸仍可辨？
- [ ] 不对称（不是无聊的镜像）？
- [ ] 有清晰负空间（不是一团糊）？
- [ ] 有独特地标（不是通用人形）？
- [ ] 与其他角色剪影不撞车？

**症状**：设定图好看但实际观感"糊"；远处认不出角色；角色融进复杂背景；填黑后是团通用人形。

## 过度设计视觉噪音（Over-Designed Visual Noise）

**严重级别**：critical
**场景**：每个表面都有纹样，每条肢体都有配饰，多个视觉焦点互相打架。

**成因**：眼睛不知道该看哪里。细节在远处糊成噪音。角色"忙"而不"精"。这是业余第一大错——把复杂当质量。记住：马里奥就红帽蓝背带裤胡子，林克就绿衣尖帽剑。大师知道：简洁 = 难忘。

**解法：删除审计**
对每个设计元素问：
1. 移除它会伤害剪影吗？（会→保留）
2. 移除它会改变角色身份吗？（会→保留）
3. 有人会注意到它消失了吗？（不会→移除）

**3-3-3 规则**：
- 最多 3 个主导色
- 最多 3 个主要服饰元素
- 最多 3 个配饰焦点

**焦点层级**：主焦点（第一个抓住视线，通常是脸）→ 次焦点（第二个，武器/手部）→ 三级（其余全部让位）。

**减法技法**：删掉 30% 细节 → 变小测可读性 → 变好了就再删 20% → 直到删除反而变差为止。"拿不准就去掉。"——迪士尼原则。

**症状**：眼睛不知道看哪；每次看都像不同角色（无焦点）；远看发糊；"用力过猛"感。

## 团块剪影综合征（Blob Silhouette Syndrome）

**严重级别**：critical
**场景**：角色填黑后就是一个无区分度的椭圆或通用人形。

**成因**：团块剪影在远处不可见。观众无法把角色和其他人区分。太多"写实"角色栽在这——看起来都像别人。

**解法：破团技法**
1. **加不对称**：双手不同、打破头型的发、不对称服饰、单侧配饰
2. **造负空间**：站姿双腿分开、手臂离体、披风/布料制造形状、服饰开衩镂空
3. **加地标**：独特头型（耳/角/发/帽）、武器工具剪影、非常规体型、独特站姿
4. **夸张一个特征**：巨手（打手）、高瘦（优雅）、宽肩（守护）、独特腿型（疾行者）

**"能是谁都行吗"测试**：把剪影给不知道你剧的人看。如果他描述不出独特点，就是团块。

**症状**：剪影不可辨；被误认为通用人形；无地标特征；融入复杂背景；队列测试失败。

## 色彩冲突或消失（Colors That Clash Or Vanish）

**严重级别**：high
**场景**：设定图光线下好看，实际剧集场景里不对。

**成因**：角色存在于动态环境里。昼夜、不同场景、战斗特效——角色必须全程可读。只在摄影棚中性光下成立的配色，到真场景就废。

**解法：环境免疫配色**
1. **极端测试**：暖环境（夕阳/火光）、冷环境（夜景/雪/水下）、中性环境（阴天/灰调）、高对比（烈日/深影）
2. **明度对比**：浅色元素与深色元素必须保持对比；如果全是中间调，会在中间调环境里隐形；至少包含一个很亮和一个很暗的明度
3. **饱和度锚点**：一个饱和色在任何环境下"跳出来"（通常是主色）
4. **色相避让**：避免与环境同色相的角色主色——绿衣角色站森林=隐形；蓝衣角色站水里=隐形。除非靠饱和度/明度制造对比

**常见失败**：红衣角色+熔岩橙背景=消失；蓝衣+蓝天=消失；去饱和角色+灰环境=隐形；全高饱和=眼睛疲劳、谁也不突出。

**症状**：角色在不同场景"看起来不一样"；某些场景看不清角色；截图效果随场景忽好忽坏。

## 文化不敏感雷区（Cultural Insensitivity Landmines）

**严重级别**：critical
**场景**：不懂文化背景就把文化服饰、符号、特征当装饰用。

**成因**：有害刻板印象会造成现实伤害。不专业的设计师没有"我不知道"的借口。这损害作品口碑、赶走观众。

**解法：文化责任协议**
1. **先研究再引用**：了解元素的历史与含义；知道谁在用、为何用；分清神圣与世俗；了解曾被怎样滥用
2. **咨询文化中人**：多个视角而非一人；付费请教专家；对方说有问题是听而不是辩解
3. **避开常见陷阱**：宗教符号当"酷"装饰；圣物当时尚配饰；把"部落风"当万能美学；把互不相关的文化元素搅成"民族大杂烩"
4. **代表 vs 挪用**：代表 = 角色来自该文化、被尊重地设计；挪用 = 为审美挪用文化元素而不理解
5. **虚构文化设计**：不要用虚构文化影射真实刻板印象；避免"邪恶种族"套路；给文化以复杂而非漫画化

**红旗自查**：
- [ ] 角色的文化是其唯一性格标签？
- [ ] 我在把宗教/圣物当装饰？
- [ ] 设计依赖刻板印象？
- [ ] 该文化的人会觉得被冒犯吗？
- [ ] 我有资格做这个设计决策吗？

**症状**：文化成了服装而不是人物深度；依赖刻板视觉速记；圣物被当装饰；被批评时防御性回应（"只是虚构"）。

## 同质化阵容综合征（Samey Cast Syndrome）

**严重级别**：high
**场景**：角色们排开站，像同一个人的换装秀。

**成因**：观众无法瞬间区分角色 = 基本沟通失败。故事里，认错人破坏沉浸。视觉多样性不只是好看——是功能性设计。

**解法：队列差异化测试**
把全部主角剪影并排。对每个角色问：
- 这个剪影独特在哪？
- 会和别人混淆吗？
- 哪一个元素让人认出他？

**差异化维度**：
1. **体型**：变化身高、宽度、头身比、体格
2. **剪影地标**：每个角色独有地标，两人不共享同一地标（发型、配饰、武器、服装形态）
3. **色彩分配**：每个角色"独占"一个主色；次色避免过度重叠；远看凭色识人
4. **形状语言**：变化主导形状族——圆角色、方角色、三角角色，同团队内也应有差异
5. **站姿体态**：默认姿态应独特；体态传达性格；队列不该像克隆人换装

**多样性检查表**：
- [ ] 至少 2 种体型？
- [ ] 每个角色有独有剪影地标？
- [ ] 每个角色有独有主色？
- [ ] 全阵容形状语言有变化？
- [ ] 1 秒内能认出每个角色？

**"三词速描"测试**：能否用 3 个词描述每个角色的长相？不同角色用词相同 = 重设计。

**症状**：观众认错人；角色像彼此的"换皮"；剪影队列像同一个人换装；群像无视觉层级；必须靠名字才能区分。

## 比例不一致（Proportion Inconsistency）

**严重级别**：medium
**场景**：同一角色在不同作品里头身比、肢体长度、身形时变。

**成因**：比例不稳定让角色"走样"、不专业。观众会下意识注意到。破坏沉浸，也说明缺乏质量把控。

**解法：比例文档化**
建立角色设定表：
1. **头身比**：角色几头身？精确记录："角色 6.5 头身"
2. **关键尺寸**：头宽、肩宽（X 头）、臂长（肩到腕）、腿长（胯到踝）、躯干长
3. **比例参考线**：画水平线标记关键高度——眼位、下巴、肩、腰、胯、膝、踝；所有作品必须对齐
4. **叠加层**：做一张正确比例的透明叠加图，所有新图对着检查

**常见漂移**：头随画风情绪变大变小；动作姿势拉长肢体后不还原；不同人画身形就变；"英雄"姿势永久夸大比例。

**设定表必备**：
- [ ] 头身比已记录
- [ ] 三视图（正/侧/背/3-4）
- [ ] 与其他角色的体型对比
- [ ] 允许的风格化范围
- [ ] 常见漂移的"不要"示例

**症状**：角色在不同作品"感觉不一样"；画师问"哪个版本是对的"；角色辨识度飘忽。

## 可读但无聊陷阱（Readable But Boring Trap）

**严重级别**：medium
**场景**：设计过了所有测试，但没灵魂、没记忆点、没有任何特别之处。

**成因**：技术达标但没有创造力 = 墙纸角色。这些设计"安全"，却输掉了最重要的测试——有人真的在乎这个角色吗？无聊设计不会让人产粮、cosplay、情感连接。

**解法："会有人画这个吗"测试**
诚实自问：
- 会有人为这个角色画同人吗？
- 会有人想 cos 这个角色吗？
- 十年后有人记得这个设计吗？
- 这个角色和每个同类角色有何不同？

**反无聊技法**：
1. **一件怪事**：每个难忘角色都有一样非常规元素。给角色一个意料之外的东西
2. **把某一元素推到极致**：眼睛大就大得夸张；强壮就壮到夸张。敢
3. **意外组合**：把两个不搭的东西放一起（骑士+朋克美学；可爱动物+威胁配色）
4. **明确的观点**：设计要有立场，不讨好所有人，坚定一种情绪、风格、宣言
5. **2 秒推销**：2 秒内能说清这角色吗？"用吉他打架的朋克公主"——推销词无聊，设计就无聊

**无聊红旗**：
- [ ] 全是"安全"选择？
- [ ] 没有任何意外或非常规？
- [ ] 多个角色能用同一句话描述？
- [ ] 没有元素推到有趣极致？

**症状**：没有同人产出；观众记住剧情记不住角色；设计"通用感""委员会感"；角色可被互换。

## 背景故事无视觉支撑（Backstory Without Visual Support）

**严重级别**：medium
**场景**：角色设定写了丰富背景故事，但设计完全没体现。

**成因**：如果设定说"身经百战的老将、悲剧过去"，设计却是"路人甲"，视觉叙事就失败了。设计本身就是角色沟通——好角色应该在没有任何文字说明的情况下，暗示出自己的故事。

**解法：视觉叙事审计**
对每个背景元素问："**设计如何体现这一点？**"

示例转换：
- "身经百战的老将" → 伤疤、磨损的装备、沉稳姿态
- "没落贵族" → 精致衣物的残迹、家族戒指、讲究的仪态
- "悲剧过去" → 悲伤的静息表情、纪念物配饰
- "自学成才的法师" → 拼凑装备、书不离身
- "幸存者" → 实用服装、多件小武器

**静默测试**：把设计给完全不知道背景的人看。他们对角色的猜测和设定一致吗？不一致 = 设计失败。

**叙事层次**：
1. **明显层**（一眼读懂）：身份（甲=战士、袍=法师）、阵营（色/符号）、威胁度（体型、武器）
2. **可发现层**（奖励细看）：性格（姿态、表情、配饰）、经历痕迹（伤疤、磨损、留存的物件）、关系（与其他角色的呼应元素）
3. **深层**（给考据党）：象征元素、文化引用、彩蛋

**对齐检查表**：
- [ ] 设计体现职业/身份？
- [ ] 设计暗示过去？
- [ ] 设计显示性格特质？
- [ ] 设计表明阵营/归属？
- [ ] 设计暗示经济地位？
- [ ] 设计传达情绪状态？

**症状**：背景故事与视觉脱节；观众对角色行为的猜测与设定不符；设计能套进任意背景故事；视觉讲的故事和设定不同。
