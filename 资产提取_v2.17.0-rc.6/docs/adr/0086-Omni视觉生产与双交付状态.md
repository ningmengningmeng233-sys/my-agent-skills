# 0086. Omni 视觉生产与双交付状态 (Omni Visual Production & Dual Delivery Lines)

- **状态**: 采纳
- **日期**: 2026-09-16
- **版本**: v2.15.0-rc.1
- **作者**: 柠檬才不萌

## 背景与问题

ADR-0085 划定了「叙事反推是核心、视觉生产是可选下游」的边界，并交付了输入规范化、四类资产子类型与视觉需求、双交付状态线的最小实现。本 ADR 记录**把这条边界落成可执行的视觉生产管线**时确定的关键工程决策：

1. 视觉风格必须**版本固定、可追溯、可校验**，否则「用哪个风格生成的」无法回答；
2. 参考图必须**声明职责**，否则材质参考会漂移成身份参考、风格参考会把别人的服装复制过来；
3. 生成结果必须**逐项独立、可回溯、可定向返工**，否则一次多格图与一次失败就污染整条下游；
4. 无 API 时必须**可手工执行**，且**绝不假装生成成功**；
5. 视觉验收与资料验收必须**互不阻塞**，且不得用机器检查冒充人工审美结论。

## 决策

### 1. 风格包版本化 + 内容哈希固定（工单02-Task1/2/3）

- 风格登记表 `references/styles/registry.toml` 记录每个风格的**中文正式名、别名、内部标识、验证等级、生命周期、包版本与内容哈希、分享许可**；由 `references/画风库.md` 全量派生并由测试钉死一致性。
- `luminous-xianxia_仙侠CG风格库` 是「仙侠国风电影CG」的唯一视觉母版，经 `scripts/sync_stylepack.py` **确定性同步**为 `references/styles/仙侠国风电影CG/1.0.0/`：
  - 内容根为 `<版本>/private/`，清单 `<版本>/manifest.toml` 记录每个文件的相对路径 / SHA-256 / 字节数 / 类别 / 分享许可；
  - 同步先写临时目录、校验后原子替换，不跟随符号链接、不复制 `.env`、不写入任何机器绝对路径；
  - 风格定义层（Markdown）入库，参考图（71.6 MB）按 manifest 校验但不入 Git，可由同步器重建。
- 旧 H7 外壳中与母版冲突的表述（作品/工作室名定性、瓷亮皮肤、强制高饱和、镜面高光背书、强制图板）全部清除；E1 的运镜/时长/节奏约束迁出到 `references/video_styles/`，静态解析器**不读取**该目录，并由测试守卫（`find_video_leaks` 命中即抛 `STATIC_VIDEO_LEAK`）。

### 2. 视觉计划 TOML 是唯一机器事实源（工单02-Task4）

`VisualPlan` / `VisualTask` / `ReferenceBinding` / `AttemptRecord` / `QcRecord` 定义在 `scripts/engine/visual_schema.py`：

- 任务 ID 固定为 `<资产ID>-<任务种类>-vNN`；
- 状态为内部英文枚举，用户界面一律经 `user_status_label` 显示中文（待生成 / 已生成待检查 / 需修改 / 已通过 / 可作为参考 / 需要人工决定 …）；
- 画幅固定：正脸·后脑·道具 1:1；服装独立图·人物全身 2:3；场景母版 16:9；
- 写入**确定性**（同一对象两次写出字节一致）且**原子**（临时文件 + `os.replace`）；中文直写不转义为 `\uXXXX`；Windows 反斜杠归一化为 `/`；
- 校验器拒绝：未知资产、任务 ID 格式错、重复 ID、非法种类/状态/职责、绝对路径与越界路径、自依赖、依赖环、未知依赖、超过三轮、画幅不符、风格未固定或与计划不一致、缺事实来源、**已开工的下游依赖未通过的上游**。
- `计划阅读版.md` 由 TOML 渲染，**改 Markdown 不改变任何状态**。

### 3. 人物按分级独立出任务（工单02-Task5）

- P0/P1：正脸、后脑、服装独立正面、服装独立背面、人物全身正面、人物全身背面；
- P2：正脸、人物全身正背；剧情需要时（显式参数）补服装正背；
- P3：人物全身正面；存在背面镜头时补背面。
- 依赖链：正脸 → 后脑 → 服装正背 → 全身正背，缺中间环节时自动下沉到链上**最近**的已有前置。
- 规划**只读资产索引**，不从旧提示词反推事实；重复执行幂等（保留已完成记录、人工锁定字段与备注，事实变化标记 `NEEDS_REVIEW`）。
- 服装独立图模板强制**隐形人体支撑**（领口与肩线完整、内部支撑不可见、无皮肤残端、无断颈造型），全套模板禁止多格拼版并禁止注入时间维度。

### 4. 参考图按职责最小路由（工单02-Task6）

`route_references(task, stylepack, accepted_assets, limit)`：

- 职责只允许 identity / structure / style / material / lighting / space；
- 上游已通过图片提供身份/结构/空间，内置包主体路由提供主风格（场景为空间、道具为形制），实际材质按已声明材质路由；
- **后脑刻意不使用 face 路由**（避免继承正面构图）；未登记材质不发明；
- 超出引擎上限按 身份 → 结构 → 主风格 → 关键材质 → 次要材质 裁剪，被省略项与原因记入 `omitted`。

### 5. 引擎无关执行器 + 最小发送（工单03-Task1/2/3）

- `ImageExecutor.generate(request) -> GenerationResult` 是唯一执行入口；手工模式输出任务包并返回 `AWAITING_MANUAL_RESULT`，**不产生任何图片**、不冒充已生成。
- Gemini 适配器只读 `GEMINI_API_KEY` / `GEMINI_IMAGE_MODEL` / `GEMINI_QC_MODEL`，**绝不回退读取 `OPENAI_API_KEY`**；SDK 只在该模块内延迟导入；响应必须恰好一张合法图片，空图/多图/错误 MIME 一律拒绝；网络暂态与 429 只做**传输级**退避，内容级拒绝立即上抛（不在适配器内偷偷重复收费）。
- 请求编译器按固定分块（任务目标 → 不可变事实 → 构图 → 风格 → 参考职责 → 材质 → 禁止项）组装提示词；只发送当前任务事实与选中参考图；Gemini 与 Codex 两个 profile 只允许调整块的表达顺序，**事实集合必须相同**；提示词超限即 `PROMPT_TOO_LARGE`（防止夹带整章原文）。

### 6. 产物可回溯、质检结构化、返工有上限（工单03-Task4/5/6）

- 产物目录固定为 `视觉资产/任务/<task_id>/attempt-NN/{image.png,request.json,response.json,qc.toml}`；文件名**固定**，绝不来自模型返回文本或用户原始名称；拒绝越界路径、伪装扩展名、空文件、超限文件；响应元数据写入前清除密钥与认证头；同一 response ID / 同一图片哈希重导入不产生新轮次。
- 检查结果统一为 `QcResult(decision, issues, checker, checked_at, input_hashes)`；问题码覆盖老罗失败反例（风格漂移、比例异常、断颈残留、背面残头、禁止拼版、正背不一致、主体裁切）；**任何阻断级问题不得进入 ACCEPTED**；缺证据、引用错误任务、输入哈希不一致、未知问题码、人工缺操作者标签一律返回 `QC_UNTRUSTWORTHY`。
- 状态转换白名单化，非法跳转抛 `InvalidVisualTransition`；每项最多自动返工 **3 轮**；返工必须依据结构化问题码改写指令，同一批指令重复即 `INEFFECTIVE_RETRY` 并**立即转人工决定**（不再消耗额度）；上游替换后下游转 `NEEDS_REVIEW`，旧图保留但取消参考资格。

### 7. 拼版只由已通过图片本地合成（工单03-Task7）

三宫格/参考板**只能由本地 Pillow 合成**，输入必须是 ACCEPTED/READY_AS_REFERENCE 产物；拼版清单记录输入哈希，任一输入被替换即判定过期。

### 8. 双交付状态线各自独立签发（工单03-Task7）

- 资料交付：既有 `verify`（不调用视觉门）；
- 视觉交付：独立 `verify-visual` / `check_visual_delivery.py`，全部必需任务通过 + 依赖新鲜 + 风格包哈希一致才签发 `视觉资产/视觉交付清单.json`；可选任务（拼版）失败不阻断但必须列入 `incomplete`；
- `status --json` 同时给出两条线与视觉统计。

### 9. 迁移、停用与双包（工单04-Task1/2/4）

- 旧视觉产物**只读识别 + 非破坏迁移**：先备份、旧文件哈希逐一致、新产物只写 `视觉资产/`，重复执行幂等；旧图片登记 `legacy_unreviewed`（默认不可作为参考）；
- 风格生命周期单向 `active → deprecated → disabled → removable`；被项目引用即拒绝物理删除，`remove` **只产出待删除清单**；
- 私人包与分享包分别构建、名称不同：分享包按 `share-policy.toml` 排除来源图与许可未确认文件，缺运行必需参考时在包内声明 `VISUAL_STYLE_INCOMPLETE_FOR_SHARE`；两包均零容忍 `.env`、真实密钥、绝对桌面路径、生成缓存、用户资产库与未登记图片。

### 10. 验收分级（工单04-Task3/5/6）

- 金标准契约覆盖老罗、女性长发、复杂甲胄、宽袍披风、场景母版、代表道具与失败反例集，只验证计划与 rubric，**`human_visual_review` 一律留空**；
- 离线门 `测试/run_visual_offline.py` 覆盖正例链 + 失败矩阵 + 恢复矩阵，**零真实 API 请求**；
- 真实 Gemini 抽样手册 `docs/验收/v2.15.0-Gemini视觉抽样.md` 自包含（包外密钥、唯一运行目录、老罗六任务、费用停止点、请求上限、恢复方法、结果路径），十项人工表保持空白。**未执行即如实写 `NOT_RUN`**。

## 后果与权衡

**收益**

- 每条资产图片都能回答「用哪个风格版本、哪张参考、哪轮提示词、哪次检查」；
- 视觉可以失败、暂停或未启用而不影响资料交付；两条状态线可分别签发；
- 无密钥时链路仍然可用（手工导出/导入），且不会产生假图片。

**代价**

- 视觉参考图（71.6 MB）不入 Git，精简安装需重新同步一次母版；
- 风格包哈希固定后，母版更新只提示、不自动改变已有项目（需要显式升级）；
- 每项资产最多 3 轮自动返工，超出即转人工，自动化程度有上限（这是有意的成本闸门）。

**未做**

- 未在本轮重新蒸馏其他旧风格（保留为「旧版未验证」）；
- 未构建视频生产管线（仅把 E1 的视频规则迁到独立配置）；
- 未执行真实 Gemini 抽样与人工视觉验收：v2.15.0-rc.1 只是**候选版**。

## 补充（v2.15.0-rc.2 终验修复）

rc.1 的终验发现本 ADR 描述的能力**并未真正接通**：`run`/`export` 只读 `task.references`（计划里恒为空），路由器从未被 CLI 调用；`build_generation_request` 接收 `stylepack` 却未使用，实际提示词仍来自旧 `画风库.md`/H7；Gemini 适配器对缺失参考发送**空字节**图片并硬编码 PNG。以下为修正后的**实际**契约：

1. **唯一编译链**：新增 `engine/reference_resolver.py`（逐文件校验存在性/非空/SHA-256/真实 MIME，扩展名与魔数冲突即拒，缺失/空字节/哈希不符/路径越界各给稳定码，**绝不降级为空图**）与 `engine/visual_request_chain.py`（`run` 与 `export` 共用的唯一入口）。参考由**编译期路由**产出，计划只承载任务事实——因此计划中 `references` 为空是正常设计，不是缺陷。
2. **身份参考独立于生成顺序**：依赖链只表达生成顺序（全身正面的最近前置是服装背面），身份必须由「同资产已通过的正脸」单独路由，否则全身/服装任务会丢身份锁。
3. **权威包是唯一风格源**：共同不变量、生成公式（BASE_STYLE/LIGHT_COLOR/COMPOSITION）、主体基线、材质基线与负面提示词全部取自 `references/styles/仙侠国风电影CG/1.0.0/private`；旧 H7 卡片仅用于迁移兼容，**不参与**新任务编译。主体基线按任务种类选择（全身/服装/后脑使用全身基线，不继承正脸裁切）。
4. **包完整性可自证**：`engine/stylepack_verify.py` 是清单校验的唯一实现（同步脚本、发布构建、运行期编译共用），`pack_content_hash` 提供内容指纹。权威包缺图/漂移在编译前即以 `STYLEPACK_UNAVAILABLE` 拒绝。
5. **只发真实图片**：`GenerationRequest.resolved` 携带已校验对象，适配器只发其真实字节与真实 MIME；未解析的参考以 `REFERENCE_UNRESOLVED` 拒绝，杜绝「模型以为有参考却收到空图」。
6. **视觉门只有 DELIVERED 算通过**：`NOT_ENABLED` 退出 3（`VISUAL_NOT_ENABLED`），`BLOCKED` 退出 1；失败不覆盖历史有效清单。资料线仍完全不读视觉线，两线独立不变。

**代价（新增）**：视觉路径的启动成本略增（每次编译要读权威包并校验 58 个文件的哈希）；权威包内容一旦变化，旧计划立即失效，必须显式升级项目。
