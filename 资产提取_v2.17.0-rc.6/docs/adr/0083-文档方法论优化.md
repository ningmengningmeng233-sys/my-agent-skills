# ADR-0083: 文档方法论优化（按「优化AI技能」方法论体检）

- 状态: Accepted
- 日期: 2026-09-06

## 背景

安装 CherryStudio/Codex 侧的「优化AI技能」方法论（上下文指针/两种负载/信息层级/领先词/否定式失败模式/沉积清理），对 SKILL.md 做一次全面体检。发现的偏离：

1. **description 沉积**：常驻指针里挂着 7 行「完整能力（v2.8.0）」能力清单——正文已承载的身份内容被复制进永久上下文负载；触发分支存在同义重复（「反推人物场景道具」与「提取人物场景道具」同一分支写两遍）。
2. **参考表埋步骤**：错误处理矩阵（10 行纯参考）位于执行步骤与数据布局之间——「文件内参考埋住步骤，关注被分摊成掷硬币」。

## 决策

1. **description 剪枝**：删除能力清单块；触发分支收敛为一分支一触发；保留反触发句（防止通用生图类请求误入）。
2. **错误处理矩阵下放** `references/错误处理矩阵.md`，SKILL.md 留一行上下文指针（说明何时触达：出现异常/报错分支）。
3. **保留项（体检通过）**：步骤 0-8 的完成标准（清晰+要求量双达标）；断点定位/数据布局共位；v2.11.x 近三条日志（其余已披露至 CHANGELOG）；领先词体系（断点续跑/证据收口/出处强制/身份锁）已充分。

## 被放弃的备选

- **QUICKSTART 与 SKILL.md 数据布局合并为单源**：两者受众不同（人/代理），且目录布局属「环境即真相」的可查项；保留各自视角、内容保持一致。
- **v2.11.x 三条日志也披露**：最近的变更对运行口径仍有直接影响，保留；更早已在 CHANGELOG。

## 影响

- `SKILL.md`（description/错误矩阵指针/版本）
- `references/错误处理矩阵.md`（新增）
- 版本 v2.12.0
