# ADR-0040: 道具材质身份锁定与状态变化三段式

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问修正确认：道具基础设定图锁定「材质身份」（基材/粗糙度/光泽/使用痕迹/边缘），但衍生状态变体允许材质变化——必须从基础材质身份出发、按物理逻辑变化，并写明「原本X → 因Y → 变为Z」；未受影响区域沿用基础原值，禁止凭空换材料。

## 决策

1. 基础道具模板明确「材质身份一经写出即锁定」。
2. 衍生道具状态变化采用三段式，从基础材质身份出发。
3. 描述补全道具部分写入材质身份四件套作为后续出发点。

## 影响

- `templates/基础提示词模板-道具.md`、`templates/衍生提示词模板.md`、`templates/描述补全模板.md`。
