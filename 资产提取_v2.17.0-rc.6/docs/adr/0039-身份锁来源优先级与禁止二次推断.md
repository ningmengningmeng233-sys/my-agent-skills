# ADR-0039: 身份锁来源优先级与禁止二次推断

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：身份锁来源优先级为 视觉描述/原文 →（缺失字段）按名称/等级/题材克制推断并标注「（推断）」；一经锁定，衍生与服饰设计必须复用，禁止二次推断。

## 决策

1. 原文/描述优先；缺失字段才推断并在字段后标注「（推断）」。
2. 推断值写入基础提示词后即锁定，衍生/服饰设计复用推断值并保留标注。
3. 描述补全、人物基础、人物衍生、服饰设计四处同步。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`、`templates/描述补全模板.md`、`服饰设计/SKILL.md`。
