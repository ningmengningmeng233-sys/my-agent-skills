# ADR-0004: 画风库与题材映射

- 状态: Accepted
- 日期: 2026-08-16

## 背景

用户反馈画风定性能力弱，要求"根据实际需求输出不同的画风"。素材源：作者自备国风定性技能目录（seedance-3d-skill / manga-style-video / manga-drama / higgsfield-seedance2-jineng / remotion-guofeng-starter）。素材须**精读全文**后吸收，不允许只读文件表面。

## 决策

1. **题材来源**：`--genre` 显式指定（沿用 generate_prompts.py 已有参数），不自动推断（书名推断错 → 整本风格返工）。
2. **必须确认**：生成前回显「本次题材 → 默认画风」映射，用户确认或覆盖后才生成；不允许静默使用默认值。
3. **画风粒度**：全局默认画风 + 调度清单行级「画风」列覆盖（个别变体可单独换风格）。
4. **`--style` 取值域**：
   - 画风库内名称（如 `浮世绘风`）→ 精确命中卡片：中文定性 + 英文标签块 + 负面词注入；
   - 任意自由描述（如 `赛博朋克+水墨晕染,冷色调`）→ 原样注入模板，不进库不校验。
5. **画风库**：`references/画风库.md`（**42 张**风格卡片：中文定性 + 英文标签块 + 负面词；A 系 3D 国漫 / B 系国风 2D / C 系动漫 / D 系漫画 / E 系影视 / F 系商业 / G 系速查 / H 系用户组装，A1 为五层融合定性默认卡）；`references/题材-画风映射.md` 存题材→默认画风映射表，外部文件可编辑扩展。
   > ⚠️ 更新（2026-08-17，v2.4）：新增 H2-H6 五卡（民国谍战/武侠江湖/末日废土/中式怪谈/西幻史诗）与 D 系升级后共 42 张卡片，原「34 张」描述已过时。

## 权衡

| 备选 | 结论 |
|---|---|
| 自动推断题材 vs 显式 `--genre` + 确认 | 显式+确认（推断错返工成本 > 多敲参数成本） |
| 纯全局画风 vs 调度清单行级覆盖 | 行级覆盖（全局兜底 + 变体精调，调度清单本就用户可编辑） |
| `--style` 只收库内名 vs 只收自由文本 vs 两者 | 两者（库里复用精确风格，库外自由发挥，新增卡片走文件不进代码） |

## 影响

- 新增 `references/画风库.md`、`references/题材-画风映射.md`
- 改造 `generate_prompts.py`（--style 参数、题材→画风解析、生成前确认、画风块注入模板）
- 模板（基础/衍生/描述补全）增加画风注入位
