# ADR-0037: 身份锁固定字段顺序

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：身份锁按固定字段顺序书写，保证基础、衍生、描述补全、服饰设计四处可逐字段对齐，防止同字段跨模块漂移（基础写桃花眼、衍生写杏眼）。

## 决策

1. 固定顺序：脸型骨相→肤色肤质→眉形→眼型→瞳孔色→鼻型→唇形→发型发色→疤痕/痣/胎记等标志性特征。
2. 主流水线人物基础/衍生、描述补全、服饰设计角色条目面部特征全部按此顺序。
3. 衍生逐字复用按此顺序提取。

## 影响

- `templates/基础提示词模板-人物.md`、`templates/衍生提示词模板.md`、`templates/描述补全模板.md`、`服饰设计/SKILL.md`。
