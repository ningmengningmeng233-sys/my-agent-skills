# ADR-0022: 自动化画风确认强制显式 --style 与描述层纯中文检查

- 状态: Accepted
- 日期: 2026-08-19

## 背景

落地核查发现两处约束缺口：

1. `generate_prompts.py` 的 `--yes` 可以不带 `--style` 直接跳过画风确认，SKILL 虽写明自动化场景必须显式传 `--style + --yes`，但代码未强制，存在静默默认画风的偷懒路径。
2. 纯中文约定此前只对 基础/衍生提示词 做脚本级检查，`描述/` 三个合并文档只有模板约束，缺少机械校验。

## 决策

1. `--yes` 与 `--style` 绑定：自动化/管道场景 `--yes` 必须显式传 `--style`，否则直接报错退出（`--init-schedule` 不涉及画风确认，不受影响）。
2. `check_schedule.py` 新增 `scan_desc_pure_chinese()`：对 `描述/人物描述.md|场景描述.md|道具描述.md` 逐节执行纯中文检查（色值代码除外），违规计入「内容不合规·需重新生成」。

## 影响

- `scripts/generate_prompts.py`、`scripts/check_schedule.py`、SKILL 步骤 5/7 说明、单元测试。
