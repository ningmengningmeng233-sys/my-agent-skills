# ADR-0026: 新增「高精度 3D 国漫设定集风」画风卡片

## 状态

已接受（2026-08-19）

## 背景

用户通过 6 张参考图（斗罗大陆/玄机科技角色设定集：写实比例、PBR 材质、纯白/浅灰摄影棚背景、正侧背四视图、华丽金属/宝石/皮革装饰）确认目标画风，并命名为「高精度 3D 国漫设定集风」。现有 H1「仙侠奇幻三维渲染」已部分贴近该风格，但仍残留「非写实渲染/NPR/卡通渲染」等表述，且名称限定在仙侠奇幻，无法覆盖参考图中西装、皮革、蒸汽朋克护目镜等跨题材服饰风格。

## 决策

1. 新增画风卡片 **H7「高精度 3D 国漫设定集风」**，完整写入写实 3D 国漫设定集的中文定性、建模/渲染层、场景/背景、镜头与负面限制。
2. 更新 `references/题材-画风映射.md`：将玄幻/玄幻3D/仙侠3D/仙侠/神魔/修真等题材的默认画风从 H1 改为 H7。
3. 保留旧 H1「仙侠奇幻三维渲染」卡片，仅在备注中标注为 legacy/备用仙侠风，避免破坏已有 `--style "仙侠奇幻三维渲染"` 引用。

## 权衡

- **新增 H7 vs 覆盖 H1**：
  - 覆盖 H1 更简单，但会静默改变所有使用 `--style "仙侠奇幻三维渲染"` 的旧输出，且破坏既有文档/脚本对 H1 的引用。
  - 新增 H7 并改映射，可在不破坏旧引用的前提下让新题材默认命中目标画风；旧 H1 作为显式指定仍可复用。
- **写实 3D 与 NPR 的取舍**：参考图明确为写实 PBR 渲染，因此 H7 彻底排除 NPR/赛璐璐/卡通描边/硬边阴影，与 A1/A2/H1-H6 中残留的卡通渲染表述切割。

## 后果

- 玄幻/仙侠/神魔/修真题材在 `--genre` 命中映射时，将默认注入 H7 风格锁定块。
- 现有 H1 用户显式引用不受影响，但新用户若不指定 `--style` 将不再落入 H1。
- 需要同步清理 `描述补全模板.md`、基础提示词模板等仍默认写入「非写实渲染/赛璐璐/卡通渲染」的字样，否则 H7 与模板之间会产生风格矛盾（见后续 ADR）。
