# ADR-0081: 冒烟修复与 AI 味词表吸收

- 状态: Accepted
- 日期: 2026-09-06

## 背景

全量冒烟测试（status/verify/拆段/init-schedule/备份恢复/59 卡矩阵）发现两类问题：
1. **氛围卡负面块被丢光**：A3-A6/C2/C4 的负面词（无都市感/无浓艳色彩/无史诗感运镜类）全部不在类型过滤词表内，被 `build_negative_block` 整条过滤为空——这些画风的提示词拿不到任何画风负面。
2. **verify 假绿灯**：无 `--style` 且无 `.start-state.json` 时画风检查被跳过，状态仍判 DONE。

随后审阅 deepseek skills 库（120+ 技能，按薄弱项定向吸收）：
- **stop-slop**（中文 AI 味去除）：6 类填充词 + 8 类公式句式 + 硬性密度指标——比 ADR-0080 借「去AI味」时的词表更系统；
- **minimax-h3-craft**（同作者，本流水线输出目标即 MiniMax H3）：`audit_prompt.py` 的 ANTISLOP 抽象词黑名单（震撼/绝美/史诗感/唯美/大气磅礴…）经实战检验；
- **scene-character-prompt-designer**：环境维度补「季节感」；
- **wjs-distilling-style**：方法论印证（风格=可复现指纹，与本库逐字锁定同哲学）。

## 决策

1. **负面块回退保障**：类型过滤后为空但卡片本身有负面时，整条保留卡片负面（负面词宁多勿失）；同时扩充 NEG_CORE_WORDS（色彩/配色/色调/构图/节奏/氛围/光线/都市/运动/明暗）。
2. **verify 状态降级**：全过但画风检查未跑 → NEEDS_REVIEW（rc=1），不判 DONE；判定抽为 `judge_status()` 可测函数。
3. **e2e 步骤 0 补状态文件持久化模拟**（`.start-state.json`），快照画风检查可被 verify 真实沿用。
4. **AI 味拦截扩表**（stop-slop + h3 ANTISLOP 合并口径）：
   - 起手式扩充：众所周知/毫无疑问/不可否认/完全可以说/无法否认；
   - 新增**抽象空洞词黑名单**（震撼/绝美/史诗感/唯美/大气磅礴/很酷/非常漂亮/惊人/壮丽/梦幻/极致；「华丽」除外——服装强化方向体系合法使用）；
   - 新增句式密度：过度省略号（段落内……≥2）、量化虚词堆砌（微微/些许≥3）、转折堆砌（然而/但是/不过/可是≥3）；
   - 负面提示词行整体豁免（禁令行合法包含这些词）。
5. **卡面卫生**：A5「史诗感运镜」→史诗运镜；B1「诗意唯美」→诗意留白（×3）；C3「梦幻舞台」→梦境舞台。
6. 描述补全场景维度 4 补「季节感」。

## 被放弃的备选

- **照搬去AI味/stop-slop 全部 11+8 类**：翻译腔五式等需句法分析，误报率高；只收可精确匹配的保守集。
- **抽象词黑名单含「华丽」**：与 ADR-0075 服装强化方向体系冲突（模板强制「配华丽首饰」），排除并在代码注释说明。
