# ADR-0034: 提示词末尾单独输出负面提示词段（适配 MiniMax H3 负面字段）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

用户确认其出图模型 MiniMax H3 提供负面提示词输入框。为了让「无网红脸/无第二张脸/无文字」等负面锁在图像端也生效，所有基础/衍生提示词在正文后单独输出「负面提示词：」段，供用户直接复制进负面字段。

## 决策

1. 人物/场景/道具基础模板与衍生模板输出格式新增末尾「负面提示词：」段，内容 = 模板负面限制与画风锁定块负面词的并集。
2. 负面段全程纯中文；作为图像模型的负面提示词字段输入使用。
3. `check_schedule.py` 每类型必守新增「负面提示词：」存在检查。
4. 描述补全不面向出图，不输出负面段。

## 影响

- `templates/*` 四个提示词模板、`scripts/check_schedule.py`、e2e mock 与快照。
