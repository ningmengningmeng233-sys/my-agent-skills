# ADR-0005: 新增风格接口（卡片模板与扩展流程）

- 状态: Accepted
- 日期: 2026-08-16

## 背景

用户计划后期持续新增画风。ADR-0004 决策 5 已预留文件级扩展（画风库/映射表外部可编辑、新增卡片走文件不进代码），但接口存在隐性契约与缺口：定妆注入依赖中文定性的「建模层/渲染层」分节（未文档化）、卡片 ID 编号无约定、入口二义（卡片「适用」字段 vs 题材映射行）、新增后无验证通道。

## 决策

1. **新增风格 = 两步，卡片为主、映射行可选**：
   - ① `references/画风库.md` 加卡片（主体）——获得 `--style 名称` 触发、风格锁定块注入、渲染层注入、`check_schedule` 画风必守词检查；
   - ② `references/题材-画风映射.md` 加行（可选）——仅在需要「按题材自动命中」时加，否则卡片只能手动 `--style` 触发。
2. **提供标准卡片模板**：`references/画风卡片模板.md`，用户照格式填写即新增；模板字段契约见下文（决策 3）。
3. **卡片「适用」字段降级为纯备注**：代码不消费；题材挂钩的唯一入口 = 题材映射行。
4. **模板字段契约（必填 4 字段 + 可选分层）**：卡片必填 = 名称 / 中文定性 / 英文标签块 / 负面词；**可选「X. 渲染层」分节 = 人物/道具定妆注入的开关**——中文定性含含「建模层」「渲染层」关键词的行才会进入定妆渲染块，缺则该风格不支持人物/道具定妆注入（`build_render_block` 退化），此契约在模板注释明示 + 运行时警告（解析到无渲染层分节的卡片且用于人物/道具生成时提示）。
5. **新增卡片编号 = H 系预留**：用户自定义风格一律 `H1` 起（H1、H2…无上限），不侵入 A-G 既有系；**G 系为速查表非卡片，禁止用 G 系编号新增卡片**（`parse_style_card` 会把非卡片块解析为空卡/劣化卡）。
6. **组合 ID /「按分集确认」语义**：映射表 ID 列组合（如「A6 / B1」）只取首个为默认；「分集/场景级画风切换」的唯一落地通道 = 调度清单行级「画风」列（ADR-0004 决策 3），映射表内「按分集确认」式备注改写为指向该通道；编排器不在画风确认环节自行推断分集画风。
7. **风格组装（按剧本类型组装 H 卡）**：混合风格（经常使用）的组装机制——`references/风格组装参考.md` 提供内容/渲染/色调/氛围四维组件表（组件措辞取自画风库原卡），编排器按剧本类型选组件 → 起草一张 H 卡 → **必须向用户展示全文并等待确认**（用户拍板：重要决策不允许静默落库，也不允许「确认一次规则后自动落库」）→ 确认后写入画风库 → 映射加行（可选）→ 自检。负面词 = 所选组件负面并集去冲突；渲染层组件为 3D 国漫时固定追加 A1 渲染负面。

## 权衡

| 备选 | 结论 |
|---|---|
| 只加卡片（自动题材触发） vs 卡片 + 映射行 | 卡片为主 + 映射行可选（题材挂钩是用户语义决策，不该由卡片隐式决定） |
| 模板字段严格五层 vs 必填 4 字段 + 可选分层 | 必填 4 字段 + 可选分层（写卡低门槛；渲染层契约文档明示而非强制，用户自选是否支持定妆注入） |
| 新卡按内容归入现有系 vs 预留 H 系 | H 系预留（用户自定义不侵入既有体系，编号永不冲突） |

## 影响

- 新增 `references/画风卡片模板.md`（标准卡片模板 + 新增三步指引）
- D 系 7 张漫画卡由表格格式升级为标准卡片格式（原表格卡无标题，不能经 `--style`/映射触发——升级后可触发，`画风库.md` D 系注明）
- 新增 `scripts/check_style_lib.py`（自检脚本：映射 ID 存在性 / 必填字段 / H 系编号连续 / 渲染层契约警告 / 必守词可提取）
- `references/画风库.md` 头部加「新增风格」指引（指向模板 + 编号约定 + 自检命令）
- `references/题材-画风映射.md` 头部备注更新（新画风先建卡）+ 「按分集确认」备注改写为指向调度清单「画风」列
- `CONTEXT.md` 新增画风术语节（画风卡片 / 题材挂钩）
- `SKILL.md` 步骤 0 补「分集/场景级画风切换走调度清单『画风』列」
