# ADR-0024: 服饰设计子模块纯中文输出与落盘闭环

- 状态: Accepted
- 日期: 2026-08-19

## 背景

服饰设计子模块此前被主流水线纯中文约定排除，存在三处不一致：

1. SKILL 未声明纯中文输出，交付文本可能出现 `hex / RGB / cm / Art Deco / oversize / logo` 等英文词；
2. 输出样例与参考文档含上述英文词，会示范 LLM 继续输出英文；
3. 落盘路径只有「当前工作目录\输出\剧名\」，与主流水线桥接器「覆写为 `<资产库>\服饰设计\<剧名>\`」的约定只在主 SKILL 写明，子模块自身没有闭环说明，独立触发时会把用户数据写进技能包。

## 决策

1. 子模块新增**纯中文输出**质量底线：角色条目与生图提示词正文全程纯中文；十六进制色值（如 `#E63946`）与数字比例（如 16:9、6.5 头身）允许出现；英文术语只允许出现在参考文档括注中。
2. 输出样例、`genre-styles.md` 黑名单/母题、`validations.md` 文本规则、`CONTEXT.md` 术语同步中文化。
3. 阶段 4 落盘规则补闭环：独立触发默认 `输出\剧名\`；与主流水线衔接时落盘到桥接角色清单所在目录 `<资产库>\服饰设计\<剧名>\`（数据外置）。

## 影响

- `服饰设计/SKILL.md`、`服饰设计/CONTEXT.md`、`服饰设计/references/*`、`服饰设计/输出/*` 样例。
