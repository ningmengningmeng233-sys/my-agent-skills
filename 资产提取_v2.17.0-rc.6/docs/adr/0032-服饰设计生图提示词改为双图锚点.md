# ADR-0032: 服饰设计生图提示词改为双图锚点（裁头服装三视图）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

经拷问确认，服饰设计子模块的生图提示词从「16:9 左半脸+右半三视图单图」改为与主流水线一致的双图锚点：图一=脸部参考图；图二=裁头服装三视图（同一画面横排正面/侧面/背面全身三格，三格头部一律裁除不入画）。依据为地狱写实线的 face-lock crop：脸只出现一次，三视图不产生三脸平均化；服装正/侧/背信息完整保留；仍是两张图，与主流水线身份锁完全兼容。

## 决策

1. 服饰设计生图提示词 = 图一脸部参考图 + 图二裁头服装三视图，共两张。
2. 背景为中性灰（不带色值 hex，避免校验脚本把背景色误判为角色配色）。
3. check_costumes 三视图检查（正面/侧面/背面）继续适用；两内置样例同步更新并通过 0 阻断 0 警告。
4. 不吸收地狱动漫线 6 头角 + 6 细节区（那属于 2D 动漫身份锁板，与 H7 写实 3D 线冲突）。

## 影响

- `服饰设计/SKILL.md`、`服饰设计/输出/*/角色服饰标准表.md`、`测试/e2e_flow.py`。
