# ADR-0021: LLM 客户端认证快速失败与画风简写匹配

- 状态: Accepted
- 日期: 2026-08-19

## 背景

错误处理与画风映射审查发现：

1. `llm.py` 对 401/403 认证失败与网络错误一样按 5s/10s/15s 空转重试 3 次，配置错误也要白等 30 秒且日志误导；
2. 429 退避为线性 10/20/30 秒，32 路并发限流时缺乏退避弹性；
3. `find_card_by_name` 用 `not title[len(name)].isalnum()` 做前缀边界，中文字符 `isalnum()` 恒为 True，导致任何中文简写（如「仙侠奇幻」）都无法命中卡片而落为自由描述；
4. 题材未命中映射时 SKILL 承诺提示用户，但 `resolve_style` 静默返回 A1，确认环节不提示。

## 决策

1. 新增 `LLMAuthError`：401/403 立即抛出、不重试，错误信息直接指向 `OPENAI_API_KEY / SUMMARY_API_URL`。
2. 429 退避改为指数 `min(60, 10 * 2**attempt)`。
3. 画风前缀边界改为「仅 ASCII 字母数字才阻断前缀匹配」；中文字符边界允许前缀命中。精确名仍优先。
4. `confirm_style` 在题材未命中映射时打印兜底提示（交互与 `--yes` 两个分支都提示）。
5. 同步修正 `题材-画风映射.md` 中已改名的画风名称列（A1/H1/E2），画风库标题括号内英文来源标注中文化。

## 影响

- `scripts/engine/llm.py`、`scripts/engine/style.py`、`references/题材-画风映射.md`、`references/画风库.md`、相关单元测试。
