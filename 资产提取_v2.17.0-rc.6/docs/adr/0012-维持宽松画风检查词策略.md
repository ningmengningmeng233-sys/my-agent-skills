# ADR-0012: 维持宽松画风检查词策略

- 状态: Accepted
- 日期: 2026-08-18

## 背景

`check_schedule.py` 中的 `style_keywords()` 与 `_kw()` 负责从画风卡片中提取「必守词」，并在合规检查时验证人物/场景/道具提示词是否包含这些关键词，以防止画风丢失。在审查中曾提出：是否增加 `--strict-style` 模式，将部分警告升级为错误，以更强地约束画风词的复现？

## 决策

**不引入 `--strict-style` 模式，维持当前宽松默认策略。**

1. 当前 `check_schedule.py` 对画风词缺失输出警告（⚠️ 画风词未复现），但不阻塞生成流程。
2. 不新增命令行开关，也不提高任何现有规则的严重性。
3. 保持 `style_keywords()` 的当前分词与过滤逻辑不变，避免改变已有快照与 e2e 复验结果。

## 权衡

| 备选 | 优点 | 缺点 |
|---|---|---|
| A. 增加 `--strict-style`，缺失画风词视为错误并退出 | 画风约束更强 | 增加用户负担，轻微的风格化改写、变体提示词可能被误判；需同步调整大量快照与测试 |
| B. 保持宽松警告策略（选定） | 不增加配置复杂度，给提示词留有余地，用户可人工决定是否采纳警告 | 画风丢失需依赖用户主动关注警告 |

选择 B 是因为用户明确拒绝增加负担：「不同意 这样会增加负担」。画风词复现的严格程度属于审美与工程策略的交界，当前警告级别已能提示风险，强行升级会提高误报率并破坏现有工作流。

## 影响

- `check_schedule.py` 与画风词相关逻辑不做修改。
- 未来若出现大量画风丢失漏报，再重新评估是否需要分级策略（如按卡片维度区分「强制复现」与「建议复现」），但不引入全局严格模式。
