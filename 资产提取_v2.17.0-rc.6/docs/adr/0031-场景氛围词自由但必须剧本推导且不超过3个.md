# ADR-0031: 场景氛围词自由但必须剧本推导且≤3

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：场景提示词的氛围词/风格词不设固定候选库，允许自由书写，但必须满足三项约束——从剧本/视觉描述推导、最多 2-3 个、禁止形容词堆砌。

## 决策

1. 氛围词自由书写，不设候选库。
2. 必须从剧本/视觉描述推导；未提供时按题材逻辑推断。
3. 最多 2-3 个；「电影感」「好看」「美丽」等无效词禁止出现。
4. 画风锁定块（H7）不受此限，照常全量注入。

## 影响

- `templates/基础提示词模板-场景.md` 风格锚点行。
