# ADR-0071: v2.9.40 落地后审计补强（锁定检查分层、类型范围与文档口径）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

对 v2.9.40 三格图板双版落地做全量审计后发现：渲染锁定检查仍是「四层任中其一」的弱检查，懒生成可只写一层通过；道具会被要求写入它并不注入的场景/镜头层，形成不可达检查；模板与术语表残留 PBR/四视图等旧口径；`--style H7` 等卡片编号会被当作自由描述而丢锁；裁头版存在孤儿文件与补生成顺序漏洞。

## 决策

1. **渲染锁定段按层逐条必查（ADR-0069 补强）**：check_schedule 把四层拆成独立检查项——人物/场景必须四层逐层命中；道具只必查建模层与渲染层（道具模板只注入渲染基调，保持素灰 #B8B8B8 与静物定妆）。
2. **内容语言必查按类型收敛**：玄幻/仙侠/神魔/修真/奇幻题材的人物/场景另必查画风卡中文定性第一段逐字命中；道具不做内容语言必查（ADR-0046/0069）。
3. **衍生提示词质量词与布局词必查**：人物/场景/道具衍生补齐三维渲染质量词检查；人物基础与衍生额外必查「左面特写格 + 右面双视图格」两个布局标记，防止只写三视图词、不写地狱式左右布局。
4. **`--style` 支持卡片编号**：H7/A2 等卡片编号直接解析为卡片，不再落入自由描述；`find_card_by_name` 增加编号精确匹配并补测试。
5. **裁头版闭环加固**：存在裁头版衍生但缺裁头版基础时照报缺失；`--view-mode crop` 未检测到默认不裁头版时打印补充版警告；裁头版合并文档标题带「-裁头版」后缀。
6. **口径清理**：衍生/描述/聚合等模板删除 PBR/3D 英文残留；CONTEXT、画风卡片模板、画风库注入点表统一为三格图板；反推文件模块数统一表述为 12 模块。

## 影响

- `scripts/engine/style.py`（卡片编号解析 + `content_lock_sentence`）
- `scripts/generate_prompts.py`（衍生道具渲染层注入、裁头版标题、补生成警告）
- `templates/`（PBR/3D 清理、衍生锁定段按类型说明）
- `references/画风库.md`、`references/画风卡片模板.md`、`CONTEXT.md`、`SKILL.md`、`README.md`、`测试/触发顺序.md`
- `测试/unit/test_check_schedule.py`、`测试/unit/test_style.py`（137 用例）
