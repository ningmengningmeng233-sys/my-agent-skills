# ADR-0044: 一个变体一个情绪 + 只生成需要的变体

- 状态: Accepted
- 日期: 2026-08-19

## 背景

拷问确认：①人物衍生强制「一个变体一个情绪状态」，服装变体可顺带情绪变化，但情绪最多 1 个且与场合匹配；②只生成需要的、不生成还没出现过的——禁止自动扩展 人物×全部服装 全组合矩阵，只生成调度清单实际出现的变体。

## 决策

1. 衍生人物：一个变体一个情绪状态，表情肌肉描述只写一套。
2. 服装变体可带情绪变化。
3. 只生成清单变体，禁止生成尚未出现的组合/造型/状态。

## 影响

- `templates/衍生提示词模板.md` 人物段、`SKILL.md` 步骤 6。
