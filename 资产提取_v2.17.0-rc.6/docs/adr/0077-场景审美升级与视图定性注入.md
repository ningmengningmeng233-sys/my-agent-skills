# ADR-0077: 场景审美升级与视图定性注入

- 状态: Accepted
- 日期: 2026-09-06

## 背景

用户实测反馈场景提示词审美效果一般。排查确认四个根因：

1. **视图定性从未被使用**：ADR-0076 落库的风格包含四份视图定性文件（脸部/全身/环境/物件），是素材库中场景审美密度最高的文本（剪影可读、三层景深、大块面明度组织、大气柔化、倒影处理），但材质路由只路由了 16 类材质，视图文件零注入。
2. **场景模板只管机位不管画面组织**：镜头填空体系（景别/角度/布光）约束拍摄参数，但画面组织美学（明度块面、留白、远景简化、细节分布）无任何要求。
3. **前/中/后景是套话填空**：e2e 快照中三个不同场景（茶楼/天井/码头）的前中后景一字不差，无检查拦截。
4. **描述补全场景维度过粗**：一句话带过，无剪影/层次/明度/大气介质预写。

## 决策

1. **视图定性注入（按资产类型路由）**：人物=视图-脸部+视图-全身，场景=视图-环境，道具=视图-物件；逐字写入输出「视图基调：」段（基础与衍生一致）；行级画风覆盖时随覆盖包重建。
2. **环境审美骨架（模板级，所有画风通用）**：场景模板必守六条——剪影可读、三层景深内容必须来自本场景视觉描述且跨场景禁止雷同、明度组织、留白呼吸、远景简化+大气柔化、水面倒影平静；细节分布规则（只保留在焦平面附近与结构边界）写入骨架。
3. **风格锚点升级**：从「最多 2-3 个氛围词」改为「色调组织（主色调块面+强调色+位置）」，保留无效词禁令。
4. **雷同拦截**：check_schedule 新增「场景层次雷同」——场景合并文档中前/中/后景句归一化后跨节逐字重复即报；挂风格包的卡逐字必查视图定性段正文。
5. **描述补全场景 7 维度**：空间与剪影/层次与景深/明度与色彩组织/大气与光/材质与表面/水面倒影植被/负面限制；镜头体系四项预写保持必写。

## 被放弃的备选

- **只改模板措辞、不注入视图文件**：审美密度最高的蒸馏素材继续闲置，且不同画风的环境审美差异无法表达（骨架是共性，视图定性是画风个性，二者互补）。
- **把环境审美写入画风卡分层**：会让 46 张卡每张膨胀四分之一且大量重复；共性规则放模板、个性规则放风格包的分层更干净。
