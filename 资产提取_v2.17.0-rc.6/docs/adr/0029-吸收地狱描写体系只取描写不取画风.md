# ADR-0029: 吸收《地狱》描写体系（只取描写，不取画风）

- 状态: Accepted
- 日期: 2026-08-19

## 背景

用户要求吸收 Higgsfield 技能库《地狱》技能中人物/场景提示词的优秀描写定义，但明确排除其画风——画风必须保持 H7「高精度 3D 国漫设定集风（斗罗/玄机风）」。经拷问确认三点：① 载体为模板内嵌速查（不建死文档）；② 人物视图从四视图改为地狱实际喂给视频生成台的「双图锚点」；③ 全身图裁掉头部；④ 场景嵌入镜头填空体系；⑤ 一切以用户剧本为准，禁止乱填。

## 决策

1. **人物双图锚点**：脸部参考图（正面或四分之三侧面、中性表情写肌肉动作、均匀柔光、单人、构图头顶到锁骨）+ 全身图（头部不入画、从颈根到脚完整入画、管体型/头身比/服装/剪影）；身份锁只写一次、两图共用。
2. **场景镜头填空体系**：景别十级 + 角度九种 + 布光（光名+方向+时间）+ 环境具体化（时间+地点+可测量尺度）+ 材质四件套 + 一个镜头一个变化 + 风格锚点 ≤3；「电影感/好看/美丽」为无效词。
3. **描写铁律**（描述补全模板）：只写可观测特征；写肌肉动作不写情绪标签；材质四件套；一切以原文/剧本为准，未提供才按题材逻辑推断并克制。
4. `check_schedule.py` 必守词同步：人物=双图锚点；场景=景别+角度+布光；H7 画风卡镜头描述同步。
5. 不吸收地狱的画风/模型名/平台词/英文代码（保留纯中文与 H7 渲染）。

## 权衡

- 双图锚点 vs 四视图：四视图脸小、三脸平均化导致身份漂移；双图锚点让脸与身材各有一个清晰真相，与地狱实测结论一致。
- 模板内嵌 vs 独立语料库：本架构是脚本直调、模板即注入源，独立语料库不会自动被读取，故内嵌。
