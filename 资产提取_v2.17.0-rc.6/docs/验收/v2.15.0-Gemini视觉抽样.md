# v2.15.0 真实 Gemini 视觉抽样手册（自包含，不代填人工结果）

> 用途：在**有密钥的机器上**抽样验证 Gemini 生图链路（计划 → 导出 → 生成 → 质检 → 签发）。
> 本手册**不产生任何人工视觉结论**：文末十项人工表保持空白，由执行者逐项填写。
> 自动化质量门（`python 测试\run_all_checks.py`、`python 测试\run_visual_offline.py`）
> 全部离线通过 ≠ 真实模型内容合格；两者必须分开报告。

---

## 0. 前置（离线，不消耗额度）

```powershell
cd <技能仓库根>
python -m pytest 测试\unit\test_visual_quality_gates.py -q
python 测试\run_visual_offline.py
```

两项都必须退出码 0。任一项非零即**中止**本手册，先修离线门。

## 0.5 环境体检（离线，不发收费调用）

```powershell
python scripts\maintenance.py visual-doctor --lib <资产库> --json
```

`authoritative_pack.integrity_ok` 必须为 `true`（缺图/漂移即先修风格包）；
`api_key` 应为「未配置」或「已配置」，但输出**绝不含密钥值**。

## 1. 包外密钥配置（密钥绝不入仓、不入包、不入日志）

```powershell
# 真实 .env 放技能包外（推荐），或设置环境变量
$env:GEMINI_API_KEY      = "<在此填写真实密钥>"
$env:GEMINI_IMAGE_MODEL  = "gemini-3-pro-image"
# 质检模型：必须支持「图像输入 + 文本输出」；rc.1 的 gemini-3-pro 已不存在
$env:GEMINI_QC_MODEL     = "gemini-3.1-pro-preview"
$env:GEMINI_IMAGE_SIZE   = "2K"
$env:GEMINI_TIMEOUT_SECONDS = "180"
```

**硬规**：密钥只存在于当前 shell 会话或包外 `.env`；`GEMINI_API_KEY` 必须填真实值；
不要把密钥写进任何命令输出、报告或截图。

## 3. 生成视觉计划（离线）

```powershell
python scripts\create_visual_plan.py --lib $LIB --style 仙侠国风电影CG
python scripts\maintenance.py visual-plan --lib $LIB --style 仙侠国风电影CG
python scripts\maintenance.py status --lib $LIB --json
```

期望：计划含 6 个老罗任务（正脸、后脑、服装独立正面、服装独立背面、人物全身正面、人物全身背面），
`status --json` 的 `data_delivery.state` 应为 `DELIVERED`，`visual_delivery.state` 为 `PLANNED`。

## 4. 老罗六任务抽样（**核心步骤，消耗额度**）

按依赖顺序逐项执行；每项**最多 3 轮**（三轮后自动进入"需要人工决定"，不会再发请求）。

```powershell
python scripts\visual_production.py run --lib $LIB --task CH_老罗-正脸-v01
python scripts\visual_production.py run --lib $LIB --task CH_老罗-后脑-v01
python scripts\visual_production.py run --lib $LIB --task CH_老罗-服装独立正面-v01
python scripts\visual_production.py run --lib $LIB --task CH_老罗-服装独立背面-v01
python scripts\visual_production.py run --lib $LIB --task CH_老罗-人物全身正面-v01
python scripts\visual_production.py run --lib $LIB --task CH_老罗-人物全身背面-v01
```

无密钥或想省额度时，改用手工链路（同样绑定 task_id）：

```powershell
python scripts\visual_production.py export --lib $LIB --task CH_老罗-正脸-v01
python scripts\visual_production.py import --lib $LIB --task CH_老罗-正脸-v01 --image "<生成结果图片>"
python scripts\visual_production.py check  --lib $LIB --task CH_老罗-正脸-v01 --qc "<结构化检查结果.json>"
```

## 5. 费用停止点与请求上限（**必须遵守**）

- 每一项资产**最多 3 轮**自动请求（含质检请求，每轮 2 次调用：生图 + 质检）。
- 六个任务的理论上限 = 6 项 × 3 轮 × 2 次 = **36 次调用**；
  出现第 4 轮请求即视为实现缺陷，立即停止并记录。
- 抽样**总额度上限**：36 次调用。达到上限立即停止，剩余任务记为「未抽样」。
- 任一任务出现连续两轮完全相同的问题码（`INEFFECTIVE_RETRY`），
  该任务自动转「需要人工决定」，**不再消耗额度**。


## 7. 恢复方法（中断/失败后）

```powershell
# 查看当前状态（只读）
python scripts\maintenance.py status --lib $LIB --json
python scripts\visual_production.py check --lib $LIB

# 断点续跑：重跑同一命令即可（幂等：已通过任务不会重复请求）
python scripts\create_visual_plan.py --lib $LIB --style 仙侠国风电影CG

# 某项被人工判定需修改：从该任务重新生成（上游未变时只重跑这一项）
python scripts\visual_production.py run --lib $LIB --task <task_id>
```

**恢复矩阵要求**：上游替换后，下游自动转「需要重新检查」（`NEEDS_REVIEW`），
旧图保留但不再作为参考；恢复上游并重跑后只重验受影响任务，资料交付状态不受视觉扰动影响。

## 8. 视觉交付门（独立执行，不改变资料交付）

```powershell
python scripts\maintenance.py verify-visual --lib $LIB
python scripts\check_visual_delivery.py --lib $LIB --json
```

- 全部必需任务通过 + 依赖新鲜 + 风格包哈希一致 → 签发 `视觉资产\视觉交付清单.json`；
- 可选任务（拼版）失败不阻断，但必须出现在清单的 `incomplete` 列表中；
- 资料 `verify` **不调用**视觉门：视觉未启用/失败都不影响「资产资料已交付」。
