
退出码口径：**0 = 当前口径自洽**（rc 版本 + 全表待人工即为自洽，且 stdout 会打印「拒绝出正式版」及原因）；
**2 = 假绿灯或口径不一致**（stderr 逐条列出原因）。

## 2. 谁来签

**只能由真人逐项签署**。机器签发（`verify` 出 `DELIVERED`、`check_visual_delivery.py` 退 0、
Omni 自动审核判定「通过」）不等于内容正确，机器不得充当 `reviewer`。

- 顶层 `reviewer`：签字的真人姓名或可追溯的花名，**不得为空、不得只写空格**；
- 顶层 `review_date`：`YYYY-MM-DD`（缺前导零、写成「昨天」都算没签）；
- `items[].证据路径`：该项判据所依据的**真实产物**（相对仓库根，必须存在）。
  指向不存在文件的证据视为无证据。

## 3. 签的判据（十项，顺序固定）

| id | 项目 | 判定为「通过」的条件（看图人自己确认，不靠机器） |
|---|---|---|
| `style` | 画风一致性 | 与「仙侠国风电影CG」权威参考图同调：无真人毛孔词式写实、无 2D 平涂跑偏、无高饱和塑料感 |
| `identity` | 角色身份 | 与角色三视图/正脸是**同一个人**（骨相、五官比例、肤色不漂移），换镜头不换脸 |
| `age` | 年龄感 | 与资产表登记的年龄段一致，不出现「少年脸配中年体态」等违和 |
| `composition` | 构图 | 主体位置、视线方向、留白符合任务提示词与导演构图卡，无截断主体 |
| `crop` | 裁切 | 视图要求完整（正脸不切下巴、全身不切脚），无越界裁切与多格拼图 |
| `ratio` | 比例 | 画幅符合模板固定值（正脸/后脑/道具 1:1、全身与服装 2:3、场景母版 16:9） |
| `material` | 材质 | 甲胄/织物/皮肤/金属的质感可信，无「一切皆瓷」的统一高光 |
| `lighting` | 光影 | 光源方向单一、投影一致、无游离发光体，与 LIGHT_COLOR 段一致 |
| `forbidden` | 禁项 | 负面清单与豁免规则均不违反：无多指/畸形手部、无文字水印、无多余人物与皮肤残端 |
| `series` | 系列一致性 | 同一角色/场景的全部资产放在一起仍像**成套**出品（跨资产不各画各的） |

填写规则（闸门强制）：

1. `判定` 只能取 `待人工` / `通过` / `不通过`，写别的（「已验收」「PASS」「基本能用」）判红；
2. 判 `通过` 必须同时具备：真人 `reviewer` + 合规 `review_date` + 至少一条真实存在的 `证据路径`；
3. 判 `不通过` 必须写 `备注`（问题出在哪），否则判红；
4. 十项未全 `通过` 时，`SKILL.md` 版本号**不得**去掉 `-rc`；
5. 画质表 `version_under_review` 与当前版本不同线时，旧签署**不可**沿用（须以新版本重签）。

3. 真人对照第 3 节判据逐项看图，填 `判定`/`评分`/`证据路径`/`备注`，并填顶层 `reviewer`/`review_date`；
4. 跑 `PYTHONIOENCODING=utf-8 python scripts/check_manual_qc.py` 与 `python 测试/run_all_checks.py`，
   两者退出码均为 0 且 stdout 不再打印「拒绝出正式版」后，才可讨论把版本号去掉 `-rc`。

十项里任何一项判 `不通过`，都回到第 1 步之前的状态：不得升正式版。
