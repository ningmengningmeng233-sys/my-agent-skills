## 二、产品边界落实情况（规格 1/3/12）

- 核心资产反推可**完全离线**运行：`data_delivery` 与 `visual_delivery` 是两条独立状态线，
  视觉未启用显示「视觉生产：未启用」（`NOT_ENABLED`），是合法状态而非失败。
- 核心链路零 Gemini 依赖由两道守卫钉死：`测试/unit/test_core_without_visual.py` 对 10 个核心模块做
  静态导入扫描 + 干净解释器导入断言，并在总门里以**清空全部密钥环境**的方式再跑一遍
  （`core without visual`，见「四」）。
- 四类顶层资产不变：新增中文子类型枚举（怪物/妖兽 → 人物·非人角色，马车/舟船 → 道具·载具，
  宫殿/楼阁 → 场景·建筑，盔甲/铠甲 → 服装·甲胄），法术/天气/特效以「视觉需求」挂在已有资产上，
  索引校验器拒绝第五类顶层类型。
- 正式输入：TXT / Markdown / DOCX / EPUB / 多文件项目；**PDF 以 `UNSUPPORTED_SOURCE_FORMAT` 拒绝**，
  不建设 OCR。

## 八、已知限制与正式版晋级条件

**已知限制**

1. 参考图（32 张，71.6 MB）不入 Git：精简安装需重跑 `scripts/sync_stylepack.py` 从母版重建；
   缺失时校验器会如实报告「参考图未随包分发」而不会伪称完整。
2. 发布包的密钥扫描对**显式占位串**（`fake`/`example`/`should-not` 等）放行，
   阈值取 30 字符；真实形状的密钥仍被拦截（有正反两例回归）。
3. 旧提示词文档路径（`提示词/基础|衍生`）仍保留历史的三格图板写法（既有产物格式）；
   新视觉生产路径禁止模型一次生成多格，拼版只能由已通过图片本地合成。
4. 旧风格未重新蒸馏，标记为「旧版未验证」，仅「仙侠国风电影CG」为 Omni 验证风格。
5. 视频生产管线未构建：E1 的运镜/时长/节奏只迁入 `references/video_styles/` 备用。
