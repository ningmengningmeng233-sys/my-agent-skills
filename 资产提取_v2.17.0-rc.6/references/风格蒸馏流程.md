# 风格蒸馏流程（从参考图造风格包）

> 状态：**新增能力文档**（v2.17.0-rc.1 加速改法 第三批 T16 交付）。
> 只出流程与公式，**不动任何代码**；风格包路径与校验仍以权威包规则为准（见 `references/画风库.md` 与 `SKILL.md` 的「权威风格包」一节）。
> 在此之前，技能只会**使用**现成风格包；本文补上「从一张参考图造出一个新风格包」的完整路径。

---

## 一、输入

| 输入 | 要求 |
|---|---|
| 参考图 | 至少 1 张、清晰可读、无文字水印；单图只蒸馏**一个**风格，多风格混在一张图里先按 §二.4 拆分 |
| 用途声明 | 这批资产是给哪一类题材（仙侠 / 玄幻 / 都市…）用，决定「必须排除」的边界 |
| 输出目标 | 新风格包的中文名与版本号（落库前先起名，避免同名覆盖既有包） |

**不做**：不把「题材相似」当「风格相似」（见 §二.3）；不把参考图里的**具体角色/物件**当成风格要素。

## 二、步骤

1. **大类媒介判定**：先判这张图属于哪一类媒介（三维写实渲染 / 三维风格化 / 纯 2D 手绘 / 2.5D 折中 / 摄影）。
   - **纯 2D 与 2.5D 必须强制辨别**：看轮廓是否有物理体积受光、材质是否有真实反射与粗糙度变化；纯 2D 的「体积感」靠上色造，2.5D 有简化但真实的受光。二者混判会让后续提示词自相矛盾（既要三维材质又要平涂描边），必须二选一。
2. **按 Prompt 公式起草**：把参考图的风格拆进固定公式（下方「Prompt 公式」），逐槽位写满，不留空槽。
3. **边界检查（写成两张清单）**：
   - **必须进入**：媒介、材质反应、光色倾向、镜头语言、时代与文明气质。
   - **必须排除**：与目标题材冲突的元素（例如仙侠题材排除现代工业件、科幻件）、参考图里偶发的杂物。
   - **纹理噪点默认禁入**：参考图的胶片颗粒 / 压缩噪点 / 扫描纹理，默认**不**作为风格要素写进公式；确实要保留时才显式加入并在确认环节说明理由。
4. **单图拆分**：一张参考图里若混有两种明显不同的媒介（如左半三维、右半平涂），先拆成两条独立蒸馏记录，各自走完本流程，不允许合并成一个包。
5. **风格相似 ≠ 题材相似**：判定「像不像」只看媒介 / 材质 / 光色 / 笔触，不看画面里画的是什么。画着龙的三维图与画着机甲的三维图，**风格**可以同属一类；而画着龙的平涂图与画着龙的三维图，**题材**相同但风格不同。

### Prompt 公式（风格槽位）

```
[媒介大类] + [渲染/笔触特征] + [材质与表面反应] + [主光与色调] + [镜头与构图语言] + [时代与文明气质]
```

- 每一槽位只写**可观察**的特征，不写感受词（"大气""高级感"不是特征）。
- 槽位之间不得互相矛盾（判过 2D 就不能再写"物理渲染材质"）。
- 公式写进候选风格包草案，供人工确认（§三）。

## 三、确认

- 草案产出后**必须**由人确认：媒介判定是否正确、两张清单（必须进入 / 必须排除）是否认同、纹理噪点是否保留。
- 确认之前**不得**落库；确认记录（谁、何时、确认了什么）随包落库。
- 未确认的草案只能作为候选留在草案目录，不得被资产生产引用。

## 四、落库

- 按权威风格包规则落库：包内含风格卡（中文正式名 + 版本号 + 公式与两张清单）、参考图、来源说明（蒸馏自哪张图 / 由谁确认）。
- **不覆盖**：同名风格包已存在时只递增版本号，不覆盖旧版本（与「每项只有一个当前正式版本」同口径：新版本生效，旧版本保留可回溯）。
- 落库后风格包路径仍以权威包规则为准；本文不改任何路径定义。

## 五、验收

- **缺图拒绝**：包内参考图缺失、空字节或哈希不符 → 拒绝入库（不给"先入库后补图"的口子）。
- **漂移拒绝**：公式与参考图实际媒介不一致（例如判成 2.5D 却写了纯 2D 平涂槽位）、或包内容与风格卡描述不一致 → 拒绝入库。
- 落库后做一次抽查：用新包对一个最小资产发一条基础提示词，人工确认"风格对得上"，记录结论（通过 / 返工）。
- 本流程产出的包与既有权威包在**结构上等价**：校验口径一致，缺图与漂移的拒绝逻辑一致。
