# 画风库（v1.0）

精读自国风定性技能集（seedance-3d-skill / manga-style-video / manga-drama / remotion-guofeng-starter / higgsfield-seedance2-jineng 15 技能）。用法：
1. 题材 → `题材-画风映射.md` 查默认画风
2. 命中本库风格卡片 → 注入「中文定性 + 负面词」（英文标签块仅作内部索引，不注入提示词）
3. `--style "自由描述"` 可直接绕过本库原样注入

> **新增风格**：照 `画风卡片模板.md` 复制填写（当前 H 系已有 H1-H18，其中 H8-H18 为风格蒸馏落库卡、各挂 references/stylepacks/ 中文风格包；新卡从下一个连续 H 编号开始，勿用 A-G；卡内编号分层行 = 定妆注入开关；卡片可带「别名」行（旧名/俗称，`--style` 可用别名命中）；规范见 references/stylepacks/README.md）；需要按题材自动命中时在 `题材-画风映射.md` 加行；完成后跑 `python scripts\check_style_lib.py` 自检（ADR-0005）。

```
禁止在后续提示词中改变画风、色调、渲染方式或镜头语言基线的描述。
```

- 变体覆盖: 调度清单行级「画风」列可覆盖单个变体（注入新锁定块替换）
- **合规检查挂钩**（check_schedule.py）：人物/场景按选定画风的渲染锁定段四层逐层必查（道具只查建模/渲染层），玄幻/仙侠/神魔/修真/奇幻题材的人物/场景另必查内容语言段；并把中文定性「必守关键词」（如"写实三维渲染/物理渲染材质/八K超高清/细腻毛发与皮肤纹理/拒绝非写实渲染/拒绝赛璐璐/拒绝卡通渲染/拒绝硬边阴影色块"）纳入提示词合规检查——缺失即报"不合规·画风丢失"，防生成器偷懒丢画风（流程吸收清单第 3 条）
