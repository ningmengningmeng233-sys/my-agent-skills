# 错误处理矩阵（按场景一条处理路径）

> 自 SKILL.md 披露的参考文件（ADR-0083）：只在出现异常/报错分支时读取；预防性口径见各步骤「完成标准」。

| 场景 | 处理 |
|---|---|
| 源文件异常/章节识别异常 | 调整 `--chapters-per-seg` 或改用字数切分 |
| 段文件同名内容冲突（源文件已变更） | 确认后 `--force` 覆盖，或检查源文件/分卷配置 |
| 登记表候选遍/聚合失败 | 独立断点表 registry_tasks，重跑续传；连续失败 ≥3 自动跳过，`--force-retry` 强制重试 |
| 段提取失败 | 引擎自动重试 3 次（429 退避）；仍失败记录断点，重跑续传 |
| 裁决表解析失败（整块） | 裁决输入/产物按块存 `.process/裁决/裁决输入_<块>.md` / `裁决_<块>.md`（断点带内容指纹，输入变化自动重跑）；`--no-llm` 单跑脚本部分调试 |
| 裁决块 API 重试耗尽 | aggregate 明确报错返回 1（不裸崩溃）；hash 断点保证重跑不重复烧钱——重跑同一命令续传，失败块修正后重跑 |
| 裁决 dropped（部分行丢弃） | **已阻断（aggregate 返回 1，不产出）**——修正对应 `.process/裁决/裁决_<块>.md` 后重跑单块；逐条核对丢弃行是否损失正式资产 |
| 描述/基础/衍生生成失败 | 引擎重试 3 次；仍失败重跑续传（断点跳过已完成项）；不合格文件 `--force` 覆盖 |
| check_schedule 报缺失 | 缺生成 → 重跑对应命令；内容不合规/画风丢失 → `--force` 重新生成；附录引用 → 人工决定补录或删除 |
| check_asset_index 报关系/事实/母版/P3 | 悬空关系改待确认后重跑聚合；越级事实降级；母版漂移以索引为准回写；P3 补故事功能说明 |
| verify 失败无交付清单 | 看 `.process/验证报告.md` 修复后重跑 `verify --style`；历史有效清单不被覆盖 |
| 老库缺索引/母版 | `maintenance.py migrate --lib <资产库>`（先备份，旧表不动） |
| 状态机回退（源/风格/产物变更） | 按 `status --json` 的下一命令重跑最早失效步骤；不宣称精准跳过 |
| API key 缺失 | 提示配置 .env（`~/.asset-extract/.env` 或技能目录）；只读 status/backup 不被 NEEDS_CONFIG 阻断 |
| 中断 | 任何步骤重跑同一命令即续传，零浪费；重开会话见「断点定位」 |
