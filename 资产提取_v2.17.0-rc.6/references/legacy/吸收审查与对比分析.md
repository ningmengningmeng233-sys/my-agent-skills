# 吸收审查与对比分析

对照「原本」(skill.md + templates 全部模板 + CONTEXT.md)审查国风定性技能集五目录 19 批吸收成果。原则:一切以国漫3D为主;同类型择优;流程方法优秀部分照收。

## 二、3D 国漫风格定性对比分析(最重点)

五来源对"3D 国漫"的定性对比:

| 来源 | 定性表述 | 优势维度 | 短板 |
|---|---|---|---|
| **原本(描述补全视觉基准)** | NPR、Toon Shading、赛璐璐/次世代风格化、发束感/色块分割、底层真实感逻辑(克制) | 技术渲染最精确;有"克制"原则 | 无色彩/构图/镜头/文化维度 |
| **seedance 中式国漫** | 古风、飘逸衣袂、东方美学、大气构图、暖金色调、柔光、8K、精致建模、真实布料质感、史诗感镜头 | 文化符号+构图+色彩+镜头最全 | 渲染词偏"CG影视级",赛璐璐表述弱 |
| **higgsfield 02 Cel-Shaded with Depth** | bold outlines + rim lighting + specular highlights + high-contrast shadow boundaries(非平涂) | 赛璐璐渲染的专业表述最优 | 无国漫文化元素 |
| **higgsfield 03 CGI 3D Cel-Shading** | toon shader、solid color blocks with hard shadows、smooth 3D motion | 与 02 同向 | **02 更优**(03 偏平涂,缺深度与高光) |
| **higgsfield 08 动漫** | 阴影=色块非渐变、有限动画、戏剧光影(轮廓/底光) | 动漫侧原则 | 2D 向,与 3D 国漫有距离 |

**融合结论(择优合成,写入画风库 A1)**:

> **3D 国漫 = 写实建模层 + 赛璐璐渲染层 + 东方色彩层 + 史诗构图层 + 高颜值角色层**
> 1. **建模层**(原本 + seedance):高精度建模、PBR 材质、真实布料/丝绸/金属质感、发束感、8K 超高清、次世代风格化
> 2. **渲染层**(原本 + higgsfield 02,弃 03 平涂):NPR 非真实感渲染、Toon Shading、bold outlines 轮廓描边、hard-edged shadow boundaries 硬影色块、specular highlights 高光、底层真实感克制
> 3. **色彩层**(seedance):东方美学色板——暖金/玉清/冷青/青绿/灰蓝 5 变体;唯一高饱和强调色规则(remotion 朱红原则可借鉴)
> 4. **构图镜头层**(seedance):大气构图、留白、史诗/写意/节奏三系镜头语言
> 5. **角色层**(seedance):高颜值中式国漫面部、正常成人比例、禁止网红脸/随机换脸/幼态化/分身镜像

**同类型文件对比结论**:
- 赛璐璐表述:higgsfield 02 > 03(02 带深度,03 平涂)→ 画风库取 02
- 国风定位:manga-style 国风水墨(动画) / remotion 纸片(拼贴) / seedance 江南烟雨(3D 国漫变体)三者定位不同,全部保留,按题材/用途区分,互不冲突
- 电影感:higgsfield 01(参数化数字语言) > seedance 史诗感(词块)→ 镜头参数化语言(ft/s/K/f/%)吸收进画风库 G 通用维度

## 三、流程方法吸收清单

**吸收(并入本流水线)**:
1. **光影与色彩基线规则**(seedance):场景衍生变体切换(时段/天候)时,必须写明"变化起因+变化方向+完成状态";同变体内部禁止任意改变主光方向/软硬/对比/介质 → 升级衍生模板
2. **角色唯一性锁**(seedance):禁止分身/克隆/镜像替身/背景重复人物 → 补人物模板负面
3. **风格锁定句法**(04-comic-to-video "Preserve ..." + 画风库锁定块):跨变体风格一致,check_schedule 合规检查把"画风锁定关键词"纳入必守 → 防生成器丢画风
4. **2 秒钩子/参数化数字语言**(higgsfield 01):镜头运动全部数字化(速度/时长/方向)→ 画风库 G 维度
5. **防偷懒四查**(check_schedule 已有"必守关键词"):扩展为含画风关键词
6. **美学克制原则**(原本"克制不夸张" + remotion"一片一高饱和色"):画风注入强度分级(定妆零注入/场景全量/描述克制)

**记录不吸收(超范围或冲突)**:
- 逐秒分镜时间轴/对白硬性规则/轴线规则/音效设计:本流水线产静态图提示词,不适用(保留在画风库 E 系供视频向参考)
- 纸片抠边生产流程(remotion):素材生产向,非提示词生成向
- 漫剧分镜类型(manga-drama):与调度清单思路同源,不新增

## 四、画风注入点决策(落实 ADR-0004)

| 模板/环节 | 画风注入 | 说明 |
|---|---|---|
| 人物定妆(基础) | ❌ 不注入色调/氛围;✅ 注入渲染层(赛璐璐带深度) | 定妆必须中性:素灰+均匀柔光,画风色调破坏规范 |
| 道具定妆(基础) | ❌ 不注入色调/氛围;✅ 渲染层 | 同上 |
| 场景主视图(基础) | ✅ 全量注入(色调/氛围/镜头/渲染) | 画风主战场 |
| 描述补全 | ✅ 注入色彩倾向/氛围倾向(克制) | 描述服务于下游生成 |
| 衍生变体 | ✅ 全量注入 + 行级"画风"列可覆盖 | 调度清单扩展列 |
| 确认环节 | 步骤 0 题材确认时,回显"题材→默认画风",用户确认或 `--style` 覆盖后才继续 | 精确优先,绝不允许静默默认 |

> 注:调度清单已存在的用户可编辑文件,新增「画风」列即完成行级覆盖,与 ADR-0004 决策 3 一致。
