# 判官验证规范（双判官闭环，必做）

> 目的：防止"看着分析得漂亮、用起来没效果"的垃圾卡入库。
> 验证对象不是"像不像原书"，而是"按卡能不能写出中国网文味"——
> 因为卡本来就是给改写者当静态基线用的，测生成力才是测对地方。

## 流程

```
新卡产出（验证状态: 未验证）
  → ①写手判官：按卡写 3 段样本（打脸/围观/金句各 200-300 字）
  → ②评审判官：独立盲评"像不像中国网文"（逐轴 1-5）
  → 平均 ≥4 且无单轴 ≤2 → 通过 → 入库登记
  → 不达标 → 回炉改卡（≤2 轮）→ 仍不过 → 标"不合格"废弃
```

## ① 写手判官（派子代理）

- **输入**：只给风格卡文件（可执行规则部分）——**不给原文、不给索引、不给样本段**
- **任务**：按卡写 3 段 200-300 字样本，场景分别为（书卡）：
  1. 打脸碾压场景（反派挑衅→主角回应→围观反应）
  2. 围观震撼场景（强者出手→观众反应）
  3. 金句宣言场景（主角抛出一句宣言）
- **场景专卡（2026-08-17 增）**：样本场景改为该卡的 3 个子型
  （如感情线卡=暧昧心动/告白/离别；智斗布局卡=设局/博弈/揭晓；
  危机化解卡=绝境/破局/余波——以卡内"场景节奏"区定义为准），
  判官评分轴不变（场景完整性轴按该场景要素核）
- **场景内容自拟**（虚构人物与事件，不写任何原书内容）——顺带验证锚点纪律
- 硬约束：禁止读取卡库其他文件、禁止搜原文

## ② 评审判官（派子代理，独立于写手）

- **输入**：只给 3 段样本 + 一份"中国网文风格共识"基准
  （可引用包内 `references/风格基准.md`）
- **任务**：逐轴评分（1-5）：
  - 句子节奏 / 段落 / 词汇 / 语气腔调 / 情绪强度 / 开头收尾 / 网文味整体感
- **判定**：平均 ≥4 且无单轴 ≤2 → 通过
- **输出附带**：每个场景的"强项/弱项"结论（用于登记 `场景强项` 字段）

## 评分后处理

| 结果 | 处理 |
|------|------|
| 通过 | 更新卡 frontmatter：`验证状态: 已验证` + `场景强项: 打脸碾压:A 围观震撼:B ...` → 跑 build_card_index.py |
| 回炉（≤2 轮） | 拿评审判官的具体意见改卡的可执行规则 → 重新验证 |
| 2 轮仍不过 | 卡标"不合格"废弃，不入库；告知用户原因 |

## 红牌（出现即返工）

- 「我自己看挺像的，不用判官了」→ 自评不算数，判官必做
- 「样本写得像原书」→ 写手判官偷读了原文，验证无效
- 「判官说缺 X，我加一段进去凑分」→ 卡要改的是规则，不是给写手加戏
- 「规则堆满签名动作更像」→ 调料不是公式，堆满是拙劣模仿
