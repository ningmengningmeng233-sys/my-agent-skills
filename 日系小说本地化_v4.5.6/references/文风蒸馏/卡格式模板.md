# 风格卡格式模板

> 每张卡输出为一个 md 文件：`<卡库目录>/<书名>-<作者>-风格卡.md`
> 卡只写"怎么写"，不写"写了什么"。

## frontmatter（脚本 build_card_index.py 解析字段，勿改名）

```yaml
---
书名: 《XX》
作者: XXX
蒸馏日期: YYYY-MM-DD
卡类型: 网文风格卡（文风蒸馏·如何写）
取样章节清单:
  - 开篇钩子: 第X章 xxx（段NNN）
  - 打脸/金句宣言: ...
  - ...（7 类场景各一行）
样本规模: N 段原文直读，每段约 800-1500 字
验证状态: 未验证 | 已验证   ← 判官验证通过后改为已验证
锚点验证: 待验证 | 通过 | 部分通过 | 失败   ← verify_anchors.py 产出；失败不得入库
卡源: 标准蒸馏 | 外部适配   ← 蒸馏七步产出=标准蒸馏；用户提供转换=外部适配
场景强项: 打脸碾压:A 围观震撼:B 金句霸气:A  ...   ← 判官验证后登记（A/B/C 等级）
---
```

## 正文结构

```markdown

> 本卡只写"怎么写"，不写"写了什么"。所有规则均可用于新场景写作；
> 锚点原句为唯一允许保留的原文（每句 ≤30 字）。
> 校准注：调料不是公式——签名动作是工具不是清单，堆满即拙劣模仿。

## 〇、母题意象（可选字段，2026-08-16 用户确认）

> 无显著意象的书标"不适用"（爽文类常见），不强制。
```

> （3 本书对照提炼），不绑单书风格。

## 外部卡适配规则（用户提供非标准格式卡时）

1. **识别**：含风格规则/写法提炼、无剧情内容 = 是卡，可适配；
   小说片段/评论/摘要 = 不是卡，退回
2. **转换**：按本模板重新结构化——
   - 无 frontmatter → 补齐（书名/作者提取不到就问用户；
     蒸馏日期=入库日；验证状态=未验证；卡源=外部适配）
   - 缺某些轴/场景 → 标"缺省"——允许缺，绝不编造
   - 剧情复述/评论废话 → 丢弃；锚点超长 → 截到 ≤30 字
   - 完全无锚点 → 标"弱卡"（规则缺证据），判官验证重点测
3. **验证**：照常走锚点验证（有锚点则验证，无锚点=弱卡跳过）+ 判官验证
   （格式可多样，门槛不降）；双通过 → 入库+索引标"外部适配"；
   任一不通过 → 回炉 ≤2 轮 → 仍不过废弃
