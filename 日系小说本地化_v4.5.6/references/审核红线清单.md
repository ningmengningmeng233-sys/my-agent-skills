# 审核红线清单（标记→待确认→用户拍板）

中国短剧平台内容红线检测清单。原则：**AI 标记风险 → 记入待确认清单 → 用户逐案拍板**；
删改是版权方/用户的商业决策，AI 拍板前不预判处理方式。

---

## 一、红线类别

| 类别 | 典型内容 | 风险等级 |
|------|----------|----------|
| **未成年题材** | 未成年恋爱主线、校园恋情重点描写 | 🔴 高 |
| **擦边内容** | 泳装、暧昧、性暗示描写、服装暴露（事业线等） | 🔴 高 |
| **血腥暴力** | 血腥细节、自杀/自残描写、过度暴力 | 🟡 中高 |
| **犯罪细节** | 作案过程详细描写、犯罪方法教学 | 🟡 中高 |
| **宗教/政治敏感** | 宗教批判（"洗脑"论）、政治制度类比、影射现实 | 🟡 中高 |
| **敏感军事词** | 核弹/核武器等现实军事词汇（→ 蘑菇弹/禁忌兵器） | 🟡 中 |
| **价值观冲突** | 等级制美化、霸凌正当化、宿命论宣扬 | 🟡 中 |
| **结局导向** | 悲剧结局/坏人得逞/无正向引导 | 🟡 中 |

### 等级 ↔ 处理流程归属映射（三档 → 两级）

| 等级 | 类别 | 归属 | 确认方式 |
|------|------|------|----------|
| 🔴 高 | 未成年题材、擦边内容（含服装暴露） | 剧情核心红线 | 当场确认（A保留/B调整/C删除） |
| 🟡 中高 | 血腥暴力、宗教/政治敏感、犯罪细节 | 剧情核心红线 | 当场确认 |
| 🟡 中 | 敏感军事词（核弹等） | 边缘红线 | 攒批确认（按通用映射替换） |
| 🟡 中 | 价值观冲突（等级制美化/霸凌正当化等） | 剧情核心红线 | 当场确认 |
| 🟡 中 | 结局导向 | 边缘红线 | 攒批确认 |

## 二、处理流程（分级确认 + 确认来源，与 SKILL.md「批稿路径的交付字段」一致）

1. **检测**：改写时发现红线桥段 → 标记风险（不擅自处理）
2. **分级确认**：
   - **剧情核心红线**（影响走向/审核生死：未成年/擦边/血腥/宗教政治敏感）
     → **当场用可点击选项向用户确认**（A保留/B调整/C删除），拍板后才处理，
     记录：`红线: <桥段> | 处理: <A/B/C> | 确认来源: 用户拍板·批<NNN>·选项<X>`
   - **边缘红线**（用词尺度/背景细节/敏感军事词替换）→ 标记风险 →
     **攒批确认**（每 10 批待确认清单）
   - **AI 无权宣布"已确认"**：未经用户确认的红线只能标【AI 提议·待确认】
     且**保持原文不处理**；红线记录无确认来源 = 未确认 = 该批不得标"已完成"
3. **记录格式**（批稿「本批说明」区，两种格式的关系）：
   - **风险标记**用树状格式（发现问题时）：
   ```
   【审核风险】第X章 段落摘要
   ├─ 风险类型: 未成年恋爱
   ├─ 风险等级: 🔴 高
   ├─ 原文功能: 关系确认的关键场景
   ├─ 状态: 已确认 / 待确认
   └─ 确认来源: 用户拍板·批007·选项B（已确认时必填）
   ```
   - **确认记录**用单行格式（SKILL.md「批稿路径的交付字段」，用户拍板后追加）：
   `红线: <桥段> | 处理: <A/B/C> | 确认来源: 用户拍板·批<NNN>·选项<X>`
   - 两格式并存不冲突：标记格式记"发现与风险等级"，确认格式记"拍板结果"；
     盲审与合并脚本以单行格式的"确认来源"字段为准判定已确认
4. **执行**：用户拍板后按决定调整；未确认的红线保持原文不动

## 三、与架空世界的关系

架空世界规避的是**制度层面**审核（角色生存环境不触碰现实中国制度）；
**内容层面**红线（未成年/擦边/血腥）与背景无关，**架空世界无法规避**，
必须走标红-确认流程。

---

## 四、质量原则

- **保真 vs 过审的冲突由用户裁决**——AI 不预设立场
- 用户拍板"保留"→ 尊重决定，不二次劝阻
- 用户拍板"调整"→ 按"功能保留、场景重构"规则重写该桥段
- 用户拍板"删除"→ 用承担相同叙事功能的新桥段补位，不留剧情漏洞

### 5.1 既有类别扩充（红果规则 → 增补点）

| 既有类别 | 红果规则映射 | 增补执行点 |
|----------|-------------|-----------|
| 未成年题材 | 七、未成年负面内容 | 扩为：未成年**主动错误行为**（自残/斗殴/烟酒/赌博/违法，且无制止批判）+ **暴力欺凌未成年**（殴打虐待/言语贬损/心理创伤）+ 既有"未成年恋爱" |
| 擦边内容 | 五、低俗色情 | 扩为：**低俗性言论**（借低俗物件/标志性语言暗示擦边——"王者之剑/蚯蚓"命中第 4 条）+ 性暗示台词/目光聚焦敏感部位 + 暴露着装 + 既有"事业线" |
| 血腥暴力 | 四、画风观感不适 | 扩为：极端血腥特写（模糊化仍可辨认=违规）/ 施虐氛围（无损伤但压迫受虐感）/ 恶心行径 / 无底线猎奇审丑 / 恐怖惊悚氛围（阴森怪异） |
| 价值观冲突 | 二、不良价值观 | 扩为：**群体妖魔化**（单一负面形象刻画社会群体）/ 极端家庭暴力（致伤残死亡）/ 封建婚恋观（现代场景一对多）/ 出轨偷情宣扬 / 不择手段获取财富（正面人物危害他人生命未批判）/ 夸大财富作用 / **性别物化** |
| 宗教/政治敏感 | 二+六+备案要求 | **宗教 = 备案特殊题材**（短剧口径，含宗教内容须申报）；小说平台对"圣教体系=权力机构"呈现从严——维持"系统性宗教体系呈现"条目 |
| 结局导向 | 二（不良价值观总则） | 维持；补充"宣扬消极颓废人生观"口径 |

### 5.2 新增类别

| 类别 | 要点 | 适用 |
|------|------|------|
| **封建迷信** | 现代场景限制"法术逆天改命/命理风水关联生死/法术作恶"——**关键词"非合理背景"**：架空西幻世界=合理背景，法术/玄学**豁免**；现代背景才受限 | 架空西幻豁免 |
| **不良导向**（政治类） | 历史虚无/领土主权/国家标志/社会热点影射/恶搞公众人物/民族歧视——架空世界天然规避，但改写不得影射现实 | 架空天然规避 |
| **侮辱贬损** | 极端侮辱（非人化手段/狗链狗笼/打砸骨灰盒）+ 密集脏话/人格贬损性辱骂/扇巴掌下跪钻胯等侮辱行为——"过多展现"即违规 | 通用 |

### 5.3 书名/简介红线（质量要求）

> 对 ADR-0001 中文书决策直接可用：书名简介不得含
> 拜金炫富/出轨宣扬/犯罪正向表述/敏感话题煽动/歧视言论/色情低俗/
> 夸张博眼球/营销词（热播爆款）/蹭热度拉踩/特殊符号（除逗号感叹冒号问号双引号外）。

### 5.4 架空世界豁免清单（红果规则中不适用于西幻的部分）

- 封建迷信"法术玄学"——架空=合理背景，豁免
- 现代玄幻荒诞——架空世界不适用"现代科学场景"限定
- 封建阶级文化（帝制/权力崇拜）——**注意**：红果要求"非合理背景下"，
  架空王朝制度=合理背景可豁免；但"宣扬/赞美"导向仍需警惕，
  走标红-确认流程（如弑父情节的核心价值观确认）
- 暴露着装/性行为——不因架空豁免，照常标红确认

### 5.5 执行顺序（改写时）

1. 按目标平台选口径（默认红果/番茄）
2. 检测到红线 → 按第一节流程分级确认（当场/攒批）
3. 命中 5.1/5.2 增补条目 → 同流程；命中 5.4 豁免清单 → 不标红但记录
   "已按豁免规则放行"（留审计痕迹）
4. 源文件存疑（条目细则）→ 查 `平台审查规则/红果-内容审查要求.md`
