# 中文填充词清单（Phrases to Remove — 中文版）

供中文写作/改写时去除 AI 味使用。规则思想与英文版 stop-slop 一致：填充词不加信息，删掉后直接进入要点。

## A. 语气副词堆砌

删除以下副词——它们不增加意义，只增加"AI味"。出现即删，除非删除会改变句意。

- 真的 / 其实 / 简直 / 确实 / 完全 / 彻底 / 居然 / 竟然 / 实在 / 显然
- 完全可以说 / 不得不说 / 不得不承认 / 无法否认

示例：
- ❌ "他确实真的愤怒了。" → ✅ "他愤怒了。"
- ❌ "这简直是一场灾难。" → ✅ "这是一场灾难。"

## B. 空转开场

句首的"清嗓子"短语。直接删掉，进入正题。

- 众所周知 / 众所周知的是
- 值得一提的是 / 值得注意的是 / 令人注意的是
- 不可否认的是 / 毫无疑问 / 毋庸置疑
- 首先 / 其次 / 再次 / 最后（仅当它们是真实序列时保留；纯装饰时删）
- 在这里 / 在此 / 于此处

示例：
- ❌ "值得一提的是，他从未放弃。" → ✅ "他从未放弃。"

## C. 万金油过渡

- 然而 / 但是 / 不过 / 可是 / 却
- 与此同时 / 与此同时的是 / 与此同时，……
- 接下来 / 随后 / 紧接着 / 然后
- 另一方面 / 另一方面来说
- 换句话说 / 换言之 / 也就是说

规则（**段内规则优先**，全书密度为警戒线）：一段内转折连词 ≤ 1 个；
一段内时间过渡词 ≤ 1 个，多于即删，保留最必要的一个；
全书密度警戒线：每千字 >2 次视为过度，触发抽查。

## D. AI 模板句尾

句子/段落结尾的总结性空话。删掉后让内容自己说话。

- 总而言之 / 归根结底 / 说到底 / 说到底了
- 从某种程度来说 / 从某种意义上说 / 在某种程度上
- 简而言之 / 一言以蔽之
- 无论如何 / 不管怎样 / 无论怎样

示例：
- ❌ "从某种程度来说，这改变了一切。" → ✅ "这改变了一切。"

## E. 现代网络词（小说场景禁入）

小说正文（非对话）中禁止使用。若角色对话中刻意使用，需有明确人设依据，否则同样删除。

- 绝了 / 绝绝子 / yyds / 破防 / 天花板 / 顶流 / 出圈 / 内卷 / 躺平
- 洗脑 / 上头 / 上头了 / 蚌埠住了 / 栓Q / 芭比Q了
- 爷青回 / 爷青结 / 集美 / 姐妹（非对话语境）

规则：这些词只允许出现在"明确设定为网感角色"的对话中；叙述层一律禁止。

## F. 量化虚词

以下虚词在中文里常被 AI 滥用。**单个使用可保留（克制的表达是有效的）**，但同一自然段出现 2 个以上即删到 1 个。

- 微微 / 些许 / 稍稍 / 略微
- 一点 / 一些 / 一丝 / 一缕
- 某种 / 一定 / 某些
- 缓缓 / 慢慢 / 渐渐（与上一条冲突时保留更具体的动词）

示例：
- ✅ "他微微点了点头。"（克制，保留）
- ❌ "他微微抬了抬头，稍稍侧过身，些许迟疑地、缓缓地伸出手。" → "他抬了抬头，侧过身，迟疑地伸出手。"

---

## 使用说明

1. 本清单用于**改写/润色后检查**，不用于初始创作——先写，后删。
2. 优先级：删除填充词 > 调整语序 > 补充具体信息。能删就删，删不掉就换更具体的词。
3. 判定"AI味"的终极标准：这句话去掉所有划线词后，意思是否变化？不变 → 删。
4. 与 `structures-zh.md` 配合使用：phrases 管"词"，structures 管"句"。
