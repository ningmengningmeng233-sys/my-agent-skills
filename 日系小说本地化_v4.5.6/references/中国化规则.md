# 中国化规则（全面中国化执行规范）

将日语小说的全部表层符号替换为中国对应物，目标：**观众完全看不出原作是日本小说**。
本文件是改写时的唯一规则源。与 `混合文体规则.md`（文体）、`映射表规范.md`（一致性）配合使用。

---

## 一、书名与章节名

### 书名（决策：中式短名化）

- 长句日轻书名 → 压缩为 2-6 字中式网文风格短名
- 文学类 → 短句雅名（2-4 字，保留原作气质）
- 输出 3 个候选 + 推荐，用户拍板后写入映射表 P0
- 例：《关于我转生变成史莱姆这档事》→《史莱姆之王》

**候选质量标准（三条全满足才可作为候选）**：
1. 2-6 字（网文风）/ 2-4 字（文学风）
2. 保留原作核心气质（爽感/神秘感/世界观暗示，不是随意取名）
3. 3 个候选**风格互不相同**（如：直白爽感型 / 悬念型 / 意境型），方便用户对比选择

自查：候选名念出来是否像中国网文书名？不像则重拟。

### 章节名（决策：保留个性章名）

- 保留章节标题的个性与"反转式"结构（日轻章名的节奏标记是分场依据）
- 仅中文化措辞："第X話"→"第X话/章"；长句章名翻译成通顺中文
- 例："〇〇、しかし××" → "〇〇，但××"

## 二、人名与称谓

### 角色名（决策：暗示型新名）

- 按角色性格/命运取有暗示的中文名（保留原作"名字=角色功能"的设计）
- 例：黑羽→夜枭（黑暗暗示）；雪→凌霜；樱→晚晴
- 名字须为常见中国姓氏+名，避免"崎/藤/井/泽/田"等日系高频字做姓
- **禁用"X·Y"间隔号复姓式**（如"蔷薇·沧云"）——读起来像外国人名，
  一律合并为纯中式名（例：蔷薇·沧云→沧云薇）
- 与情节相关的重要名字（名字即伏笔）→ 新编中文双关（见双关规则）

### 机构与组织名（决策：优先中式化——实测反馈）

- **骑士团/冒险者公会/圣教堂**等西幻机构名**优先中式化**：
  骑士团→骑查司/御骑卫/巡查司、圣教堂→英雄殿、冒险者公会→武者行会/佣兵堂
  （见通用映射第七节）
- 纯西幻氛围词（魔法/魔力/骑士称号）保留——"魔力"不改为"灵力"（用户决策：
  魔力是常见网文词，保留）
- 判断标准：机构名读起来不像"翻译过来的外国组织"即可

### 称谓（决策：关系+场景双维映射）

| 日式 | 关系维度（长辈/平辈/晚辈） | 场景维度（校园/职场/江湖） |
|------|--------------------------|--------------------------|
| さん | 长辈=叔/姨/爷；平辈=哥/姐/直呼名 | 职场=职位（王经理/李医生） |
| くん | 直呼名/小X/阿X | 校园=同学互称 |
| ちゃん | 小名/叠字/昵称（小美/璐璐） | 亲密关系专用 |
| 先輩 | 校园=学长/学姐/师兄/师姐 | 职场=老师/头儿 |
| お兄ちゃん/お姉ちゃん | 哥/大哥/二哥；姐 | 家庭内 |
| 先生（老师） | 老师/师父/师傅 | 按场景定 |

每个角色一条"称呼规则"写入映射表：`谁叫他什么`（含亲疏层级）。

### 自称（决策：B+C 混合）

- 极端人设：粗犷男="老子/爷"；傲娇大小姐="本小姐"；市井="咱"
- 普通角色：不靠自称区分，靠对话风格（语速/用词/口头禅）体现性格
- 中文只有一个"我"——不要在自称上过度发挥，性格靠语气表达

## 三、文化符号替换（爽文标准）

### 生活场景词（决策：全部替换，含食物）

**完整日→中词表见 `通用映射.md`（单一事实来源）**——食物/生活场景/服饰/意象/语气词/
拟声词全部在通用映射维护，本文件不重复定义。改写时直接查通用映射词库。

原则：**核心目标 = 中国观众能接受的样子，不是纯正中国风**：
- **必换（日本痕迹）**：人名/称谓/和服/神社/日式食物/日式语气词/樱花意象等
- **可留（中国观众接受的外国元素）**：西幻框架（魔法/骑士/精灵/教会/贵族世家）、
  架空世界观——观众读到不会联想到"这是日本小说"即可
- **前世设定**：一律架空（"上一世/那个世界"），不锚定任何具体国家
- 背景设定**不出现"现实中国"的制度符号**（避免审核与自洽问题）

### 情绪意象词（决策：B 为主 C 允许）

**完整日→中意象词表见 `通用映射.md` 第四节（单一事实来源）**，本文件不重复定义。
处理原则：以中文近似表达为主（物哀→"说不清的怅惘"），已入中文语境的词（羁绊）可保留。

## 四、语体与身份

### 礼貌度（决策：称呼+语气双轨）

- 生疏关系：全名 + 您/请/承蒙
- 熟络关系：昵称 + 随意语气（"咱俩""说真的"）
- 不用"です/ます"式敬语痕迹（"呢/吧"滥用也是翻译腔）

### 身份语/口癖（决策：口头禅+用词习惯，不用中文方言）

| 日式身份语 | 中文方案 |
|------------|----------|
| 关西腔（亲切市井） | 口头禅（"得嘞""成"）+ 用词市井 |
| 大小姐语（ですわ） | 书面语+矜持用词（"罢了""有趣"）+ 句尾习惯 |
| 老人语（じゃ/ぞ） | 四字成语/古语用词（"老夫""甚好"） |
| 恶役语（だぜ/だぞ） | 短句+命令式（"给我等着！"） |

**禁用中文方言**（东北话/四川话自带喜剧人设与地域联想，会扭曲角色定位）。

## 五、文字游戏

### 双关/谐音（决策：分级处理）

- **剧情关键处**（名字即伏笔/台词双关推动剧情）：新编中文双关，保留叙事功能
- **装饰性谐音**（冷笑话等）：直接放弃，意译即可

### 拟声拟态词（决策：全中式，保持日式密度）

**完整日→中拟声词表见 `通用映射.md` 第六节（单一事实来源）**，本文件不重复定义。

保持日文小说的拟声词密度（密集使用中式拟声：怦怦/刷/咔哒），保留节奏感但不留日语音。

## 六、叙事习惯

### 视角（决策：第一人称保留）

- 第一人称小说保留第一人称（角色的声音，转第三人称丢人设）
- 第一人称 + 短剧不冲突：剧本台词本来就是第一人称

### 章末（决策：钩子强化）

- 章末统一强化钩子（断章式强钩子），服务短剧出口
- 日式"且听下回分解"→ 中式"断章"（悬念前置）

### 语气词（决策：按功能转中文）

**完整日→中语气词表见 `通用映射.md` 第五节（单一事实来源）**，本文件不重复定义。
处理原则：按功能转中文（ね→对吧/你说呢、よ→着呢/好吧、ぞ/ぜ→强语气、
まあ→嘛/算了、句尾な→转心理描写或省略）。

## 八、骨架桥段（功能保留、场景重构）

日式文化桥段不找"表面对应物"（学园祭≠校运会），而是**重新设计能承担相同叙事功能的
中国架空场景**：

| 桥段 | 叙事功能 | 重构方向 |
|------|----------|----------|
| 文化祭 | 公开场合紧张+关系暧昧推进 | 架空中国的"节庆/集市/比武大会"等 |
| 神社初詣 | 许愿+命运感 | 庙会/祈福仪式 |
| 告白文化 | 关系确定的高张力场景 | 按架空世界重建（城墙下/比武后/雨天） |
| 前辈后辈制 | 权力关系+成长 | 师门/堂口/社团的层级 |
| 社团部活 | 团队归属+日常 | 架空学院/武馆的日常训练 |

原则：**剧情功能一点不少，文化外衣完全中国化**。判断标准：重构后的桥段，
中国观众读完不会想到"这是日本学校那套"，但情节功能（气氛/关系/冲突）完整保留。
