# 分发验证范围

本分享版源于UMH提交153742d，核心归档的SHA256记录在BUILD-SOURCE.json和DISTRIBUTION.json。原归档通过既有分发包安全/完整性校验，第三方运行资源按冻结清单提取。附带已安装固定版本Node依赖；不会打包作者的数据根、客户端配置、凭据、现场记录或备份。

本机验证项目：
- 技能格式、整包逐文件SHA256、Node/Python及Windows PowerShell ACL环境检查。
- 完整复制到独立的中文和空格路径，在原工作树之外运行，清除NODE_PATH/PYTHONPATH等额外查找路径。
- 从零初始化隔离数据根，生成并应用仅指向测试配置的连接计划。
- 实际启动中央服务、加载五个MCP工具、提交候选、管理审核后召回。
- 停服务、撤销测试配置、保护已有字段、生成离线备份。
- 独立代理按“陌生用户/不同盘符/无作者目录”的情境复核入口、迁移及撤销流程。

上述MCP调用是隔离SDK分发测试，不是接收者原生客户端验收。没有在另一台真实电脑执行，也未重测其他系统；接收者实际客户端必须按clients.md验证，不继承作者原生PASS。

迁移限制：先撤销活动连接再搬移；分享入口拒绝可能覆盖活动回执的preview。包内原始核心CLI不含此入口保护，不应绕过scripts/umh.mjs直接覆盖活动连接。
