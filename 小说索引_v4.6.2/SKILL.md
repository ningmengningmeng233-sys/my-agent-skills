# 小说索引 v4.6.1：编排器协议

目标：**可检索、可复核、可恢复的小说索引库**。模型必须执行流程并留下验证证据；“读过”“生成过”“看起来完整”都不等于完成。

## 0. 路由：先选一个分支

| 分支 | 识别语境 | 立即读取 | 最终交付 |
|---|---|---|---|
| 建库 | 从 `.txt/.md` 建立小说索引 | `references/建立索引.md` 的建库部分 | 段文件、章节索引、小说导航、验收摘要 |
| 追更/重建 | 已有书库，源文件新增、修订或需要重跑 | `references/建立索引.md` 的追更/恢复部分 | 受影响索引、刷新导航、增量验收 |
| 检索/验证 | 查询章节、剧情、原文位置，或要求体检/修复 | 检索读 `references/索引内容.md`；验证读 `references/建立索引.md` 的验证部分 | 分级检索结果或验证报告 |
| 基于索引创作 | 明确提到小说索引、索引桥段或防撞车 | `references/索引内容.md` 的创作部分 | 创作稿、素材出处、防撞车清单 |
| 文风蒸馏 | 指定已索引作品/作者的笔法 | `references/索引内容.md` 的文风部分 | 轻量风格卡或外部完整蒸馏；未配置外部 skill 时仅输出轻量风格卡 |
| 删除/恢复 | 删除某书、恢复备份、重置库 | `references/建立索引.md` 的运维部分 | 二次确认记录和复核报告 |

只说“续写/仿写/总结/查一下”时，先询问目标小说、索引库和范围；不读取原文、不扫描全库。普通短剧仿写、通用文风分析和无可溯源作品不由本技能接管。

## 1. 不变量：任何分支都必须遵守

- `<技能目录>` = 本 `SKILL.md` 所在目录；`<索引库>` = `<技能目录>/.env` 的 `INDEX_LIB_DIR`，为空则 `<技能目录>/索引库`。
- 所有模板、reference、脚本从 `<技能目录>` 解析；所有索引 `源文件` 路径相对 `<索引库>` 解析，绝不相对 cwd。
- 源文件、段文件和已完成索引默认只读。需要改变内容时走追更或重建，不在检索阶段直接改文件。
- 建库可以读取必要源文件；检索/创作按四级读取和授权作用域执行；定位类豁免只覆盖完成定位所需的索引读取，不扩展到原文或全文。
- 不编造章节、行号、API 成功、子代理结果或索引状态。任何失败、截断、待核、零命中都如实标注。
- 未通过验证的结果只能标记 `BLOCKED` 或 `NEEDS_REVIEW`，不能写“已完成”。

`.env` 不存在时使用 `direct` 和默认 `<技能目录>/索引库`，同时提示配置 API；`subagent` 只有宿主确实提供 Agent/子代理能力时才可用，否则停在 `BLOCKED` 或回退 `direct`。脚本使用技能目录绝对路径，例如：

```text
uv run --with requests --with python-dotenv python "<技能目录>/scripts/脚本.py" ...
```

## 2. 分支流程：按分支读取对应 reference

不要把 reference 当作背景材料通读：只读与当前分支对应的小节，读完后立刻返回执行。

| 分支 | 读取文件 |
|---|---|
| 建库 / 追更 / 重建 / 验证 / 删除 / 恢复 | `references/建立索引.md` |
| 检索 / 授权 / 创作 / 文风蒸馏 | `references/索引内容.md` |

## 3. 共同交付契约

每个分支结尾使用以下结构：

```text
状态：DONE / BLOCKED / NEEDS_REVIEW
范围：本次处理的书、章节、文件或抽样范围
读取/生成：实际读取和写入的路径清单
验证：命令、返回码、关键统计或人工抽检结果
失败项：没有则写“无”
恢复/下一步：可直接执行的下一步；未完成不得省略
```

## 4. 资源指针

- 建库、追更、验证、恢复、删除：`references/建立索引.md`；读取对应分支小节。
- 检索、授权、全文搜索、跨书、创作、文风：`references/索引内容.md`；先执行授权决策，再执行读取层级。
- LLM 输出：`templates/直调任务模板.md`；子代理输出：`templates/子代理任务模板.md`。
- 章节索引：`templates/章节索引模板.md`；小说导航：`templates/小说索引模板.md`；标签：`templates/包含元素标签词汇表.md`。
