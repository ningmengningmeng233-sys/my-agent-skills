# 命令速查与红旗（知识库转录_v5.4.2 SKILL.md 深参）

> 归属：本文件内容自 `SKILL.md` 的「命令速查（本仓·主干）」与「常见错误 / 红旗」两小节整段挪入，一字未改；SKILL.md 原位置保留小节标题与指针。双胞胎对端 成人文学索引_v4.8.1 有同名文件，本仓（内核主干）命令以本文为准。

## 命令速查（本仓·主干，均已对照 scripts/ 代码核对）

统一调用前缀：`uv run --with requests --with python-dotenv python "<技能目录>/scripts/脚本.py"`；`orchestrate.py` 的 `--lib` 为全局参数。

| 目的 | 命令/子命令（关键参数） |
|---|---|
| 初始化/看状态 | `orchestrate.py --lib "<知识库>" init` / `status` |
| 完整建库 | `orchestrate.py build --source <文件> --novel <名> --author <作者> [--volume] [--chapters-per-seg 5] [--chars-per-seg 10000] [--workers 32] [--force] [--skip-existing]` |
| 验证门禁/续跑 | `orchestrate.py verify`；`orchestrate.py resume [--workers 32]` |
| 删书/删单篇 | `orchestrate.py delete --novel <名> --author <作者> [--yes]`；删独立文档集中单篇用 `delete_novel.py --doc <篇名>` |
| 语义索引（默认关） | `orchestrate.py semantic build [--model] [--force] [--batch-size 32]` / `semantic search "<查询>" [--top-k 5] [--threshold 0.5] [--json]` |
| 行号校准/引用体检 | `verify_and_fix_lines.py ["<索引文件或目录>"...] --lib <库>`（缺省校准 段索引/ 全部）；`check_line_refs.py --lib <库> [--detail] [--strict]` |
| 重命名/迁移旧库 | `rename_novel.py --old-novel --old-author --new-novel --new-author --lib [--yes]`；`migrate_library.py --from <旧> --to <新> [--copy] [--yes]` |
| 节点池体检/演练 | `probe_pool.py [--config] [--json] [--only <节点>] [--timeout 40]`；`failover_drill.py [--workdir] [--kill-all] [--json]` |
| 向量选型/环境自检 | `hardware_profile.py [--json] [--host <Ollama地址>]`；`check_env.py [--lib <库>] [--json] [--pull]` |
| Web 控制台 | `start_web.py [--lib <库>] [--host] [--port 5888]`（默认仅监听 127.0.0.1） |

## 常见错误 / 红旗（本仓代码防御分支与测试实测，非臆造）

- **llm_nodes.json 占位符密钥没改就建库**：`api_pool.py` 按占位符特征识别并只列节点名、绝不回显密钥；未配置即建库前置 `BLOCKED`（0.2 节）。先跑 `probe_pool.py`。
- **把向量召回当最终证据 / 静默换 embedding 模型**：语义检索只是默认关闭的辅助召回，关键结论必须回读原文补行号；`semantic_index.py` 拒绝零向量/空向量/静默换模型，`engine=test` 的 hash 向量禁止发布正式索引（`assert_vector`，测试 `test_semantic.py`）。
- **同一库并发构建**：`.build.lock` 进程锁直接拒绝并行（测试 `test_build_lock_rejects_concurrent`）。
- **建库后不跑校准就报 DONE**：`verify_and_fix_lines.py` / `check_line_refs.py` 返回 0 是 `DONE` 前提；章节小标题逆序、行号越界会被 `build_segment_index.py` 的 `validate_index_output` 拒收（测试 `test_review_fixes.py`）。
- **书名/目录名含 `[` 等 glob 元字符**：`check_line_refs.py` 对 `--lib` 做 `glob.escape`，删除走 `norm_name` 转义，防误伤他书（测试 `test_ops.py` 括号名用例）。
- **问答无限扩读**：核对预算 3 段/3 万行，超限必须熔断请示（第 2 节），不得越出知识库工作区。
- **指望远程 Ollama 自动拉起**：仅本机地址才自愈启动，远程配置只探测不启动（测试 `test_ollama_autostart.py`）；故障转移演练绝不泄露 api_key（测试 `test_failover_drill.py`）。
- **用户只说「建库/追更/体检/索引库」未指明语料就抢单**：这些词与孪生「成人文学索引」共用；语料是小说/TXT网文、目的为笔法蒸馏或仿写归对端，本仓只接长篇专著/资料/独立文档集与带文件名+行号双引用问答，拿不准先问一句语料类型（测试 `tests/test_skill_discovery.py` 锁排除句）。
