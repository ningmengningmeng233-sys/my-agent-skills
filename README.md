## 下载和使用

- 完整取用可在 GitHub 的 Code 菜单选择 Download ZIP，解压后选择需要的技能目录。
- 按各技能的 `INSTALL.md`、`references/SETUP.md` 或 `SKILL.md` 准备依赖与宿主入口；无需安装全部技能。
- `.env.example` 是配置模板，真实密钥、Cookie、转录库和模型缓存由使用者自行准备。
- 部分包包含校验清单及随包依赖，保持原始文件，按包内说明验证。

## 已知边界

- 目录收录、工程验证、宿主安装、自然触发、真实业务及公开发布是不同状态；完整跨系统和多宿主验收尚未完成。
- 知识转录索引 1.5.0 保持待核验，不能替代知识库转录技能。
- 素材公开档排除了受限风格图片，相关视觉能力不可用。
- 各技能和第三方组件遵循各自的许可及来源声明；本仓库不统一授予 MIT。B站转录的 README 与入口许可声明冲突尚待裁决。
