# 知识库索引（知识库索引 v5.4.7）

> **作者：柠檬才不萌 · 联系：ningmeng2233@qq.com**
>
> 专为严肃知识库设计的专业索引与精准可溯问答引擎。以「长篇专著」与「单篇独立文档」为主要知识形态，通过「书导航 → 段索引提取卡 → 聚合比对 → 原文深度核对」四级路径，实现精度优先、有据可查、精确标注原文行号的带引用精准问答。
>
> 快速开始：`QUICKSTART.md` ｜ 常见问题与排错：`FAQ.md`

---

## 这是什么？

一个 **AI Agent 知识库技能包**。将海量长篇专著与独立文档切分、精炼提炼为包含**「本段概要、知识点条目（概念/方法/数据/观点）、逐字关键引用、实体、交叉引用、通用标签」**的高信息密度知识提取卡。

在用户提问时，彻底告别模型幻觉与模糊记忆，直接检索索引提取卡，并在 3 个段落或 3 万行原文预算内深度核对原文，输出回答到点子上、带精确原文行号（如 `《深度学习》原文/深度学习-001.md:120`）的高质量解答。

**双执行器支持**
- **执行器 1（默认直调引擎）**：32 路线程并行直调 LLM，429 限流自动退避重试、SQLite 断点层（中断重跑零浪费）、行号双层自动校准（逐字关键引用 + 行号区间）。
- **执行器 2（子代理派发）**：`INDEX_EXECUTOR=subagent`，在宿主环境支持 Agent 时进行多代理协作。

## 核心架构与宋氏思考决议

| 维度 | 决策方案 |
|---|---|
| **核心定位** | 彻底剥离小说创作模式，全面转型为「知识库索引」，版本为 v5.2.0。 |
| **资料形态** | 混合形态：以长篇专著为主（章节结构清晰），单篇独立文档为辅（通过 `--doc` 统一汇入虚拟书「独立文档集」）。 |
| **核心业务** | 带引用精准问答（精度优先，贵一些准一些，回答到点子上）。 |
| **提取卡结构** | 本段概要 / 知识点条目（概念/方法/数据/观点+行号） / 关键引用（逐字+行号） / 实体 / 交叉引用 / 通用标签。彻底移除爽点、伏笔、情绪弧线、手法分析。 |
| **目录规范** | 新三目录：`原文/`、`段索引/`、`书导航/`。 |
| **授权与预算** | 用户提问即视为整体授权，但设置 3 个最相关段落原文或累计 3 万行原文核查预算，超限必须暂停询问。 |
| **两级删除** | 支持虚拟书单篇文档删除（`delete_novel.py "独立文档集" --doc "文档名"`）与整集高危二次确认删除。 |
| **文风蒸馏** | 全链路彻底废除与清理（ADR-0009 已被 ADR-0015 取代）。 |

## 目录结构

```text
知识库/
├── 原文/                  # 拆段存放目录
│   ├── <书名-作者>/       # 长书分段（如：第1章~第5章-001.md）
│   └── 独立文档集/        # 独立文档分段（如：独立文档集-白皮书-001.md）
├── 段索引/                # 知识提取卡（如：<书名-作者>-001-idx.md）
├── 书导航/                # 书籍及独立文档集导航（如：<书名-作者>.md、独立文档集.md）
├── .index_state.db        # 断点管理与 hash 校验库（SQLite）
└── .semantic_index/       # 可选向量辅助检索索引缓存
```

## 核心命令与用法

### 1. 拆段

```text
# 长篇著作（按章节切分，默认 5 章/段）
python scripts/split_segments.py "<源文件路径>" --novel "书名" --author "作者" --lib "<知识库>"

# 单篇独立文档（按字数切分，并入独立文档集）
python scripts/split_segments.py "<源文档路径>" --novel "文档名" --doc --lib "<知识库>"
```

### 2. 生成知识提取卡

```text
# 直调引擎批量提取
python scripts/build_segment_index.py "<知识库>/原文/<书名-作者>/" --lib "<知识库>" --skip-existing
```

### 3. 行号校准与体检

```text
# 行号校准
python scripts/verify_and_fix_lines.py "<知识库>/段索引" --lib "<知识库>"

# 批次与体检
python scripts/_验证批次.py --lib "<知识库>"
python scripts/check_line_refs.py --lib "<知识库>" --detail
```

### 4. 发布与刷新书导航

```text
# 长书导航生成
python scripts/build_novel_index.py --novel "书名-作者" --lib "<知识库>" --force

# 独立文档集全局导航刷新
python scripts/build_novel_index.py --novel "独立文档集" --lib "<知识库>" --force
```

### 5. 编排器一键全流程

```text
python scripts/orchestrate.py --lib "<知识库>" build --source "<源文件>" --novel "书名" --author "作者"
```

### 6. 两级删除与库运维

```text
# 单篇独立文档删除
python scripts/delete_novel.py "独立文档集" --doc "文档名" --lib "<知识库>"

# 整书删除
python scripts/delete_novel.py "书名-作者" --lib "<知识库>"

# 旧库一键升级迁移（自动将旧三目录与字段改写升级到 v5.0）
python scripts/migrate_library.py "<旧库路径>" "<新库路径>"
```
