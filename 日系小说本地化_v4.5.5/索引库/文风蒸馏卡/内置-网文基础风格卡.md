# 内置-网文基础风格卡

本卡是 skill 自带的最小可用风格卡（v4.3.0 起随包分发），规则全部提炼自
`references/风格基准.md` 与 `references/去AI味-问题清单.md`，不包含任何外部
小说句面。用户索引库存在时优先使用用户卡片；本卡保证「索引库为空也不静默」。

### 1. 句子节奏

- **规则**：欧化长句/从句堆叠/多重定语 → 中式短句直叙；主语在前，动作直给。
- **规则**：正式书面腔 → 网文口吻；「进行了一番思考」→「琢磨了半天」。
- **规则**：句子长短交错；连续 3 句同长 = 念经感，拆开或合并。
- **规则**：破折号、随即/紧接着/与此同时 等连接词每万字要控制在阈值内。

### 2. 爽点与打脸

- **规则**：日式含蓄碾压 → 中式明面打脸；隐藏实力要写出围观者反应。
- **规则**：关键情绪高潮必须有 ≤20 字、无语气词、可独立引用的金句。
- **规则**：反派必须先有「打脸价值」；有苦衷的反派也先被打脸、后揭苦衷。
- **规则**：情绪外放一档：愤怒拍案/红了眼眶/大笑，不写「沉默不语」。

### 3. 章末钩子

- **规则**：正文章节最后一段必须落在悬念、反转、威胁、新信息或情绪最高点。
- **规则**：日式「且听下回分解」式平淡收尾 → 中式断章：卡在冲突最高点。
- **规则**：钩子不改变已确认事件图，只强化原有段落的落点表达。

### 4. 去AI味

- **规则**：不用「众所周知/值得一提的是/总而言之/归根结底」等模板语。
- **规则**：不用「不是……而是……」连续排比；不用对仗三连。
- **规则**：每段有具体物件/动作/数字；人物说人话，有口语毛边和口头禅。
- **规则**：不追求全面安全；敢于给出立场、判断和脾气。
