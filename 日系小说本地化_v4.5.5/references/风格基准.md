## 二、风格差异对照（日式 → 中式）

| 维度 | 日式习惯 | 中式基准（来自索引库共识） |
|------|----------|---------------------------|
| **碾压表达** | 含蓄、心理活动多（"原来如此"） | 明面打脸、围观反应、众人震惊 |
| **升级时刻** | 内在感悟、静默突破 | 突破+威压外放+他人反应 |
| **情感冲突** | 暧昧、留白、欲言又止 | 修罗场、直接对峙、情绪爆发 |
| **悲伤表达** | 物哀、氛围、不说破 | 虐心、催泪、发刀（但要给情绪出口） |
| **日常章节** | 缓慢铺陈 | 压缩为过渡，快速回到主线 |
| **章末悬念** | "且听下回分解"式平淡 | 断章式强钩子（卡在冲突最高点） |
| **反派处理** | 有时模糊、有苦衷 | 反派要有"打脸价值"（衬托主角） |
| **战斗描写** | 一招一式、过程长 | 招式+境界压制+围观震撼，节奏更快 |

## 三、风格执行规则（改写时必须对照）

### 规则 1：打脸时刻必须"围观化"
日式碾压常常只有主角和对手在场、以内心活动呈现。中式要求**有围观者反应**：
众人震惊、低声议论、有人失态。改写时若原场景没有围观者，可加"观众"层
（架空世界自由度高，加角色成本低）。

### 规则 2：金句必须有（含检查标准）
每个重要情绪高潮（身份揭露/复仇完成/表白/决裂）必须有一个"金句"——
短、有力、可记忆。这是中式读者最强的爽点记忆点。

**金句检查标准（三条全满足才算成立）**：
1. ≤ 20 字（可一句话说完）
2. 不含语气词/口头禅（"啊""吧""了"等不算金句）
3. 脱离上下文可独立引用（单拎出来仍有力，如"三十年河东，三十年河西"）

自查方法：改写后把候选金句单独念一遍——如果离开章节上下文就没味道，重写。

### 规则 3：日常章压缩
日式小说的"日常回"（校园日常/相处日常）是节奏放缓点。中式基准要求：
- 保留日常的**功能**（关系推进/性格展示）
- 删除日常的**铺陈**（场景细节、无事件对话）
- 每章日常占比 ≤ 30%，且日常中必须埋钩子（下一冲突的暗示）

### 规则 4：情绪外放一档
日式"克制"→ 中式"外放"：
- 愤怒：日式"握紧拳头沉默" → 中式"拍案而起/怒极反笑"
- 悲伤：日式"望着远方不语" → 中式"红了眼眶/声音发颤"
- 喜悦：日式"嘴角微扬" → 中式"大笑/激动"

> 与去AI清单的关系：去AI清单（phrases-zh/structures-zh）会删除"真的/简直"等
> 副词堆砌——那是**词级**的填充词，与本规则**句级**的情绪表达不冲突。
> 冲突时按优先级：风格基准（本文件）优先（顺序见 references/流程指南.md 四、规则优先级）。

### 规则 5：反派打脸价值
- 反派必须**值得被打**（傲慢/欺压/轻蔑主角），给读者"期待打脸"的情绪
- 日式"有苦衷的反派"保留，但苦衷要在被打脸**之后**揭示（先爽后深）

### 规则 6：力量体系按世界设定保留（不强制中式化）
异世界西幻框架（魔法/魔力/勇者/魔王/精灵）**保留**——中国观众接受西幻（斗破苍穹
即为混搭先例），且西幻不属于"日本痕迹"（历史决策：西幻框架保留，
见 `实测反馈修订.md` 决策索引 #26；"魔力"词保留为实测反馈 #12 决策）。
- 力量体系**跟随原作世界设定**：原作是西幻 → 保留魔法/斗气/魔力的表述
- 只有**日式特有的力量表述**才需转换（如"魔力暴走"→ 灵力失控/气机紊乱，按映射表）
- 等级/突破等**叙事节奏**（境界压制/威压外放）仍按中式爽感处理，但名词不强制换成
  修仙体系——"斗气化翼"和"金丹出窍"都是可接受的，取决于原作设定
- 判断标准：观众读完不会觉得"这是日本小说"，而不是"必须看起来像仙侠"

### 规则 7：叙事语言汉化（防"翻译腔外壳"——实测反馈）
词都换对了，但句子读起来"像翻译的/像外国人写的"，是本地化最隐蔽的失败。
**语言层面必须达到"母语者随手写的"标准**：

1. **欧化句式 → 中式短句直叙**：被动句、从句堆叠、多重定语 →
   主语在前、动作直给。如"被她所注视着的我，感到了一种难以言喻的感觉"
   → "她盯着我，我说不上来那是什么感觉。"
2. **正式书面腔 → 网文口吻**："那么，就让我们……" → "那就……"；
   "进行了一番深入的思考" → "琢磨了半天"；"展示出" → "露了一手"
3. **长排比/并列赞美 → 拆短+口语+吐槽**：连续三四个并列句的赞美/感慨
   读着别扭，拆成短句，或加一句主角式吐槽收尾
4. **现代行政词 → 网文词**：高层人士→达官贵人、官员→朝臣（见通用映射第八节）
5. **自查**：改写后朗读一遍——如果哪句话"像公文体/翻译腔/外语直译"，
   重写。判断标准：**读起来像中国人随手写的网文，而不是翻译过来的**。

> 与翻译腔硬门槛的关系：硬门槛（check_localization.py）查的是**词级/句尾**残留
> （"……的样子""……的感觉"）；本规则管**句级语感**（欧化句式/书面腔），
> 脚本查不出，靠 AI 自查 + 盲审"够味性"判断。

## 四、风格基准的验收

改写后对照本文件检查：
- 每个身份揭露/实力展示场景：有围观反应吗？（规则1）
- 每个情绪高潮：有可记忆的金句吗？（规则2）
- 每章日常占比 ≤30% 吗？（规则3）
- 情绪表达是否比日式外放一档？（规则4）
- 反派有"打脸价值"吗？（规则5）
- 力量体系是中式表达吗？（规则6）
- 语言读起来像中国人随手写的吗？（规则7：欧化句式/书面腔/长排比自查）

与 `质检规范.md` 的抽查项配合：这些规则主要影响"叙事节奏"与"情节保真"打分。
