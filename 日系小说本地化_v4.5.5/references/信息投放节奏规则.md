# 信息投放节奏规则（悬念式挤牙膏，2026-08-16）

> 实测参照：《斗破苍穹》黑色古戒——情感钩子先行（母亲遗物/十年眷恋）
> → 信号只露一角（"诡异毫光，眨眼便逝"）→ 不给解释 → 几十章后药老登场揭。

## 病灶（要改掉的写法）

一次性倒尽：人物出场即全档案、宝物到手即全说明书、真相发现即全揭晓
——钩子全断，读者没有"想知道"的驱动力。

## 规则

### 1. 悬念埋设三要素（新悬念首次出现时）

1. **情感/利益钩子先行**：先让读者关心这个东西（遗物/恩情/利益关联），
   再给神秘信号
2. **信号只露一角**：只给"存在感"（毫光/低语/异常），不给解释——
   "眨眼便逝，没有引起任何人的察觉"式
3. **解释时机后置**：解释在后面的情绪高点/剧情需求点分批给

### 2. 信息三阶揭示（新事物/新设定的标准节奏）

- 第一阶：只给"存在"（有这个东西）
- 第二阶：给"功能"（怎么用）
- 第三阶：给"根源"（为什么）——通常挂在重大剧情点

### 3. 悬念守恒

- 每批检查：本批是否把某悬念"一次性解释完"了？是 = 钩子断 = 违规
- 每卷至少 1 个大悬念贯通 + 若干小悬念周转
- 卷末允许"揭 1-2 个老悬念换新悬念"（有收有放）

### 4. 与桥段三档衔接

- 关键桥段的悬念节点不可动（大主教之死 = 悬疑起点，位置不能变）
- 解释的时机/方式可调（半关键档）

## 盲审检查

- 本批一次性解释完的悬念数 >1 → 标红
- 新悬念出现时有无"信号先行+解释后置"？无 = 返工
- 卷末是否"有收有放"？全揭 = 下卷无钩，全藏 = 本卷无果

## 灵活度

- 短篇/单集（短剧化）可放宽：600-800 字的集内可"快速揭晓"（集内闭环），
  但章/卷级必须有延续悬念
- 判断口诀：**读者的好奇心是燃料，省着烧**——一次全烧完就没得烧了
