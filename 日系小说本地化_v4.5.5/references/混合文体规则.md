# 混合文体规则（段落分类 + 网文化/文学化）

中文改写采用**混合文体**：按叙事功能切分，推进性内容网文化，氛围性内容文学化。
本文件规定分类标准、改写方式和硬性比例。

---

## 一、段落分类预处理（阶段二，可并行）

改写前先对全文段落做**两分类标注**，写回批文件：

| 分类 | 定义 | 特征检测（可机械检查） |
|------|------|----------------------|
| 【推进】 | 改变情节状态的内容 | 有对白/有动作/有事件结果 |
| 【氛围】 | 不改变情节状态，定调情绪 | 无对白密度（连续3+句无对话无动作）+ 感官词密度高（光线/气味/温度/声音）+ 句均>25字 + 时间锚点（场景开头/情绪转折/章首章尾） |

**执行**：分类结果写回每批文件（每段前标注），改写时按分类处理。

### 判定优先级（唯一裁判：事件推进度）

1. 先判断"这段是否改变情节状态"？
2. **改变 → 网文化**（即使读着很美，如《情书》雪地告白——它推进了关系状态，网文化处理）
3. 不改变 → 检查氛围特征 → 满足则文学化
4. 一段既有氛围又要推进 → **网文化优先**，氛围只留开头一句

---

## 二、网文化写法（推进性内容）

| 内容类型 | 写法 |
|----------|------|
| 对话及交锋 | 短句、口语化、一来一回不留白 |
| 动作/打斗/追逐 | 动词密集、画面感（"他猛地/她骤然"） |
| 冲突/反转/爽点 | 钩子前置、结果先行、情绪外放 |
| 章末 | 强钩子（断章式） |

## 三、文学化写法（氛围性内容）

| 内容类型 | 写法 |
|----------|------|
| 环境/氛围定调（场景开头的天气/光线/气味） | 长句、留白、通感 |
| 情感高潮前的心理蓄力 | 内心独白（**去日式**：不省略主语、不用"……的样子"） |
| 人物首出场/死亡/离别等仪式段落 | 慢节奏、隐喻适度 |
| 梦境/回忆/闪回 | 文学化、意识流适度 |

**文学化硬约束**：
- 每处 ≤ 2 段，不拖节奏
- 保留日式文学的氛围资产，但**零日式语法残留**

---

## 四、硬性比例（防跑偏，可机械检查）

| 指标 | 红线 |
|------|------|
| 文学化段落占比 | 全书 ≤ 20% |
| 对话+动作占比 | 每章 ≥ 70% |
| 句均字数（网文段） | 15-18 字 |
| 句均字数（氛围段） | >25 字 |

**检查方式**：按 `质检规范.md` 硬门槛 #5（去 AI 味）与段落分布统计执行。

## 五、执行示例

**示例 1：推进段网文化**
原文（日式抒情推进）："桜の花びらが舞い散る中、彼はようやく口を開いた。これまで言えずにいた想いを、今ここで伝えるべきだと決意したのだ。"
改写（网文化）："樱花…不，桃花瓣落在肩头。他攥紧拳头，终于开口："我喜欢你。""

**示例 2：氛围段文学化**
原文（日式氛围）："夕暮れの匂いがした。夏が終わろうとしていた。"
改写（文学化）："空气里有暮色将尽的气味。夏天正在一点一点退场。"

**示例 3：美且推进 → 网文化**
雪地告白（既美又推进关系）→ 网文化处理，但保留一句氛围开头：
"风雪扑面。他深吸一口气，对着她的背影喊出声——"（氛围一句 + 推进主体）
