# 日常戏处理规则（2026-08-16）

> 病灶：日轻日常戏 = 场景流（马车闲聊/温泉闲谈/逛街都是完整场景），
> 网文日常戏 = 事件外壳（场景只是壳，里面必须有事件内核）。

## 索引库实证

《全职高手》第 100-104 章（冰霜森林副本记录）——表面是"日常练级"，
实际埋了 4 层内核：
1. 目标：破副本记录（有倒计时张力）
2. 悬念：爱凑热闹的真实身份 = 蒋游会长（身份揭示）
3. 人物变化：唐柔从"怀疑差距只在理解"到"意识到手速真实差距"
4. 信息/展示：押枪神技 + 34 只哥布林操作细节（数字全是展示不是流水账）

## 规则

1. **日常章必须有事件内核**（目标/悬念/人物变化/信息揭示，≥2 个）——
   日常场景只是外壳；无内核的日常 = 流水账 = 压缩/删/并
2. **日常细节功能化**：数字/操作/过程服务于展示（爽点）或情绪，
   不写"无功能细节"（纯逛街见闻式）
3. **纯日常段落压缩 60-70%**（与时间线规则衔接）：只保留
   "有信息/有情绪/有喜剧"的片段
4. **与爽点分布衔接**：日常章也要有小爽点（推进性：获得/揭密/关系推进）
5. **与桥段三档衔接**：关键桥段中的日常（如温泉赔罪戏）事件保留，
   细节可压缩；可动桥段日常自由处理

## 盲审检查

- 无事件内核的日常段 → 标红（改为带目标/悬念/变化的写法或压缩）
- 无功能细节（纯见闻流水账）→ 标红删

## 灵活度

- 喜剧日常章可放宽（搞笑本身是功能——全职高手式吐槽日常成立），
  但也要有"人物/关系推进"
- 判断口诀：**日常是糖不是饭**——偶尔一颗甜，不能当主食吃
